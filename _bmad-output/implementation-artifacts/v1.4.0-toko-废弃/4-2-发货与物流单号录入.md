## 四处刻意的设计选择

1. **权限拆成三个码而不是一个。** `order_view`（看单）/ `order_fulfill`（发货）/ `order_phone_search`
   （按号码捞人）三件事的风险等级差一个量级。给发货专员看单，不等于给他全站按号码查人的能力。
2. **审计摘要只记承运商与单号。** 审计表是永久保留、无 TTL 的（V34），且谁有 `admin.view_logs`
   都能翻。把收件人写进去，等于建了第二份不会过期的通讯录。
3. **推送失败不回滚发货。** 货已经交给承运商了，回滚只会让库里的状态与现实脱节。
   用户在订单详情里照样能看到单号 —— 通知是加速器，不是唯一通道。
4. **承运成本必填，但允许 0。** 自提 / 免运协议价确实可能是 0，但必须是一个**明确的** 0，
   不是"忘了填"。不录则 AB-13A 缺行、假设 A-19 不可验证（S-11）。
