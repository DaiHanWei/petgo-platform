## 0. 开测前准备

### 0.1 环境

| 项 | 说明 |
|---|---|
| App | **staging 测试包**（版本号带 `-stag` 后缀，连 `api-stag.tailtopia.id`）。不要用生产包。 |
| 运营后台 | `https://api-stag.tailtopia.id/admin`，账号需有：场所管理、运营配置、支付记录、用户（赠送 PawCoin）权限 |
| PostHog | 埋点平台，项目同生产；按 **App Version 含 `-stag`** 或按测试账号的 Person 过滤，区分测试数据 |
| 浏览器 | 任意手机 / 电脑浏览器，用于打开 H5 分享页、扫二维码 |

### 0.2 人员与设备

| 角色 | 设备 / 账号 | 职责 |
|---|---|---|
| **测试员 A** | 手机 A + 账号 A（有宠物档案；建议猫） | 主流程操作者 |
| **测试员 B** | 手机 B + 账号 B（有宠物档案；建议狗，用于验证狗题套） | 以「别人」的身份看 A 的公开内容、打开 A 分享的链接 |
| **运营** | 电脑登录运营后台（可由 B 兼任） | 建场所、上传专属章、改价格、赠币、配分享奖励、模拟到账、下架 / 合并场所 |

> 需要两人配合的用例在「协作」列标 **双人**，并写明谁做哪一步。

### 0.3 测试数据准备（运营，一次性）

1. **在测试员 A 当前所在位置附近（≤500 米）新建 2～3 个场所**：后台「运营 → 场所管理 → 新建」。**必须上传至少 1 张照片**，否则不允许保存（这条本身也是用例 C-05）。类型建议各不相同（咖啡店 / 公园 / 宠物酒店）。
2. **给账号 A 赠送 PawCoin**：后台「用户」→ 搜账号 A → 抽屉「操作」页签 →「赠送 PawCoin」，例如 30000，原因写「v1.3.2 真机测试」。
3. **确认一次性解锁定价**：后台「运营配置 → 一次性解锁定价」，四个价格都 ≥1（护照内页价应 ≥ 登机牌单张价）。记下各自金额，用例里会核对。
4. **分享奖励先保持 0**（用例 K-20 起再配置），避免前面分享时提前领掉奖励。

### 0.5 几条全局规则（验证时对照）

- **打卡**：必须在场所 **500 米内**；同一宠物同一场所 **每天（雅加达时间）只能打一次**。要测「再访」需**隔天**或换场所。
- **水印**：宠物足迹 **只有纵览（九宫格）页** 在「当前版本未买」时带水印；单章页、章详情、打卡成功页**一律不带**。分享卡：当前版本未买就带。登机牌：该张未解锁就带。性格结果卡：未解锁就带。**配型卡永远不带。**
- **分享成功才算**：所有「分享」类埋点与分享奖励，都只在系统分享面板里**选了目标**之后才触发；打开面板后取消 = 不算。
