# Story 2.5: 主人配型页

Status: ready-for-dev

## Story

As a 知道自己四字母类型的主人,
I want 看看我和我家毛孩子有多像,
so that 更懂彼此的相处方式（顺便有个好玩的东西能晒）。

**AC4 — 类型选择器** `[L2]` `[L0]`
1. 未设类型时直接显示选择器：标题「Tipe 4 huruf kamu?」+ 说明「Pilih tipe kamu buat lihat seberapa cocok kalian.」+ **4×4 网格**，行序固定 `ENTJ ENTP ENFJ ENFP / ESTJ ESTP ESFJ ESFP / INTJ INTP INFJ INFP / ISTJ ISTP ISFJ ISFP`（UI 稿 A12）；格内**只显四字母**、字母分列排布（每个字母独立字距）。
2. **无别名、无「跳过 / 我不知道」、不做逐轴四步选择**（内容设计 §4.3、AD-20）；不想选直接返回。

4. 吸底「Lihat Hasil」：未选中时禁用；**选中的同一帧由禁用转可点**（UX-DR8：两处状态必须同时变）。**点确认才出结果，选中不跳**。
5. 确认 → `PUT` → 成功：provider 更新、切到结果视图、发 `tailsonality_owner_type_set`（`{'owner_type': 主人四字母, 'pet_type': 宠物四字母, 'match_level': 相同字母数 0..4}`）；失败：保持选择器与当前选中，轻提示「Tipe kamu belum kesimpan, coba lagi ya.」。
6. 已设类型时点「Ganti tipe」→ 回到选择器，**预选当前类型**；换类型不收费、无任何付费要素（内容设计 §2.2：配型全免费）。

**AC5 — 配型计算（纯客户端）** `[L0]`
新建 `lib/features/tailsonality/domain/ts_match.dart`：`TsMatch computeTsMatch(String owner4, String pet4)`（入参都是四字母，调用方负责去掉宠物能量后缀；非四字母抛 `ArgumentError`）→
1. `sameCount`：逐位比较相同字母数（**只比四字母、不比后缀**）；
2. 档位：`kTsMatchTiers[sameCount]`——4 Literally Twins / 3 Twin Flames / 2 Backs Together / 1 Counterweight / 0 Magnetic Poles（D-18，以设计图为准）；素材档号 `tier = 5 - sameCount`（1..5，对应 `match_tier<tier>.webp`）；
3. 卡面差异句键（最多 2 条，Story 4.2 卡面用）：取不同的轴，按优先级 **E/I > T/F > J/P > N/S** 取前两条，键 = 主人字母 + 宠物字母（如主人 E 宠物 I → `'EI'`）；`sameCount == 4` 时为空（卡面改放档位总评首句，4.2 处理）；
4. 逐轴详解键：固定顺序 **E/I → N/S → T/F → J/P** 四条，键 = 主人字母 + 宠物字母（`kTsAxisDetails`）。
单测：4/4 → 空差异；1 位不同（N/S）→ `['NS' 或 'SN']`；全不同 → 取 E/I 与 T/F 两条；只 J/P 与 N/S 不同 → 顺序为 J/P 在前；`ENTJ` vs `INFP` 的 `sameCount == 1`；传 `ENTJ-H` 抛错；逐轴键顺序恒为 EI/NS/TF/JP 四轴。

### 关键设计点

- **配型不落库**：只存主人类型；档位、差异句、详解全部由 `computeTsMatch` 现算（AD-3）。所以「换类型」只是改一个字段，结果页与配型页读同一个 provider 自动一致。
- **宠物侧用本次结果的四字母**：配型页挂在某个结果 token 下——同一宠物不同次结果的四字母可能不同，配型跟着「当前看的那次」走。
- **优先级 E/I > T/F > J/P > N/S 只影响卡面差异句**（最多 2 条，4.2 用）；页内详解永远四轴全出、顺序 E/I → N/S → T/F → J/P。两套文案不可互相替代（内容设计 §4.3）。
- **配型卡永不带水印**：它是「免费传播卡」（同年龄卡），与结果卡规则相反且是有意的；别为「同一功能的卡应当一致」去统一（PRD §3.2 红框）。
- **埋点 `pet_type` 的含义是宠物的四字母**（PRD E-11C），不是物种；物种在项目里一向用 `species` 键。
- **`match_level` = 相同字母数 0..4**（PRD E-11C），与素材档号 `tier`（1..5）不是一回事，别混。
