# Story 1.3: 整页落章与章详情页

Status: review

## Story

As a 刚在新地方打完卡的用户,
I want 看到章「啪」地盖进护照、也能点开任意一枚章看细节,
so that 集章这件事有仪式感，也能回想起那次到访。

## Acceptance Criteria

**AC1 — B4 整页落章（仅首次新章）** `[L2]` `[L0]`
1. 新路由 `PetInsightsRoutes.passportNewStamp = '$hub/passport/new-stamp'`（`/profile/` 前缀下，自动继承门控，**不进**例外集合），参数经 `extra` 传入 `NewStampArgs { placeToken, placeName, placeType, stampImageUrl?, stampCount }`（来源：打卡响应，1.1 + 1.2 已有这些字段；`stampImageUrl` 由 Story 1.4 补，本 story 先按可空接收）。`extra` 缺失或类型不符 → `context.go(PetInsightsRoutes.passport)`，不崩（照 `/me/refunds/pawcoin-success` 的兜底写法）。
2. 打卡成功页 C2 的「Lihat Paspor」（Story 1.2 已接到护照页）**改为**先进 B4：`context.push(PetInsightsRoutes.passportNewStamp, extra: NewStampArgs(...))`。
3. B4 页面：AppBar 标题「Paspor Hewan」；居中大尺寸章面（`PlaceStampView`，与护照格子同一张图等比放大）+ 落章动效（缩放 1.3→1.0 + 淡入 + 轻微回弹，一次，≤600ms，振动一次，见下「可直接复用」）+「Cap baru! {placeName}」+「{stampCount} cap terkumpul」（**无分母**）+ 吸底主按钮「Lihat Paspor」。
4. 「Lihat Paspor」→ `context.pushReplacement(PetInsightsRoutes.passportFor(focus: placeToken))`：进入 B2 并停在新章（Story 1.2 的 `focus` 能力）；返回键从 B2 回到打卡成功页，不会再回到 B4。
5. **静态兜底**：动效关闭（`MediaQuery.disableAnimations == true`）或动画未跑完时，章面 + 两行文案已完整可读（widget 测试：`disableAnimations` 下首帧即可 `find.text` 到两行文案与章面）。
6. **重复到访（C2b）不会进入 B4** `[L0]`：C2b 无「Lihat Paspor」按钮（Story 1.2 已钉）；另加一条测试：`NewStampArgs` 只由成功页在 `isNewStamp == true` 分支构造（源码扫描 `place_checkin_success_page.dart`：`passportNewStamp` 只出现在 `isNewStamp` 为真的分支内）。

**AC3 — B5 章详情页（独立页，非抽屉）** `[L2]` `[L0]`
1. 新路由 `PetInsightsRoutes.passportStamp = '$hub/passport/stamps/:placeToken'`；页面从 `petPassportProvider`（1.2）取数据，按 `placeToken` 找章；找不到（数据变了）→ 显示「Tempat tidak ditemukan」空态 + 返回，不崩。

### 关键设计点

- **B4 只从 C2 进**：PRD 09-23 拍板「首次与重复反馈不同」——重复到访没有新章可落，重播仪式会从惊喜变干扰。因此 B4 不接受任何「重复」入参，也不从护照页内部可达。
- **`pushReplacement` 而不是 `push`**：用户从 B4 进 B2 后按返回，应回成功页而不是再看一次落章。
- **无分母**：PRD §3.3 2026-09-28 专门补记「UI 稿 B4 一度残留 `4 / 12 cap`，只报 `N cap terkumpul`」。测试断言文案不含 `/`。
- **地址只对 ACTIVE 下发**：B6 的产品口径是「只把地址与入口换成场所不存在」，服务端不给地址比客户端藏地址更稳——老客户端或调试工具看不到已下架场所的位置。
- **内页局部 = 同一组件缩小**：B5 的「该章所在护照内页局部」与 B2 的一页是同一版心，抽成一个 widget 两处用；设计稿到位后只改一处。
- **动效约束**（UI 稿硬规则 ⑦）：每个动效有静态线索兜底；本页不是高频交互，允许自定义动画，但只播一次、不循环。
