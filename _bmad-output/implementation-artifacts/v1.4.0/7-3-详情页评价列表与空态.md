## 三处刻意的设计选择
1. **平均分是 `null` 而不是 `0`。** 0 会被渲染成「零分」——
   一个没人评过的商品显示「0 分」比不显示更糟。前端在 null 时只报条数。
2. **空态下不渲染任何星级。** 用例直接断言这一点：
   哪怕是灰色的五个空星，在用户眼里也像「有人评过且给了 0 分」。
3. **评价接口失败时整区不渲染，而不是显示错误。**
   评价区是加分项，它挂了不该让商品详情看起来坏了 —— 用例正面守住这一条。

## 🔒 一处安全取舍
**接口不下发评价者身份**（昵称/头像都不下发）。
下发会让「谁买了什么」变成公开信息 —— 而宠物用品的购买记录本身带健康暗示。
详情页只需要星级、文字、图、时间，这四样就够做买前决策。
