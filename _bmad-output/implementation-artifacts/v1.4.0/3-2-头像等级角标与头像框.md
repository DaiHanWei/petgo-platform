## Story

As a 浏览内容的用户,
I want 在所有头像上看到等级角标和头像框,
so that 等级在社区里被看见。

## Acceptance Criteria

**AC1 — 共享装饰组件 `GrowthAvatarDecoration`（角标 + 三档框，代码绘制）** `[L0]`（UX-DR1 / A1、5.1、5.6、NFR8）
1. 新建 `lib/shared/widgets/growth_avatar_decoration.dart`：包住一个圆形头像 child，按入参 `GrowthBadge? badge`、`double diameter`（头像本体直径，**不含框**）、`bool showLevelBadge = true` 画「框（外圈）→ 角标（右下，最上层）」。`badge == null` → **原样返回 child**（A7）。三个头像组件与主页 / 关注条只包这一层，**不各画一遍**。
2. 角标形态由**一个常量** `kGrowthBadgeNumberMinDiameter = 32` 决定：`diameter ≥ 32` 显示数字，`< 32` 只显示段位色圆点（A1：Feed 32 / 详情 36 / 主页 84 / 关注条 56 → 数字；评论 30 / 回复 24 → 圆点）。尺寸照 A1（Dev Notes「A1 规格」表），不另发明。
3. 角标与框的颜色**只取 `colors.dart`**（段位色由 Story 1.5 定义，框的渐变色由本 story 补进 `colors.dart`），组件里不出现十六进制色值。
4. 三档框：基础 = Sahabat 色环、升级 = Penjaga 渐变环 + 外细环、动效 = Bintang 流光渐变环 **8 秒一圈**匀速旋转；`MediaQuery.maybeOf(context)?.disableAnimations ?? false` 为 true 时动效框**静止**（不建 `AnimationController` 或停在 0）。不引入任何动画 / 插画依赖（0.6）。
5. 框画在头像**外面**、不压头像；角标相对「头像 + 框」整体的右下定位，压在框之上不被遮挡（A1 层级说明）。
6. 角标**不单独响应点击**：不加任何手势；点角标区域与点头像行为一致（父级手势照旧生效）。角标排除出无障碍语义（`ExcludeSemantics`），不新增读屏文案。

### A1 规格（取自 UI 稿 CSS，单位 dp = CSS px）

**段位色**（Story 1.5 已入 `colors.dart`，本 story 只引用）：Pemula `#66748C` · Sahabat `#0A7FA3` · Penjaga `#2B4FBF` · Bintang 渐变 `linear-gradient(135deg, #4A2E9E, #B5307F)`（Flutter：`begin: Alignment.topLeft, end: Alignment.bottomRight`）。

**角标**（`.lvb`：`position:absolute; right:-3; bottom:-3; border-radius:999; border:2px #fff; box-shadow:0 1px 3px rgba(20,16,40,.18); 白字 w700; tabular-nums; z 最上`）

| 头像直径 | 形态 | 尺寸 | 字号 | 偏移 | 稿内出处 |
|---|---|---|---|---|---|
| ≥ 100（庆祝 120） | 数字 | 高 34、最小宽 34 | 15 | right / bottom −3 | D2 / D3 |
| 84 ≤ d < 100（主页、等级页头部） | 数字 | 高 26、最小宽 26 | 12 | −3 | A1 / A4 / B1 |
| 32 ≤ d < 84（Feed 32 / 详情 36 / 列表 40 / 关注条 56 / 框预览 64） | 数字 | 高 17、最小宽 17 | 9.5 | −3 | A1 / A2 / A3 / A8 |
| 28 ≤ d < 32（评论 30） | 圆点 | 9 × 9，白描边 **1.5** | — | right / bottom −1 | A1 / A3 |
| d < 28（回复 24） | 圆点 | 8 × 8，白描边 1.5 | — | −1 | A1 / A3 |

- 数字横向内边距：一位数 0，两位数 3（稿内 `padding:0 0px` / `0 3px`）；三位数同两位数，宽度随内容撑开。
- 角标底色 = 该用户**当前段位色**（Bintang 用渐变），与是否戴框、戴哪档框无关。
- 有框时，角标定位参照「头像 + 框」的外接正方形（稿内 `.lvb` 挂在 `.avw` 包装层上，包装层含框的 padding）。

**三档框**（稿内 `.avw.fr*`：包装层 `padding` = 框厚度，头像外再加 `box-shadow: 0 0 0 2px #fff` 的白隔圈压在框内侧）

| 档 | 包装层 padding | 白隔圈 | 可见色环宽 | 色环填充 | 外饰（不占布局） | 颜色出处 |
|---|---|---|---|---|---|---|
| 基础 BASIC | 3 | 2（贴头像） | 1 | `linear-gradient(160deg, #3FB3D6, #0A7FA3)` | 无 | `.avw.fr-b` |
| 升级 UPGRADED | 4 | 2 | 2 | `linear-gradient(160deg, #7D93EA, #2B4FBF 55%, #1A2F80)` | 外 1.5 白圈 + 再外 1.5 `#AEBCF0` 细环（`0 0 0 1.5px #fff, 0 0 0 3px #AEBCF0`） | `.avw.fr-u` |
| 动效 ANIMATED | 4 | 2 | 2 | `conic-gradient(from 200deg, #4A2E9E, #B5307F, #F09BC4, #B5307F, #4A2E9E)`，**整体 8s 一圈匀速旋转** | 外 1.5 白圈 + `0 0 14px rgba(110,46,158,.35)` 柔光 | `.avw.fr-p` |

- 框色**随档位**（基础 = Sahabat 系、升级 = Penjaga 系、动效 = Bintang 系），**不随佩戴者段位**（C1：Lv12 用户的「Dasar」预览是 Sahabat 色）。
- 布局占位 = `diameter + 2 × padding`（Feed 32 → 基础 38 / 升级与动效 40）；外细环与柔光**不占布局**（用 `CustomPainter` 在 `Stack(clipBehavior: Clip.none)` 外溢绘制），行内其它元素不因外饰挪位。
- CSS → Flutter 角度换算：CSS `160deg` 线性渐变方向 ≈ `begin: Alignment(-0.342, -0.940), end: Alignment(0.342, 0.940)`；CSS `conic-gradient(from 200deg)` 从 12 点钟方向顺时针 200° 起，Flutter `SweepGradient` 从 3 点钟方向起 → 初始 `GradientRotation((200 - 90) × π / 180)`，动画在此基础上叠加 `2π × t`。
- 新增 `colors.dart` 令牌（建议名，T0 对齐 1.5 的命名风格）：`frameBasicStart #3FB3D6`、`frameUpgradedStart #7D93EA`、`frameUpgradedEnd #1A2F80`、`frameUpgradedOuter #AEBCF0`、`frameAnimatedHighlight #F09BC4`、`frameAnimatedGlow rgba(110,46,158,.35)`；`#0A7FA3` / `#2B4FBF` / `#4A2E9E` / `#B5307F` 复用段位色常量。
- ⚠️ A1 文字说明写「基础框 = 段位色**实色**环」，而稿内 CSS 是 `#3FB3D6 → #0A7FA3` 的同色相浅→深渐变。按「以 UI 稿为判断依据」**照 CSS 画**；Completion Notes 记一句。

**关注条（A8）**：现有 `.ring2` = 2.5 紫环（`#845EC9`）+ 2.5 间隙、头像 56、外径 66。戴框者：去掉紫环，`GrowthAvatarDecoration(diameter: 56)`（升级 / 动效占位 64、基础 62），放在 66 × 66 的格子里居中（稿内 `.fa{height:66}` 居中）；没戴框者：紫环原样，角标挂在 56 头像上（稿内 Rina：`.ring2 > .avw > 头像 + 角标`）。

**「我的」页（A6）**：头像 84 戴框（稿内基础框示例），**无等级角标**；相机角标 `.cam2`（mint 底、2px 白描边、padding 4、相机图标 13）在右下最上层——保持现有 `Positioned(right: 0, bottom: 0)`。加框后 Stack 尺寸变大（84 → 90 / 92），相机角标会随 Stack 右下角外移 3–4dp，与稿内 `.cam2{right:-2px;bottom:2px}` 相对头像的位置一致即可（L2 对照 A6 微调，不改相机角标本身样式）。

### 架构约束

- 5.1 / 5.6：装饰组件只有一个，三个头像组件只包这一层；段位色只在 `colors.dart`；阈值一个常量；动效读 `MediaQuery.disableAnimations`。
- NFR7：App 不渲染后端显示串——段位只拿代码；本 story 不显示段位名（段位名不上角标，PRD）。
- 0.6：不引入动画 / 插画依赖；三档框代码绘制。
- 每屏 portrait-only、V1 仅浅色。
- 动效框用 `SingleTickerProviderStateMixin` + `AnimationController(duration: 8s)..repeat()`，外包 `RepaintBoundary`；Feed 一屏多个动效框各自一个 controller，可接受。
- ⚠️ 动效框会让 `pumpAndSettle` 永不结束：既有页面测试的夹具不带 `ANIMATED`（字段缺失 = 无框），不受影响；新写的测试凡含动效框一律 `pump(Duration)`，或在 `MediaQuery(data: …copyWith(disableAnimations: true))` 下测。

- 「我的」页等级胶囊（Story 1.5 已做）；Feed 加权（Story 3.4）。
- 分享页 / 分享卡 / @ 候选 / 屏蔽列表 / 场所标记人等不接入的位置（见上表）。
- 不改后端；不写 golden；不整文件 `dart format`。
- **不新增 arb 文案**：角标只显示数字、无读屏文案（`ExcludeSemantics`），本 story 无可见新文字。若实现中确需新增，键名按约定用 `growthLevel*` / `growthTier*` / `growthFrame*` / `growthBenefit*` 子前缀，不得复用现有 27 个成长档案 `growth*` 键（`growthArchive*`、`growthLoad*` 等）。
