## AC 与验证
| AC | 层级 | 验证 |
|---|---|---|
| 四步：物种硬过滤 → 年龄段 → 体型 → 权重排序取前 4–6 | L0 + **L1** | `fourStepFilter` · `capsAtSixItems` · `ageStageThresholds` |
| 犬猫年龄阈值可后台配置 | L0 | `petgo.shop.reco.puppy-max-years` / `-adult-max-years` 注入 |
| 🔴 规则式，不引入个性化算法 | L0 | 服务只有列表过滤与排序，无任何模型/评分/学习结构 |
| 🔴 每个结果附推荐理由文本 | L1 | `everyItemHasAReason`（理由必须含实际用上的维度） |
| 🔴 缺体重/年龄 → 降级为按物种，标 `degraded=true`，不报错不返回空 | L1 | `degradesWhenWeightMissing` · `degradesWhenAgeOrBothMissing` |
| 🔴 单账号单宠物，不做宠物选择器 | L0 | 入参是 `userId`，取 `findByOwnerId` 的唯一宠物；已标注「1.3.0 多宠物后启用」 |

## 两处刻意的设计选择
1. **年龄与体型在档案缺失时「整步跳过」，而不是「当作 UNIVERSAL 去匹配」。**
   后者会把只适合幼犬的粮推给一只年龄未知的狗 —— 降级的目的是少承诺，不是乱匹配。
2. **未标物种的商品不参与推荐。** 宁可少推一个，也不能把猫粮推给狗
   （`matchesSpecies` 对 null 直接返回 false）。
