## 🔴 为什么 `shippingNet()` 单独存在
它是 **A-19 的直接读数**（「按月核对实际承运成本与收取运费的差额」）。
A-19 承接的正是 FR-99「省掉整条 API 对接工期」的全部风险 —— 没有这一行，
那个假设**无从验证**，而我们已经据此砍掉了承运商 API 对接。为负 = 运费在补贴配送。

## 一处刻意的保守
`grossMarginPercent()` 在销售额为 0 时返回 **0**，不抛异常、不产出 `Infinity`。
分母为零时任何比率都是编的；看板上一个 `Infinity%` 会让人以为系统坏了，
而真相只是「这个区间没卖出东西」。有单测把守。
