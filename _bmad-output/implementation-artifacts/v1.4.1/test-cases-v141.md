# V1.4.1 测试用例（stag · Android 模拟器）

> 环境：stag 后端（api-stag / ops-stag，`petgo-server-stag`）+ Android 模拟器 emulator-5554（Pixel 9 Pro API 36）上的 stag 包（debug key，连 api-stag，Firebase / TikTok / Meta 关闭）。
> 账号：用模拟器上现有的 Google 号；需要「别人」的操作时，在服务器上用 stag 的 JWT_SECRET 给测试号签 JWT 调接口。
> 造数：允许直接写 `petgo_stag`，所有造数记在本文末「造数清单」。
> 范围：1.4.1 的全部改动。全员推送按用户要求跳过；人群筛选**只核对人数，不真发**。
> 结果：✅ 通过 ｜ ❌ 不通过（附问题号）｜ ⏭ 跳过（写原因）｜ ⚠️ 通过但有备注。
