## Story

As a **用网络很慢的、还没建档的用户或计划养宠的用户**,
I want **就算开屏等超时了，最后也别把我丢在一个我用不了的页面上**,
so that **我不用自己去猜该点哪个标签（FR-78 / FR-91）**。

### AC3 — 迟到纠正：七条硬约束逐条验收（L0/L1 · FR-91 核心）

**Given** `ensureRestored()` 的 `.timeout()` **只停止等待、不取消底层请求** —— 恢复完成后仍会写回 `AuthState` 并触发重渲染。**故超时兜底态是会变化的中间态，不是终态**
**And** 超时时用户被当作游客处理、一律落 Diary，且 Diary 渲染的是 **FR-80 游客种草页**（`resolveDiaryUserState` 的输入是 `isLoggedIn`，未恢复即视为未登录）
**When** 落地页由超时兜底产生、且会话恢复随后完成
**Then** 按真实状态**重判一次**落地目标，与当前位置不一致则跳转
**And** **① 仅当本次冷启动落地由超时兜底产生时启用** —— 正常路径（恢复在动效结束前完成）不涉及本机制
**And** **② 触发时机为恢复 future 完成**（成功或失败都算完成），**不是固定延时** —— 固定延时要么早于恢复（白跳）要么晚于恢复（用户已在操作）
**And** **③ 仅当用户仍停在兜底送去的那个落地页上才纠正**（详见 AC4，此条为安全攸关）
**And** **④ 只纠正一次**，此后本次冷启动内不再干预，防止与其它跳转逻辑互相拉扯
**And** **⑤ 本次冷启动若由深链唤起 → 不纠正**（与 AD-8 分流优先级 pending 深链 > 落地矩阵一致）
**And** **⑥ 恢复失败（确实是游客）→ 重判结果仍为 Diary → 不产生跳转**，真游客不应因本机制被打扰
**And** **⑦ 🔴 兽医角色隔离守卫（`app_router.dart` 的 `if (auth.isVet)` 分支）保留不动**，作为双保险 —— 那是**用户/兽医路由互斥的安全边界**，继承「安全规则只升不降不可绕过」，**不得以「统一由 FR-91 处理」为名弱化或替换它**

## Dev Notes

### 🔴 两条安全攸关约束（不可降级、不可跳过）

**一、兽医角色隔离守卫必须原样保留**（AC3⑦）
`app_router.dart` 的 `redirect` 里有：
- `if (auth.isVet) { if (!isVetRoute || loc == '/vet/login') return '/vet/workbench'; return null; }`
- `if (isVetRoute && loc != '/vet/login') return '/home';`

这是**用户侧与兽医侧路由互斥的安全边界**，不是「顺手做的纠正」。FR-91 新增机制时容易产生「都统一走迟到纠正就行了」的想法 —— **不行**。守卫继承「安全规则只升不降不可绕过」，必须留作双保险。

**二、不打扰已离开的用户，优先级高于纠正**（AC4）
用户可能在兜底落地后 1 秒内就点走了。此时恢复完成触发纠正，会把正在浏览的人**强行拽走** —— 这比落错页严重得多。**冲突时以「不打扰」为准。**

判定必须**比对路径**。用「路由栈深度」判断会误判：用户在同一页内开弹层 / 进详情再返回，栈深变了但人没走。

### 为什么需要 FR-91（技术根因）

`ensureRestored()` 返回的是共享 future（`auth_state.dart:44`），而 `.timeout(5s)` **只停止等待、不取消底层请求**。恢复请求继续跑，完成后写回 `AuthState`；路由挂了 `refreshListenable`（`app_router.dart:147` / `:153` 的 `ref.listen` + `authRefresh`），状态变化会**触发 redirect 重跑**、页面重渲染。

后果：
- **兽医**能自愈 —— 因为 redirect 里有角色隔离守卫，会把它收口回工作台
- **A·未建档 与 B/C 不能自愈** —— 它们是**已登录**用户，而 `/profile` 的门控条件是 `!auth.isLoggedIn && controlled`（`app_router.dart`），已登录不命中；redirect 里**没有任何分支**会把已登录用户从 Diary 移到 Discovery

所以 B/C 的实际体验是：**先看到 FR-80 游客种草页 → 恢复回来后翻成「有宠专属」功能拒绝页 → 卡住**。FR-91 补的就是「兜底跳转之后没人再纠正一次」这一环。
