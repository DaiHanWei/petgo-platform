# Story 1.3: 他人主页改版与关注按钮

Status: review

> 版本 v1.3.4 · 主题 follow · 分支 `feat/1.3.4-follow-notify`
> 口径优先级：`决策日志-follow.md` > `PRD-v1.3.4-follow.md` > `architecture-v1.3.4-follow-delta.md` > `ui-v1.3.4-follow.html`（均在 `_bmad-output/planning-artifacts/v1.3.4/`）
> 本 story 只动 **App**（`petgo_app/`）。依赖 Story 1.1（关注接口）与 Story 1.2（`PublicProfileResponse` 新字段）。

## Story

As a 用户,
I want 在别人的主页一眼看到他的帖子、获赞、关注、粉丝，并能关注他,
so that 我可以决定要不要持续关注这个人。

**AC5 — 三态按钮与 Pengikut 即时 ±1（UI 稿 A2 ~ A4）** `[L0]`
1. 我未关注且对方未关注我 →「Ikuti」；对方关注我 →「Ikuti Balik」；我已关注 →「Mengikuti」（FR-140.2，UI 稿 A3）。
2. 点「Ikuti」/「Ikuti Balik」→ 按钮立即变「Mengikuti」、Pengikut +1；点「Mengikuti」→ 立即变回「Ikuti」或「Ikuti Balik」（取决于 `followsMe`）、Pengikut −1（FR-140.7）。
3. Pengikut 显示值 = `max(0, p.followerCount + (eff.iFollow ? 1 : 0) − (p.iFollow ? 1 : 0))`，`eff = followStateProvider.effective(userId, 服务端初值)`。即：覆盖与服务端一致时直接用服务端数；不一致（本页加载后我改过关系）时 ±1。**不用**响应里的 `followerCount` 回写（避免与服务端初值来源混用；重进页面即取最新服务端值）。
4. 失败回滚：网络失败 → 按钮与 Pengikut 回到点击前 + **顶部** toast（`showAppToast(..., top: true)`，UI 稿 A11）：关注失败「Gagal mengikuti, coba lagi」、取关失败「Gagal berhenti mengikuti, coba lagi」；429（`typeSlug == 'rate-limited'` 或 `status == 429`）→ 回滚 + **底部** toast「Terlalu sering. Coba lagi nanti.」（UI 稿 A10）。其余错误（409 `follow-blocked`、404 `not-found` 等）按网络失败处理（见待确认 #4）。
5. 被拉黑方视角（对方拉黑了我，UI 稿 A7）：App 不做任何特殊分支——服务端已把帖子 / 获赞置 0、帖子空、宠物 204，关注 / 粉丝数与 `iFollow` / `followsMe` 为真实值；按钮按真实关系显示且可操作（D-4：照常可关注）。**不得**新增任何「是否被拉黑」判断（`public_profile_blocked_view_test` 的源码扫描约束继续成立）。
6. 游客登录后回到主页（登录弹窗成功关闭、仍停在此页）→ 主页数据重取（`ref.listen` 登录态变化 → `invalidate(publicProfileProvider(userId))`、`publicProfilePetProvider(userId)`、`publicUserPostsProvider(userId)`），按钮按新身份的真实关系显示（含 `self` 切换），**不自动关注**。
7. 拉黑成功（`_startBlock` 成功分支）→ `followStateProvider.forget(userId)`（服务端已同事务删除 A→B 关注，残留覆盖会让其他页面误显示「已关注」）。

### 1.3 建什么 / 2.1 扩什么（全局关注状态的分工）

| | Story 1.3（本 story） | Story 2.1 |
|---|---|---|
| `followStateProvider` | `Map<int, FollowState>` 覆盖表；`set` / `forget` / `effective`；登录态切换重建 | 覆盖值加 `pinnedSurface`（按钮实例 key）；「非常驻位置已关注不显示、刚点的那个保留 Mengikuti」；「刷新数据后清除覆盖」的时机与规则（AD-7） |

- `FollowButton` 的点击 / 回滚 / toast / 埋点逻辑写在组件内部一处，2.1 / 2.2 / 3.4 只换外观与 `source`，**不得复制一份**。
