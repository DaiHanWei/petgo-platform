# Story 2.3: 露出区域页（取代三档裁剪页）

Status: ready-for-dev

> 版本 V1.3.4 · 主题 app · Epic 2「发图不丢画面」· FR-125.2 / 125.3 / 125.4 / 125.5 / 125.6 · AD-8 · UX-DR1 / UX-DR2 · UI 稿 A1–A4
> 本 story **只新建页面与其领域类型**，不接线进发帖页、不删旧裁剪页——接线与删除在 2.4。纯 App，无后端。

## Story

As a 发帖用户,
I want 选了超宽 / 超长图后，在一个页面里拖动白框选首页露出哪一段，多张图同页切换,
so that 整张图都保留，我只决定首页展示哪一部分。

**AC2 — 默认居中** `[L0]`
打开即每张图 offset = **0.5**（白框在可移动方向上居中）；不拖动直接点「Lanjut」→ 返回 `offsets` 全为 0.5、`adjusted` 全为 false。

**AC3 — 单指拖动、只沿一个方向、到边即停** `[L0]` · `[L2]` 手感
1. 宽图：白框只接 `onHorizontalDragUpdate`，`offset += dx / range`；竖图：只接 `onVerticalDragUpdate`，`offset += dy / range`；`range` = 图片显示尺寸在该方向上减去白框尺寸；`range <= 0` 时不响应；
2. 结果 `clamp(0.0, 1.0)`：拖到最左（最上）= **0**，最右（最下）= **1**；白框跟手移动（框随手指走，**不是**拖图）；
3. 某张图收到过任何一次使 offset 改变的拖动 → 该张 `adjusted = true`（拖回 0.5 仍为 true）；
4. 手势分工：在白框**内**起手的拖动归白框（内层识别器先入场胜出）；在白框外（压暗区）起手的横向滑动归 `PageView` 切图；竖图白框只吃纵向，横向滑动一律切图。

**AC4 — 多张同页切换，各自独立** `[L0]`
一次传入 3 张：页码显示「1 / 3」；左右滑或点缩略图（`animateToPage`，200ms，`Curves.easeOut`）切到对应张，页码与缩略图高亮同步；每张 offset / adjusted 各存各的，切换不影响其他张（PRD AC7）。

**AC5 — 「Lanjut」一次返回整批** `[L0]`
`Navigator.pop(ExposureResult(offsets: [...], adjusted: [...]))`，两个列表与传入 `images` **同序等长**；未调的为 0.5 / false。

**AC6 — ✕ / 系统返回 = 取消** `[L0]`
1. 点 `exposureClose` → 先上报 `publish_image_crop_exit_tapped`，属性 `{'original_ratio': <当前张原图 w/h，保留 3 位小数的 double>}`（口径同旧页），再 `pop(null)`；
2. 系统返回键 → `pop(null)`，**不上报**事件（与旧页一致：事件名是 `_tapped`）；
3. 调用方据 `null` 丢弃本次选的全部图（调用方在 2.4 实现，本 story 只保证返回 null）。

**AC7 — 文案** `[L0]`
新增 2 个 key（en + id 两文件同 key，见下表）；标题复用 `publishCropTitle`、按钮复用 `onboardNext`；`test/l10n/microcopy_rules_test.dart` 照常通过（两文件 key 集相同、≤1 emoji、en 不含印尼语）。

### 关键设计点

- **为什么拖白框而不是拖图**：UI 决策 2026-10-09 选 A1「整图 + 白框」——用户一眼看到整张图里哪段会露出，与「原图完整保留」的心智一致；旧页「窗口固定拖图」的方向感正好相反。
- **offset 定义与展示端同一把尺子**：白框左（上）边 = `range * offset`；2.2 `BoxFit.cover + Alignment(2o−1)` 在展示端截出的正是这一段。两端任何一端改公式，另一端必须同改。
- **窗口比例不给选**：由越界方向唯一决定（过宽 1.78 / 过竖 0.75，PRD FR-125.3）；页面不接受任何「档位」入参。
- **手势冲突**：宽图白框与 `PageView` 都吃横向拖动；Flutter 手势竞技场里命中测试更深的识别器先收到事件、先越过 slop 先胜出，所以「框内起手 = 移框、框外起手 = 切图」无需自定义识别器。框外可见区域在 offset 为 0 或 1 时只剩一侧，用户仍可点缩略图切图。手感属 `[L2]`。
- **页面无状态外泄**：不读写任何 provider，进出全靠构造参数与 `pop` 结果——2.4 才能在 L0 用 fake `ask` 编排测试。
- **内存**：缩略图条 `cacheWidth: 144`（48 × 3 倍屏）；取景区每页 `Image.memory(bytes, fit: BoxFit.fill)` 放进按 contain 算好的 `SizedBox`，`PageView` 懒构建，不一次解码全部。
