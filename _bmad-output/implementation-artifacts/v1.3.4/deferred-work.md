## AB-22 评审延后项（2026-10-14，非本次改动引入或需改 app 主题校验语义）

- **单行配置卡无并发保护**：两人同时保存时后提交者整行覆盖（客服卡等存量单行卡同样如此）；如需修，统一给单行配置卡加乐观锁 / 加载时快照比对。
- **商店链接 >512 字符直接 POST → 500**：`AppVersionConfigService.update` 只校验 https 前缀不校验长度；补长度校验属改 app 主题校验语义（spec Ask First）。
- **只填 `https://` 视为已填**：`httpsOrBlank` 只看前缀，上调最低版本时可绕过 `store-url.blank`；建议校验含主机名。
- **报错标红不精确到单个字段**：`version.format` / `store-url.*` 不区分字段，三个（两个）框一起标红；需服务层码带字段信息。

## AB-30 评审延后项（2026-10-14）

- **弹窗编辑无乐观锁**：两人同时编辑同一弹窗，后提交者整表单覆盖（状态已用 @DynamicUpdate 保护，其余字段未保护）；与单行配置卡同一问题，建议一起加 `@Version`。
- **启用时不提示「启用了也不会弹」**：已结束的时间窗、印尼文图在 CDN 拼不出地址，启用照样成功；建议启用时给出提示。
- **CDN 未配置时编辑态看不到已存图片、英文图删不掉**：`resolveImage` 返回 null 时不渲染缩略图与删除钮；仅影响未配 CDN 的环境（本地 / 测试）。
