# Story 1.4: Know Your Pet 聚合页改为单列整宽

Status: review

## Story

As a 用户,
I want 聚合页每个入口一整行、副标题完整显示,
so that 看得更清楚，以后也好加新入口。

## Acceptance Criteria

**AC1 — 单列整宽，顺序不变** `[L0]` `[L2]`
1. `insightRows(List<Widget> cards, {double gap = 10})`（`petgo_app/lib/features/profile/presentation/pet_insights_page.dart`）改为单列：每张卡独占一行、宽度撑满（父 `Column` 已是 `CrossAxisAlignment.stretch`），相邻两行之间一个 `SizedBox(height: gap)`；**不再**产出 `Row` / `IntrinsicHeight` / `Expanded`。函数名与签名保持不变（AD-14：后续新增入口只需往列表追加）。
2. 五项顺序不变：Kartu Identitas（`insightIdCard`）/ Umur Hewanmu（`insightAgeCard`）/ Jejak Anabul（`insightPassport`）/ Tailsonality（`insightTailsonality`）/ Boarding Pass（`insightBoardingPass`）；五个 `inkKey` 一字不改（既有测试与埋点对照认它）。
3. 标题、副标题、图标全部沿用现有 i18n 与代码（`idCardTitle`/`idCardEntrySub`、`ageCardTitle`/`ageCardEntrySub`、`passportEntryTitle`/`passportEntrySub`、`tailsonalityTitle`/`tailsonalityEntrySub`、`boardingPassEntryTitle`/`boardingPassEntrySub`）；保留「Jejak Anabul」，**不**采用参考图的「Paspor Hewan」（FR-142A.2）。
4. `InsightEntryCard`（`widgets/insight_entry_card.dart`）**代码不改**：白底、14 圆角、柔阴影、38px 紫浅底图标块、标题 13 / 副标题 10.5（UX-DR1）。它同时被档案页头部 `diary_header.dart:234` 使用，改了会牵动档案页。
5. L2：真机 360dp 宽下 id / en 两语，五张卡等宽整行；副标题一行可完整显示时不折行（UI 稿 A1）。

**AC2 — 年龄卡置灰（不变）** `[L0]`
1. 宠物物种非 `CAT` / `DOG`（含档案取不到）时年龄卡：整卡 45% 透明、图标块 `AppColors.line2` 底 + `AppColors.muted` 图标、副标题为 `ageCardUnavailableForSpecies`、`onTap == null` 不可点（UI 稿 A2，现状逻辑 `pet_insights_page.dart:211-212, 241-245` 不动）。
2. 猫 / 狗时年龄卡可点，副标题 `ageCardEntrySub`。

**AC3 — Tailsonality NEW 角标与 coachmark 锚点（不变）** `[L0]`
1. Tailsonality 卡仍包在 `KeyedSubtree(key: _tailsonalityAnchor, …)` 里，`badge: l10n.insightNewBadge`；角标位置（卡右上 `top: -4, right: 8`）在单列下不被上一行遮挡、不被裁切。
2. 第二次入口引导（`_maybeShowTailsonalityCoachmark`）行为不变：高亮框与 `insightTailsonality` 卡矩形一致（`padding: 0`、`anchorKey: _tailsonalityAnchor`、`rootOverlay: true`）。

**AC4 — 测试** `[L0]`
1. `test/profile/pet_insights_test.dart` 按单列更新（见 Dev Notes「测试」），并**新增** `insightRows` 单元测试。
2. `test/tailsonality/tailsonality_entry_coachmark_test.dart`、`test/profile/ktp_migration_coachmark_test.dart` 不改代码即通过。
3. `flutter analyze` 无新增告警；`flutter test test/profile test/tailsonality` 全绿。

## Dev Notes

### 现状（改动前必读）

- `insightRows`（`petgo_app/lib/features/profile/presentation/pet_insights_page.dart:78-98`）：每两张一行，`IntrinsicHeight > Row(stretch) > 2×Expanded`，落单的一张 `SizedBox(width: double.infinity)` 整宽 → 当前五项排成 2+2+1。**全仓只有这一处调用**（`:225`）。
- 五张卡在 `build`（`:225-275`）里按顺序列出；Tailsonality 卡外包 `KeyedSubtree(key: _tailsonalityAnchor)`（`:256-266`），锚点供 `_maybeShowTailsonalityCoachmark`（`:142-178`）量位置。
- 年龄卡置灰：`petType` 取 `petProfileProvider`，非 CAT / DOG（含取不到）→ `onTap: null`、副标题换 `ageCardUnavailableForSpecies`（`:211-212, :241-245`）；置灰外观由 `InsightEntryCard._buildCard`（`insight_entry_card.dart:67-136`）根据 `onTap == null` 画出（`Opacity 0.45`、图标块 `line2` / `muted`）。
- `InsightEntryCard` 的角标画在外层 `Stack(clipBehavior: Clip.none, fit: StackFit.passthrough)`（`insight_entry_card.dart:38-63`）；副标题 `maxLines: 3`（`:121`，为半宽下印尼语折行而放宽）。单列后两处都不需要改；注释里「同行两卡等高」的说法可顺手改成通用描述，**不改任何数值与结构**。
- 本页外观 = UI 稿 A1 / A2；A1 说明原文：「唯一改动：`insightRows()` 由 2+2+1 改为单列整宽，卡片组件 `InsightEntryCard` 不变」。

**必须保持**：五个 `inkKey`、`_tailsonalityAnchor` 的位置（包住 Tailsonality 卡且只包它）、`ModalRoute.of(context)?.isCurrent` 判断、`Overlay.of(context, rootOverlay: true)`、`padding: 0`（`tailsonality_entry_coachmark_test.dart:101-120` 是源码断言）。

### 架构约束

- AD-14：`insightRows()` 单列；`InsightEntryCard`、顺序、文案、年龄卡置灰、Tailsonality NEW 与 coachmark 锚点不变。
- 聚合页路由与游客门控（`PetInsightsRoutes`、`_controlledExactExceptions`）不动——`pet_insights_test.dart` 的 AC5 组是安全攸关断言。
- 不新增 l10n key。

### 本 story 不做

- 不改 `InsightEntryCard` 组件、不改档案页头部入口卡（`diary_header.dart`）。
- 不改任何入口的跳转目标（身份证入口仍 `context.push(PetInsightsRoutes.idCard)`；列表页双 Tab 在 Story 1.5）。
- 不新增入口、不改文案。

### 测试

`test/profile/pet_insights_test.dart`（`_pumpHub` 在 `:320-365` 附近，默认 800×600 视口、`locale: id`）：
- `:134-148`「聚合页就是五张卡，按 C-8 顺序」——判据 `cur.top > prev.top || (同行且 left 更大)` 单列下仍成立，**保留**；建议收紧为严格 `cur.top > prev.bottom`。
- `:150-168`「第二行护照 + Tailsonality 并排」——`ktp.top == age.top`、`ts.top == pass.top`、`pass.width ≈ ktp.width` 在单列下会红。改为：五张卡 `left` 相同、`width` 相同（容差 1）、且宽度 ≈ 页面内容宽（`tester.getSize(find.byType(SingleChildScrollView)).width - 32`）；保留「护照 / Tailsonality 全物种可点」与「点护照进 passport」两段断言。
- `:170-180`「第三行登机牌整宽」——`bp.width > ktp.width * 1.8` 会红。改为：登机牌在 Tailsonality 下方、宽度与 KTP 卡相同；保留「点登机牌进列表」。
- 用例名与注释里的「2+2+1 / 第二行 / 第三行」同步改成单列描述。
- **新增** `group('insightRows 单列（V1.3.4 AD-14）')`：
  - 传 3 个带 key 的 `SizedBox(height: 40)`，`gap: 10` → 返回 5 个 widget，偶数位是卡、奇数位是 `SizedBox(height: 10)`；
  - 返回结果里没有 `Row` / `IntrinsicHeight`（pump 进 `Column(crossAxisAlignment: stretch)` 后 `find.byType(Row)` 为 0）；
  - 0 张 → 空列表；1 张 → 只有它自己、无间隔；
  - pump 后每张卡宽度 = 父宽。
- 年龄卡置灰组（`:243-293`）与 Tailsonality 分流组（`:194-241`）不改，作为回归。
- `tailsonality_entry_coachmark_test.dart`：`:51-59` 断言 `overlay.spotlight == getRect(insightTailsonality)`，单列后卡变宽仍应相等；源码断言 `:101-120` 不受影响。
- `ktp_migration_coachmark_test.dart` 测的是 `CoachmarkOverlay` 与成长档案页锚点，与本页布局无关，作为回归跑一遍即可。
