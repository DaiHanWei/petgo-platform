# Story 3.5: 首页场所入口换成「折叠地图 + 定位针」图标

Status: ready-for-dev

## Story

As a 刷首页的用户,
I want 场所入口的图标一眼看出是「地点」相关,
so that 我能注意到这个功能。

> 范围：**纯 App，单组件改图标**（FR-UI.1 / AD-20 / UX-DR13）。无后端、无文案、无埋点。

## Acceptance Criteria

**AC1 — 换图标** `[L0]` `[L2]`
1. `PlaceEntryRow`（`lib/features/place/presentation/place_entry_row.dart` L45）的 `const Icon(Icons.place_outlined, size: 20, color: AppColors.mint)` 换为 UI 稿 C1 中的「折叠地图 + 定位针」SVG：
   ```dart
   SvgPicture.string(
     kPlaceEntryMapPinSvg,
     key: const ValueKey('placeEntryIcon'),
     width: 20,
     height: 20,
     colorFilter: const ColorFilter.mode(AppColors.mint, BlendMode.srcIn),
   )
   ```
2. 尺寸 **20×20**（沿用现有图标尺寸，**不按 UI 稿的 22**）；颜色 `AppColors.mint`（`#845EC9`）不变。
3. SVG 常量 `kPlaceEntryMapPinSvg` 定义在同文件顶部（私有到本组件即可，命名照写），内容逐字如下（UI 稿 C1 `.hm-place` 里那枚图标的 4 段 `path` + 1 个 `circle`，stroke-width 1.8；仅把 `stroke="currentColor"` 换成占位色 `#000000`，颜色由 `colorFilter` 决定）：
   ```dart
   const String kPlaceEntryMapPinSvg =
       '<svg viewBox="0 0 24 24" fill="none" stroke="#000000" stroke-width="1.8" '
       'stroke-linecap="round" stroke-linejoin="round">'
       '<path d="M3 6.5l5-2 5 2 5-2v6.2"/>'
       '<path d="M3 6.5v13l5-2 3 1.2"/>'
       '<path d="M8 4.5v13"/>'
       '<path d="M18 21.5s3.6-3 3.6-5.9a3.6 3.6 0 1 0-7.2 0c0 2.9 3.6 5.9 3.6 5.9z"/>'
       '<circle cx="18" cy="15.6" r="1.2"/>'
       '</svg>';
   ```
4. 文字（`l10n.placeEntryLabel`）、右箭头（`Icons.chevron_right_rounded` 20 / mint）、背景（`AppColors.violet100`、圆角 12）、内边距、点击跳转（`context.push(PlaceListPage.routePath)`）、行 key `placeEntryRow` **全部不变**。
5. 唯一使用处是首页 `_BerandaTop`（`home_page.dart` L314），已核实 `lib/` 内无其它 `PlaceEntryRow(` 调用，无需「替换所有用到这一行的页面」。

**AC2 — 测试** `[L0]`
1. 新建 `test/place/place_entry_row_test.dart`：pump `PlaceEntryRow`（`MaterialApp` + l10n + 一个能接 `push` 的 `GoRouter`），断言
   - `find.byKey(ValueKey('placeEntryIcon'))` 找到 1 个 `SvgPicture`，`tester.getSize` = 20×20；
   - 组件子树内 `find.byIcon(Icons.place_outlined)` 为 0；
   - `find.byIcon(Icons.chevron_right_rounded)` 为 1、文案 `placeEntryLabel` 在；
   - 点 `placeEntryRow` 跳到场所列表路由（照 `pet_recommendation_strip_test.dart` 的 GoRouter 写法）。
2. 源码断言：`place_entry_row.dart` 含 `stroke-width="1.8"` 与上面 5 段图形的 `d` / `circle` 原文（防误改）。
3. 既有测试**全部通过且不改**：`test/profile/pet_recommendation_strip_test.dart`（L115、L164、L191、L217 都按 `find.byType(PlaceEntryRow)` 断言，不依赖图标）、`test/content/beranda_home_test.dart`。另：`test/profile/calendar_cell_priority_test.dart` L67-80、`test/profile/timeline_five_class_render_test.dart` L282 里的 `Icons.place_outlined` 断言针对的是**日历格 / 时间线打卡图标**，与本组件无关，不受影响、不得改。

**AC3 — 视觉** `[L2]`
模拟器首页：图标为「折叠地图 + 定位针」、紫色、20 尺寸，与文字垂直居中；其余与改前一致。

### 关键设计点

- **尺寸按 20 而非 UI 稿 22**：保持与右侧箭头（20）等大，行高不变；UI 稿 C1 的 22 只是示意（本 story 原文定 20）。
- **用 `colorFilter` 而不是改 SVG 颜色**：SVG 原文是 `stroke="currentColor"`，`flutter_svg` 对 `currentColor` 需额外传 `SvgTheme`；统一用占位色 + `srcIn` 着色最简单，颜色仍由 `AppColors.mint` 单一来源决定。
- 第一版「定位针里放爪印」缩小后认不出是地点，已弃用（UI 稿 C1 注释）——不要用它。
- 不新增依赖、不新增素材文件（SVG 内联）。
