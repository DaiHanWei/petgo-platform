# Story 3.3：后台预览与识别视频帖

Status: review

> 专题线 video · Epic 3 · 后端 + 后台模板。分支 `feat/video`。依赖 1.4（`VideoUrlResolver.forAdmin`、`SignedUrlService.sign(bucket,key,ttl)`）、2.1（`PostMediaResolver`）。
> 权威顺序：决策日志-video.md > PRD-video.md > architecture-video-delta.md > epics-video.md。

## Story

As a 运营，
I want 在后台的内容列表、内容抽屉和审核详情里直接看到并播放视频帖，
so that 我能判断内容是否需要下架或通过审核。

**范围**：FR-17（后台部分）；架构 AD-8（`forAdmin`）、AD-12（内容 / 评论审核缩略图用签名 URL）。

## Acceptance Criteria

1. **内容列表【L1 + L2 浏览器】** `content-list.html` 某行是视频帖：显示**封面**（签名 URL，私有 / 审核中 / 已下架都能看到）与「视频」标识，不显示成坏图。
2. **抽屉与审核详情【L1 + L2】** `drawer-content.html`、`review-detail.html` 打开视频帖（含私有、审核中、已下架）：`<video controls>` 播放，地址来自 `VideoUrlResolver.forAdmin(post)` 的签名 URL；封面也用签名 URL（作 `poster`）。
3. **评论审核缩略图【L1】** 评论审核（`comments-inspect`）里所属帖子是视频帖时，缩略图用签名封面。
4. **顶置管理【L1】** `AdminContentPinService` 选中 / 展示视频帖：显示签名封面与视频标识，顶置功能正常。
5. **图文帖不变【L0】** 图文帖的后台展示与改动前一致（图片地址原样）。签名 URL 不进日志。
