# Story 2.4：全屏播放页

Status: review

> 专题线 video · Epic 2 · 只改 App。分支 `feat/video`。依赖 2.1（DTO 下发 `video.url`）、2.3（模型 `isVideo` / `VideoInfo`、`VideoRouteExtra` / `VideoSource`）。
> 权威顺序：决策日志-video.md > PRD-video.md > architecture-video-delta.md > epics-video.md。

## Story

As a 用户，
I want 点开视频帖后流畅地全屏观看，
so that 我能看完一段宠物短剧或科普。

**范围**：FR-15、FR-21（观看部分）；架构 AD-10；NFR-2；决策 V-23（静音会话内记住）。
**不在范围**：播放页上的作者区 / 正文 / 点赞 / 评论 / 分享 / 举报叠加层（2.5 —— 本 Story 只留叠加层插槽与返回按钮）；H5 分享页（2.6）。

## Acceptance Criteria

1. **路由分流【L0 + L2】** `/content/:id` 不变。`ContentDetailPage`：`extra` 为 `VideoRouteExtra` 时直接渲染 `VideoPostPage`（跳过一次加载态，详情在页内继续拉）；否则先拉详情，`detail.isVideo` → 渲染 `VideoPostPage`，否则原图文详情。`focus=comments` 透传给视频页（评论抽屉由 2.5 打开，本 Story 透传参数并留接口）。`source` 取 `extra.source`，其次 query `src`，缺省 `other`；通知 / 推送深链进入时为 `notification` / `push`（由深链生成 `src`）。
2. **App 内分享页【L0】** `SharedPostPage` 遇到视频帖：分享投影刻意没有帖子 id（AD-15 Rule 5），无法跳 `/content/:id`；改为在分享页内用同一个播放器组件播放（`source=share`），不新增任何 id 字段。⚠️ 偏离 AD-10「跳到 /content/:id」—— 原因见 Dev Notes，Completion Notes 记录待 PO 确认。
3. **播放页外观【L2】** 黑底；视频按原比例 `AspectRatio` 居中显示，横屏视频上下留黑；App 保持竖屏（全局已锁）；加载中显示封面（`imageUrls[0]`）+ 转圈；有声自动播放。
4. **交互【L0 widget + L2】** 单击画面暂停 / 继续；可拖动进度条；播完循环（`setLooping(true)`）；15 秒内没出首帧 → 「视频加载失败，点击重试」（点击重建控制器重试）；移动网络不提示；有静音按钮，状态存在**进程内** provider（本次打开 App 期间保持，重启恢复有声，不落盘）。
5. **生命周期【L2】** 离开页面停止并释放控制器；App 进后台暂停，回前台**不自动续播**；不做磁盘缓存（`VideoPlayerController.networkUrl`，不加缓存层）。
6. **播放埋点【L0】**（名按仓库规范改名，见 cloud-rules）所有事件带 `post_id`、`source`（App 版本由埋点 SDK 自动带）：
   - `video_play_started{ttff_ms}`：点开到首帧；
   - `video_progress_reported{pct}`：25 / 50 / 75 各一次（单次进入内）；
   - `video_play_completed{loop}`：每播完一遍报一次，`loop` 为第几遍（从 1 起）；
   - `video_buffering_started{duration_ms}`：缓冲结束时报本次缓冲时长（首帧前的加载不算）；
   - `video_play_failed{error_type}`：`timeout | network | decode | unknown`；
   - `video_watch_time_reported{seconds, occurred_at}`：离开播放页时报；`seconds` 只计画面实际在播放的时间（暂停、后台、缓冲不计），上限 = 时长 × 3；App 被杀时 `shared_preferences` 只保留最后一条未上报记录，下次启动补报后删除。
7. **依赖【L0】** 新增 `video_player` ^2.14.1（架构基线已核实）；不新增系统权限；不加缓存库。

## Dev Notes

### 必须保留

- 判断视频帖只看 `mediaType`（`isVideo`）。
- 静音只在进程内记住（V-23），不落盘。
- 离开页面释放控制器；后台暂停、回前台不续播；不做磁盘缓存。
- 埋点名 / 属性名过 `v112_events_test`；不带 URL（签名 URL 尤其不能进埋点 / 日志，NFR-4）。
- 不新增系统权限。

### 分享页偏离说明（AC 2）

架构 AD-10 写「App 内分享页 SharedPostPage 遇到视频帖，跳到 /content/:id」，但 `SharedPostResponse` / `SharedPost` 依 AD-15 Rule 5 **刻意不含任何 id**（类注释：边界画在投影上），App 拿不到帖子 id。可选：① 给分享投影加 id（破坏 AD-15 的安全边界，不可取）；② 分享页内直接播放（不新增字段）。按「不自行拍板」原则取不触碰安全边界的 ②，并在 Completion Notes 标注待 PO 确认。
