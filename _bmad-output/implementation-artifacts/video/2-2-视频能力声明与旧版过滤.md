# Story 2.2：视频能力声明与旧版过滤

Status: review

> 专题线 video · Epic 2 · 后端 + App 拦截器一行。分支 `feat/video`。依赖 1.3（`media_type` 列）、2.1（DTO 下发视频信息）。
> 权威顺序：决策日志-video.md > PRD-video.md > architecture-video-delta.md > epics-video.md。

## Story

As a 旧版 App 用户，
I want 根本看不到我播放不了的视频帖，
so that 我不会点开一个放不出来的东西。

**范围**：FR-18；架构 AD-7；一致性规则 2、3；决策 V-36（能力声明，不比较版本号）。
**不在范围**：App 解析视频字段（2.3）；通知中心（没有帖子缩略图，AD-7 注明不适用；通知深链进详情由详情 404 兜住）；写接口（点赞、评论、生成分享链接 —— 旧版本来看不到视频帖）；`findRankableByIds`（从按能力分开的序列回填）；主页计数 `countPublicPublishedByAuthor`（AD-7 未列，视频帖本就公开，不泄露私密信息）。

## Acceptance Criteria

1. **App 能力头【L0】** `ClientInfoInterceptor` 给每个 API 请求加 `X-App-Capabilities: video`；OSS 直传（独立 Dio，不挂该拦截器）不带。
2. **只在 Controller 解析【L0 评审项】** `shared/web/ClientCapabilities`：从请求头解析逗号分隔的小写能力名（大小写不敏感、去空白、未知值忽略）→ `boolean includeVideo`；Controller 层取得后作为**显式参数**传给服务 / 仓库。服务层不注入请求级 bean。
3. **列表出口在查询里过滤【L1】** 不带视频能力时，以下查询的 WHERE 加 `(:includeVideo = true OR p.mediaType = IMAGE)`：推荐候选池 `findRankCandidatePool`、科普池 `findEduCandidatePool`、作者本人置顶插入 `findOwnPendingPosts` / `findOwnRecentPosts`、降级回落与分类 Tab `findFeed`、关注流 `findFollowingFeed`、他人主页 `findPublicPostsByAuthor`、我的发布 `findMyPosts`。禁止内存过滤、禁止读序列时过滤。
4. **单条出口 404【L1】** 不带视频能力时：详情 `GET /content-posts/{id}`、点赞人 `GET /content-posts/{id}/likers`、评论 `GET /content-posts/{id}/comments`、回复 `GET /comments/{parentId}/replies`（取 parent 所属帖子）、App 内分享 `GET /public/shared-posts/{token}` —— 视频帖统一 404「这条内容已不存在」（与已删除一致）。
5. **顶置例外【L1】** `loadPinnedSlot` 与首页让位 `pinnedContentIdToYield`：按 id 取出后判断，旧版遇到视频帖 → 视为没有顶置（坑位为空、首页不让位）。
6. **推荐序列按能力分开【L0 + L1】** 序列缓存键 `feed:seq:{ns}:v{0|1}:{seed}`；**namespace 不变**，曝光记录 `FeedSeenStore`（`feed:seen:{ns}`）不拆分。同一用户新旧两版互不串用。
7. **分页不异常【L1】** 旧版连续翻页不出现空页、不提前「没有更多了」（过滤在 SQL 里、序列按能力生成，天然满足）。
8. **带视频能力时各出口照常返回视频帖【L1】**。

## Dev Notes

### 必须保留

- **一致性规则 2**：能力只在 Controller 解析，作为显式参数传下去；服务层不注入请求级 bean（服务可能在请求线程外被调用）。
- **一致性规则 3**：视频过滤写在 SQL / JPQL 的 WHERE 里；禁止内存过滤、禁止读 Redis 序列时过滤；唯一例外是按 id 取单条的顶置。
- **序列键只改 seq，不改 namespace**：`FeedSeenStore` 曝光记录不拆分。
- 详情等单条出口的 404 文案与已删除完全一致（防枚举、与 UJ-3 一致）。
- 未知能力值忽略；只认 `video`。

### 现状（已读过）

- `FeedService`：`loadFeed`（ALL → `FeedRecommendationService.page`；其他 → `chronoFeed` → `findFeed`）、`loadFollowingFeed`、`userPublicPosts`、`myPosts`、`loadPinnedSlot`、`pinnedContentIdToYield`。
- `FeedRecommendationService.page` → `generate`（`findRankCandidatePool`、`findEduCandidatePool`）、`findOwnPendingPosts`（:176）、`ownRecent`→`findOwnRecentPosts`（:254）；序列 `FeedSequenceStore.key = feed:seq:{ns}:{seed}`。
- `ContentDetailService.requireVisiblePost` 被详情、点赞人复用；`CommentQueryService` 走自己的可见性判定。
- `ClientInfoInterceptor`（1.3.4）已加 `X-App-Version` / `X-App-Platform`。
