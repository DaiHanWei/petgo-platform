# Story 2.6：视频帖的 H5 分享页

Status: review

> 专题线 video · Epic 2 · 只改后端模板（+ Controller 组装模型）。分支 `feat/video`。依赖 2.1（`SharedPostResponse` 下发 `mediaType` / `video`）、2.2（H5 页按 `includeVideo=true` 取帖）。
> 权威顺序：决策日志-video.md > PRD-video.md > architecture-video-delta.md > epics-video.md。

## Story

As a 拿到分享链接的人，
I want 在网页上看到视频帖的封面，并被引导去 App 里观看，
so that 我知道这是一个视频，以及怎么看到它。

**范围**：FR-19；架构 AD-11（H5 部分）；决策 V-14（网页内不播放）、V-37（分享页提示更新）。

## Acceptance Criteria

1. **视频帖【L1 + L2 浏览器】** `GET /c/{shareToken}`（`content_share.html`）遇到视频帖：显示**封面**（`imageUrls[0]`）+ **播放角标** + 时长（`m:ss`）、正文，以及提示「需更新到最新版 App 观看」（印尼语，页面语言恒印尼语）；**网页内不播放**（页面里没有 `<video>`，也不输出视频地址）。
2. **跳转【L2】** 底部按钮文案改为「在 App 中观看」（印尼语）；行为沿用现有逻辑：先用 `tailtopia://post/{token}` 尝试拉起 App，失败再按平台跳商店（商店地址沿用现有 `petgo.card.ios-url` / `android-url` 配置）。
3. **图文帖【L1】** 与改动前完全一致（模型属性、模板输出不变）。

## Tasks / Subtasks

- [x] **T1 Controller**：`ContentSharePageController.sharedPost` 增加模型属性 `isVideo`、`videoCoverUrl`、`videoDurationLabel`；视频帖的 `hasImages=false`（不渲染图片列表）、`downloadCta` = 「Tonton di aplikasi」。图文帖属性与改动前一致。
- [x] **T2 模板**：`content_share.html` 加视频封面块（封面 + 居中播放角标 + 右下时长）与升级提示条；不加 `<video>`、不输出视频 URL。
- [x] **T3 测试**：L0 `ContentSharePageControllerTest`（mock 服务）：视频帖属性 / 图文帖属性不变；L0 模板渲染（Thymeleaf 独立引擎渲染 `content_share.html`）：视频帖含封面与提示、不含 `<video` 与视频地址；图文帖不含视频块。L1 `ContentShareIntegrationTest` 补一条视频帖分享页用例。
- [x] **T4 收尾**：`mvn -B clean package`（云端 `-DskipTests` + 纯单元测试）。本 Story 无迁移。
