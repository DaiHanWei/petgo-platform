# Story 2.3：列表里的视频卡片

Status: review

> 专题线 video · Epic 2 · 只改 App。分支 `feat/video`。依赖 2.1（DTO 下发 `mediaType` / `video`）、2.2（能力头）。
> 权威顺序：决策日志-video.md > PRD-video.md > architecture-video-delta.md > epics-video.md。

## Story

As a 用户，
I want 在推荐流和主页里一眼认出视频帖，
so that 我知道点进去可以看视频。

**范围**：FR-14、FR-21（曝光部分）；架构 AD-10；决策 V-18（列表不自动播放）。
**不在范围**：全屏播放页与播放埋点（2.4）；播放页互动（2.5）；H5 分享页（2.6）。

## Acceptance Criteria

1. **模型解析【L0】** `FeedItem`、`ContentDetail`、`SharedPost` 增加 `mediaType`（`IMAGE` / `VIDEO`，缺省或未知值 → 按图文处理）与 `video{url,durationMs,width,height}`（`VideoInfo`，可空）。判断视频帖一律用 `isVideo`（= `mediaType == 'VIDEO'`），**不用 `video != null`**；`isVideo` 但缺 `video` 字段时按图文降级（不崩）。
2. **卡片角标【L0 widget + L2】** 推荐流（含分类 Tab）、关注流（`MasonryCard`）、他人主页 / 我的发布（`PostGridTile`）、顶置卡（`MasonryCard` 顶置分支）渲染视频帖时：显示封面缩略图（沿用现有首图加载，不加载原图），叠加**播放角标**与「分:秒」时长（`75000ms → 1:15`，`48000 → 0:48`）；**不自动播放**；卡片比例沿用首图规则（`imageSizes` 即视频显示宽高，超范围居中裁切 —— 复用现有 `FeedImage`，不改图片区结构，角标作为叠加层）。
3. **曝光埋点【L0】** 视频卡片露出一半以上时，同一次刷新内**第一次**满足即上报 `video_card_shown{post_id, source}`，同一次刷新内不重复；下拉刷新 / 重新加载后重新计。埋点名按仓库规范（动作在词尾、属性 snake_case），架构 AD-10 的 `video_card_impression{postId,source}` 依 cloud-rules 改名。
4. **点击跳转【L0 + L2】** 点视频卡片 → `/content/:id?src=<source>`，`extra` 带 `VideoRouteExtra(mediaType: VIDEO, source)`；图文帖跳转与现在完全一致。从播放页返回后列表停在原滚动位置（push，不重建列表）。
5. **source 取值** `feed | category | following | profile | my_posts | pinned`（本 Story 涉及的列表；`notification | push | share | other` 由 2.4 处理，缺省 `other`）。

## Dev Notes

### 必须保留

- **判断视频帖只看 `mediaType`**（架构「格式」节）。
- **列表不自动播放**（V-18），列表只加载封面缩略图。
- **不改 `FeedImage` 图片区结构**（AD-8 Rule 6 的旧约定）：角标做成外层叠加。
- 埋点走 `Analytics.capture`，事件名 / 属性名过 `v112_events_test` 规范；不带 PII、不带 URL。
- 不新增依赖（可见性检测自写，不引入 `visibility_detector`）。

### 现状（已读过）

- `FeedItem.fromJson` 容忍缺字段；`FeedItem.copyWith` 只开放计数类字段，其余原样带。
- 列表点击：`home_page.dart:260/284`、`following_tab_view.dart:85`、`me_page.dart:537`、`public_profile_page.dart:642` 都是 `context.push('/content/${id}')`。
- `MasonryCard` 图片区 `FeedImage(urls, declaredSize, sizes, cropOffsets, topRight: pinnedBadge, bottomLeft: decorTag)`。
- `PostGridTile` 只有 `firstImageUrl` / `type` / `isPrivate`。
- 埋点规范：`test/analytics/v112_events_test.dart`（`video_` 前缀已登记；`_shown` 在允许后缀表）。
