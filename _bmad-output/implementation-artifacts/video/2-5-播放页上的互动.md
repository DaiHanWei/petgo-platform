# Story 2.5：播放页上的互动

Status: review

> 专题线 video · Epic 2 · 只改 App。分支 `feat/video`。依赖 2.4（`VideoPostPage` 的 `overlayBuilder` 插槽、`focusComments` 透传）。
> 权威顺序：决策日志-video.md > PRD-video.md > architecture-video-delta.md > epics-video.md。

## Story

As a 用户，
I want 在看视频的时候点赞、评论、分享、关注作者，
so that 我能像对图文帖一样参与互动。

**范围**：FR-16；架构 AD-10（复用详情页的作者区、互动、评论抽屉组件）；决策 V-13。
**不在范围**：播放器本身（2.4）。

## Acceptance Criteria

1. **叠加层【L0 widget + L2】** `VideoPostPage` 叠加层显示：
   - 左下：作者区（头像 + 昵称 + 运营标签，点击进完整主页；注销作者不可点）、关注按钮（自己的帖 / 已注销 / 封号不显示，规则同详情页）、正文（含可点 @，后端算好可点性）；
   - 右侧竖排：点赞（`LikeButton`，点数字打开点赞人抽屉）、评论（带评论数）、分享（`DetailShareCardButton`）、「···」更多（作者本人 → 删除；他人 → 举报，与图文帖详情页同一个底抽屉与流程）。
   - 白色文字 + 底部渐变遮罩，保证在视频上可读；不遮挡进度条与静音按钮。
2. **评论抽屉【L2】** 点评论图标 → 底部弹出评论抽屉（`CommentSection` + `CommentComposer`），**视频继续播放**；关闭后回到播放状态；键盘弹出时输入框在键盘上方（`KeyboardInset`）。`?focus=comments` 进入时自动打开一次。
3. **游客【L0 + L2】** 游客可以播放；点赞 / 评论 / 关注沿用现有登录墙（组件自带，不另写）。
4. **复用不重写【L0 评审项】** 「···」底抽屉与删除确认从详情页抽成公共函数（`showContentMoreSheet`），图文详情与视频页共用；作者区抽成可复用组件（亮 / 暗两种配色），图文详情页渲染结果不变。
5. **计数回写**：点赞 / 评论后回写 Feed 快照（沿用 `syncFeedCounts` / `commentsRefreshProvider` 现有链路）。
