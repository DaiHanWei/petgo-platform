# Story 7.1: B1 内容管理 + 详情抽屉

Status: review

> 自包含 story。与用户沟通用中文。纪律见根 `CLAUDE.md`（后端→前端→联调、AC 标 L0/L1/L2、`mvn -B clean package`）。
> 依赖 Story 2.3a（`HxRequest` / `AdminBusinessExceptionAdvice` / `AdminExportWriter` / `AdminTime`）与 2.3b（`tpl-b-list` 壳、`admin-drawer.js`）。**端点与参数零变更**，只重排渲染层；唯一后端改动是新增摘要条聚合查询与抽屉 fragment 端点（GET），以及导出改走 `AdminExportWriter`。

## Story

As a 运营，
I want 内容管理列表点行就在右侧抽屉看全文、数据、物种归属、限流并直接处置，
so that 不再跳独立详情页。

## Acceptance Criteria

**AC1 · 模板 B 壳与筛选栏**
**Given** `/admin/content` 套 `tpl-b-list`
**Then** 筛选栏保留现状全部条件：类型（Diary/Moment/Tips）· 作者 ID · 状态 · 日期口径（发布日 / 点赞日）· 起止日期 · 关键词 · 物种 · 物种来源；下拉即选即查（data-autosubmit），**文本搜索配显式「查询」钮** `[L2]`
**And** 筛选参数名与现状 `type / authorId / status / dateBasis / from / to / q / species / speciesSource` 逐字不变 `[L1]`

**AC2 · 摘要条**
**Then** 筛选栏下方摘要条 5 个数字：总帖数 · 今日新增 · 审核中 · 限流中 · 已下架，**随当前筛选联动**，单条 `COUNT(*) FILTER (WHERE …)` 聚合查询实现 `[L1]`
**And** 「今日」按 WIB 自然日 `[L1]`

**AC3 · 表格**
**Then** 列 = ID ｜ 类型 ｜ 作者 ｜ 正文预览 ｜ 图片（首图缩略）｜ 点赞数（口径随 dateBasis）｜ 浏览次数 ｜ 浏览人数 ｜ 评论数（可排序）｜ 创建时间 ｜ 状态 ｜ 限流标记（`content.throttle_view` 可见）｜ 物种 ｜ 推导来源；默认创建时间倒序，每页 20，行高 ~48px，状态用色点 + 文字徽标 `[L2]`
**And** 现状列一个不少（含 bug 20260828 加的点赞/浏览列与「取代内容统计页」的口径注释语义）`[L1]`

**AC4 · 详情抽屉吸收 `content-detail`**
**When** 点行 → `GET /admin/content/{postId}/drawer`（`HX-Request` 返 fragment）
**Then** 抽屉 480px 内容按序：① 内容全文 + 全部图片（点开大图）② 数据卡：作者（注销置灰 + 原 id）/ 发布时间 / 点赞数 / 评论数 / **浏览次数 / 浏览人数**（现状 `content-detail` 字段全保留）③ 物种归属卡：当前物种 + 推导来源 + 覆写下拉（含「清除覆写」；真实用户内容只读）④ 限流卡：当前限流态（粒度 / 到期 WIB / 永久）+ 限流面板（粒度：仅本条 / 该账号全部 × 期限 7 天 / 30 天 / 永久，chips 常驻未选全禁用）/ 解除 ⑤ 评论区（一级 + 展开二级，分页，状态徽标）⑥ 底部固定操作条 `[L2]`
**And** 现状 `content-detail.html` 与 `GET /admin/content/{postId}` 整页路由**删除**，不做跳转（D-23）；`AdminContentDetailIntegrationTest` 改为断言 drawer fragment `[L1]`

**AC5 · 操作（端点与参数零变更）**
| 按钮 | 端点 | 权限 | 确认 | 成功后 |
|---|---|---|---|---|
| 下架（需 reason） | `POST /admin/content/{id}/takedown` | `content.proactive_takedown` | data-confirm 复述对象与后果 | 200 + 行 oob 刷新 + 抽屉刷新 |
| 恢复 | `POST /admin/content/{id}/restore` | `content.restore` | 无 | 同上 |
| 物种覆写 / 清除 | `POST /admin/content/species`（支持批量，参数 `postIds` / `species`） | `content.proactive_takedown` | 无 | 抽屉物种卡刷新 |
| 限流 | `POST /admin/throttles`（`postId` / `scope` / `duration`） | `content.throttle_manage` | 无（参数常驻） | 抽屉限流卡 + 行刷新 |
| 解除限流 | `POST /admin/throttles/lift` | `content.throttle_manage` | 无 | 同上 |
**Then** 全部走 htmx（AD-9）：成功 200 + fragment + `hx-swap-oob` 行；失败 422 操作区行内 err；权限不足按钮禁用 + 注明所缺权限名 `[L1]`

**AC6 · 边界**
**Then** 审核中（UNDER_REVIEW）帖抽屉注明「不可下架，走 A1 送审队列」，下架钮禁用 `[L2]`
**And** 作者注销：列表与抽屉作者列置灰 + `#id` `[L2]`
**And** `?open=<postId>` 打开页面自动开该抽屉（Story 8.1 用户详情「发布内容」页签跳转靠它）`[L2]`

**AC7 · 导出走 `AdminExportWriter`**
**Then** `GET /admin/content/export.csv` 路径、参数、权限 `content.list_export` 不变；实现改用 `AdminExportWriter`（RFC 4180 转义、前导 `=` 防注入、表头随 locale、保留 UTF-8 BOM），列与现状一致 `[L1]`

**AC8 · 三语与回归**
**Then** 新增 key 走 `admin.v130.content.*`，三包同批；`AdminContentManageIntegrationTest` / `ContentSpeciesIntegrationTest` / throttle 相关测试全绿；新增 MockMvc 四条（整页 200 / drawer fragment / 422 / 403）`[L0/L1]`
