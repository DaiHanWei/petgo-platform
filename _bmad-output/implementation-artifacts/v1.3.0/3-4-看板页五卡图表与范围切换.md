# Story 3.4: 看板页五卡图表与范围切换（AB-15A 前端）

Status: review

> 自包含 story。与用户沟通用中文。执行纪律见根 `CLAUDE.md`。
> 后端 Controller + Thymeleaf fragment + Chart.js 静态文件 + 一个 JS 文件。依赖 2-3a（fragment 响应约定 / `HxRequest`）与 2-3b（模板 C 壳）；若二者未合入，本 story 可先用最小内联壳实现并在 Completion Notes 标注「待套 tpl-c」。

## Story

As a 运营，
I want 首页五张图表卡按日展示 18 项指标，可切 7/30 天、切口径，缺数据日显示断点，
so that 每天开工先看趋势。

## Acceptance Criteria

**AC1 · 页面结构**
**Given** `GET /admin`（`/admin/dashboard` 同）套模板 C
**Then** 自上而下：范围切换器（近 7 天默认 / 近 30 天）→ 五卡（用户增长 / 建档转化 / 内容生产 / 互动质量 / 付费）→ 底部「当前时点总量」摘要行（复用 `AdminDashboardService.overview()` 九个数字，紧凑一行）+ 「发布种子内容」链接 `[L2]`
**And** 原 `dashboard.html` 四模块表格替换，`admin.dashboard.*` 既有 key 保留给摘要行复用 `[L1]`

**AC2 · 图表数据 fragment**
**Given** `GET /admin/charts?range=7|30`（`HX-Request`）
**Then** 返回 `fragments/dashboard-charts.html`：五卡容器 + 每卡一个 `<script type="application/json" data-chart="<cardId>">`，JSON 结构 `{"labels":["2026-09-01",…],"series":[{"key":"new_users","scope":"ALL","values":[12,null,9,…]}]}`；`labels` 为范围内**每一天**（WIB，含无数据日），无数据日 `values` 为 `null` `[L1]`
**And** 非 htmx 请求整页 `/admin` 首屏内嵌同一 fragment（默认 7 天）`[L1]`
**And** 取数只读 `ops_daily_metrics`，不实时算 `[L0]`

**AC3 · Chart.js**
**Then** `static/admin/vendor/chart.umd.min.js`（Chart.js **4.5.x**，MIT）仅在看板页 `<script defer>` 引入；`static/admin/admin-charts.js` 监听 `htmx:afterSwap`（target 为图表区）：销毁旧 `Chart` 实例 → 读各 `data-chart` JSON → 按卡类型建图 `[L2]`
**And** 图形：新增柱状 / 累计折线（双轴）；两个平均分折线；付费人数 & 次数双序列柱；`spanGaps:false` 使 null 成断点 `[L2]`
**And** 无 CDN 外链（CSP 不放行）`[L0]`

**AC4 · 卡内 tab**
**Then** 内容生产卡、互动质量卡 tab「真实用户 / 含种子」默认真实用户（D-29）；付费卡 tab「现金到账 / 含 PawCoin 消费」默认现金到账；tab 切换纯前端切 series（JSON 已含两口径），不再请求；口径差异提示常驻卡底 `[L2]`

**AC5 · 状态**
**Then** 缺数据日断点带黄色标注；整卡无数据显示空态（与断点区分）；范围切换期间卡显示骨架（`hx-indicator`）；fragment 请求失败卡内显示重试按钮，不整页报错 `[L2]`

**AC6 · 文案**
**Then** 每指标名 + hover/图标口径提示，key `admin.v130.dashboard.metric.<key>.name / .hint`，三语；「累计注册用户数」（D-16）；次日留存一行说明 +「去 PostHog 查看」文案（`admin.v130.dashboard.retentionNote`，无外链）`[L2]`

**AC7 · 回归**
**Then** MockMvc 四条：整页 200 含 `data-chart`；`HX-Request` 返 fragment；`range=99` → 422 fragment；无登录 302 `[L1]`

## Dev Notes

### 🔴 数据只从长表读，图表数据内嵌 fragment，不开 JSON API

AD-9/AD-11 明示。切换 7/30 由 htmx 替换整块图表区，JSON 随 fragment 回来，`htmx:afterSwap` 重建图。这样后端只有一条 fragment 端点，且与模板 A/B 的响应约定一致。

### 🔴 null 与 0 必须区分

口径里「当天新增用户 0 人」是合法的 0；「该日尚未物化」才是 null → 断点。取数时只对**不存在行**填 null，存在行即使 value=0 也照传 0。`spanGaps:false` 让折线在 null 处断开、柱状自然无柱；断点黄标注用 Chart.js 默认能力 + 卡底文字「N 日缺数据」实现，不引插件。

### 🔴 Chart.js 引入

- 版本 4.5.x（09-09 联网核实 4.5.0/4.5.1 为最新稳定线），UMD 单文件全局名 `Chart`，无依赖；只在看板页引入（`layout.html` 不加）。
- CSP 若已收紧 `script-src 'self'`，vendored 同源即可；`<script type="application/json">` 不执行、不受 CSP 影响。
- 静态资源指纹化：`th:src="@{…}"` 经 `ResourceUrlEncodingFilter` 改写为带 md5 的 URL（bug 20260901-471 经验），写死路径会 404。

### 🔴 底部摘要行复用现有 `overview()`

`AdminDashboardService.overview()`（9 个数字：总用户 / 虚拟账号 / 兽医咨询单 / AI 完成单 / AI 收入 / 帖子 / 评论 / 兽医 / 待打款月结）原样复用，只改展示为一行紧凑数字；既有 `admin.dashboard.m.*` key 继续用；「发布种子内容」链接保留。
