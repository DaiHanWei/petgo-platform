# Story 8.2: B8 用户标签（与内容标签同构，分配入口收进抽屉）

Status: review

> 自包含 story，可本地或云端 L0 执行。与用户沟通用中文。执行纪律见根 `CLAUDE.md`。
> **零端点变更**：五个写端点路径 / 参数不动；页面重构 + 两条 PRD 例外（§5 ③ 第 4 条「分配入口收进抽屉、独立批量分配按钮废除」、第 9 条「标签码自动生成不可填 + 分配记录补起止时间与生效/到期状态列」）。依赖 2.3a / 2.3b。

## Story

As a 运营，
I want 用户标签页只有一张标签表，点一个标签进抽屉就能改它、看它分给了谁、直接加人，
so that 给用户挂标签的动线和内容标签一样，不用在三块区域之间来回找。

## Acceptance Criteria

**When** 打开

**AC3 · 抽屉页签二「分配记录」**
**Then** 列 **用户 ｜ 分配时间 ｜ 起止时间（WIB，结束空 = 永久）｜ 状态（生效中 / 已到期 / 隐藏原因）｜ 操作人 ｜ 移除**；数据源 `UserAssignmentRow`（startsAt / endsAt / visible / hiddenReason），状态由 `now` 与 startsAt/endsAt 推导；账号已注销的行显示「永不展示」并只留移除 `[L2]`

### 🔴 「分配唯一入口」是动线收拢，不是功能删除

**复审（对抗式）修掉的 7 条 CONFIRMED**

1. 🔴 **批量分配的「部分失败」提示永远看不见** —— 这条正是下面「自查修掉 #2」那次修复引入的新缺陷。
   htmx 是**先 oob、后主 swap**，而主 swap 的目标是发请求时就捕获的**节点引用**：
   `afterAction` 的 oob 把整个 `.drawer-body` 换掉之后，`#utag-assign-err` 已经脱离文档，
   那段非 oob 的失败提示写进了一个**游离节点**，界面上一个字都不出现。
   改成由**重渲染后的抽屉体自己**渲染这段提示（`#utag-assign-err` 直接 `th:text="${partialError}"`），
   并让承载它的 `<details>` 在有部分失败时展开（否则提示藏在折叠里）。
   ⚠️ 总失败那条路本来就是好的：它抛 422，advice 按 `HX-Target` 头 retarget，发生在任何 oob 之前。
   ⚠️ 对应测试原来只断言「响应字符串里有这个 id」= 假绿，改成断言**位置**（提示必须落在 oob 块内部）。

**施工中自查修掉的三处**（都是会到生产的）

1. 🔴 **旧书签 `?tagId=` 原本一声不响什么都不做**。第一版按 B1～B6 的惯例渲染
