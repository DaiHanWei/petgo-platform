## 0 · 基线 v2（AC1 / T1：为什么换基线）

Story 2.1 的生成器只扫 `com/tailtopia/admin/**`。但 admin 包**之外**也有挂 `/admin/**` 的 Controller：

| 端点 | 类 | 为什么在包外 |
|---|---|---|
| `POST /admin/name-moderation/{recordId}/decide` | `namemoderation/web/NameModerationAdminController` | 名称审核的处置端点由统一复核工作台以 htmx 调用（Story 2.4），归属 namemoderation 模块 |

基线 v1（134 条）**漏了它**，而且漏得很安静 —— 行数自检 `grep -rhoE '@(Post|Put|Delete)Mapping\('` 数的是同一个目录，少一行两边同时少，自检恒等。

同一轮还修了第二个静默漏抓：`@PostMapping(ROUTE + "/{id:\\d+}/edit")` 这种**常量拼接路径**（`AdminPlaceController` 8 条、`AdminWarmReplyController` 2 条）原来只抓到后半截 `"/{id:\d+}/edit"`，不以 `/admin` 开头 → 整条端点被丢掉。修法是路径也走 `@PreAuthorize` 那套常量展开，并把 Java 字面量的 `\\d+` 还原成 `\d+`。**这一条会让 after 少 10 行**，是本 story 唯一一次「机器证据本身出错」。

同一轮还修了第三处口径错误（不影响行数，影响可读性）：**退役标记按路径匹配、不看方法**，于是 `POST /admin/vets/{id}/qualification`（11.3 AC1「勿误删」名单里的端点）在底账里带着「⛔ 本版退役」的备注 —— 读的人拿到一个自相矛盾的口径。脚本原来只为 `vets/{id}/edit` 单独绕过这个坑，绕的是个例不是这一类。现改为**退役标记只贴 GET**；另把 `GET /admin/vets/{id}/qualification`、`GET /admin/vets/{id}/ratings` 的备注从 ⛔ 改为 🔄「整页退役、路径保留（改为抽屉页签片段）」—— 写成 ⛔ 会让人以为该删，删了抽屉页签就空了。

复审又逼出两处**守门本身失效**（都实测复现过，修完重跑）：

- 🔴 **扫描根按包名写死** → admin 包外新增的 `/admin` 端点完全隐形。前面那条 namemoderation 的修法只是把一个目录加进名单，没有把「按路径判定而不是按目录判定」做掉：新建 `com/tailtopia/<任意>/XxxAdminController` 加个 `POST /admin/users/{id}/nuke`，既不进清单、不进自检、也不触发任何 `::error::`，CI 恒绿（实测）。现改为**扫全树、按 `^/admin` 过滤**（`/api/v1` 由这道过滤挡掉），自检也改成**逐文件**「解析行数 ≥ 映射注解条数」——全局比总数时，「这里多两行、那里漏两行」会互相抵消。
- 🔴 **`@PreAuthorize` 里出现 `|` 时权限漂移检测被绕过**。生成表格时把 `|` 转义成 `\|` 保护 markdown，但 `--baseline` 回读按 `|` 切列，`\|` 照样当分隔符 → 权限表达式在第一个 `|` 处被**截断**，后半截永不参与比对。实测：把某处置端点的授权从 `hasRole('SUPER_ADMIN') || hasAuthority('content.takedown')` 放宽成 `|| hasAuthority('ANYTHING_GOES')`，守门**全绿**。SpEL 的 `||` 与 `or` 等价，随时会有人写。现改为写表时转成 HTML 实体 `&#124;`、回读时还原。
- 顺带：`@PatchMapping` 原来完全不在口径内（团队在 `/api/v1` 侧已在用）；写端点缺 `@PreAuthorize` 现在直接报错；`@PreAuthorize` 的**跨类常量**（`OtherController.MANAGE_AUTH`）现在也展开成 SpEL 原文 —— 之前那一行留的是 Java 表达式，「原文逐字一致」对它并不成立，且只被跨类引用的常量改了值不会产生任何 diff。

所以本 story 按 Dev Notes 的要求**用 v2 脚本重跑基线提交 `7a160d0`**，产出「基线 v2」并入库；v1 基线保留不删（历史留痕），但**不再用于 diff**。

|---|---|---|
| 基线 v1（Story 2.1，`7a160d0`） | 134 | 84 |
| **基线 v2（同一提交，v2 脚本）** | **135** | **84** |
| after（`4e15b5fe`） | **150** | **117** |
