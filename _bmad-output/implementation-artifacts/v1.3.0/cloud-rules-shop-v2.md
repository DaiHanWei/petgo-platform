
主题专属追加规则（shop-v2 · 电商板块 V2）：

  - `1-2`（埋点护栏与环境标记）**必须先于** `1-4`（App 支付埋点）。
  - `3-1`（客服号配置化）与 `3-2`（工单关联电商订单后端）**都先于** `3-3`（App 选订单 + 深链）。
