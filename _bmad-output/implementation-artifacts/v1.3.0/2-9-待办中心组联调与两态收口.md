# Story 2.9: 待办中心组联调与两态收口

Status: ready-for-dev

> 自包含 story。与用户沟通用中文。执行纪律见根 `CLAUDE.md`。本 story 不新增功能，是 2-4～2-8 五页的**联调与一致性收口**；暖贴跟进（A9，第 6 页）由 Story 4.4 接入同一机制。

## Story

As a 运营，
I want 待办中心五页的计数、角标、空态、权限禁用态口径完全一致，
so that 组名上的数字就是我今天要处理的量，清空即真清空。

## Acceptance Criteria

**AC1 · 计数三处同源**
**Given** 五页均已套模板 A
**When** 任一页处置成功
**Then** 侧导航组角标（`GET /admin/nav/badges`）、组内各项计数、页内页签计数三处同值，均来自 **一条聚合查询**（`AdminNavController` 复用各页 Service 的 `count(state=pending)`），处置后经 `HX-Trigger admin:badge-refresh` 即时刷新 `[L1]`
**And** 组名角标 = 五项（4.4 后为六项）待处理之和 `[L1]`

**AC2 · 两态统一**
**Then** 五页左栏顶部「待处理｜已处理」页签同构：已处理 = 结果徽标 + 操作人 + 时间 + 理由，可按结果 / 时间 / 关键词筛；只读，无处置按钮（A4 例外：备注仍可追加）`[L1]`

**AC3 · 空态与去向**
**Then** 某页签清空 → 空态插画 +「队列已清空 🎉」+「其他队列还有 N 条」并给各队列去向链接（N 来自 AC1 同一查询）`[L2]`

**AC4 · 权限态一致**
**Then** 五页：登录者无该页任一查看权 → 导航项不渲染；有查看权无处置权 → 操作区按钮禁用并注明所缺权限的中文标签（不露 code，标签与角色矩阵面板同源 `AdminPageCatalog`）`[L1]`
**And** 五页的 `sec:authorize` 表达式与各 Controller 的 `@PreAuthorize` 常量**逐字一致**（写一条测试遍历 `AdminPageCatalog` 比对）`[L1]`

**AC5 · 状态色点与相对时间**
**Then** 🔵 待处理 · 🟡 处理中 / 等待外部 · 🔴 超时 / 高优 · ⚪ 终态 四语义在五页映射一致；相对时间与绝对时间（WIB，`AdminTime`）格式一致 `[L2]`

**AC6 · 窄屏与失败态**
**Then** <1024px 五页均降级为列表 / 详情两屏切换；处置失败 422 行内 err 不跳条、不弹整页；五页均无键盘 ↑/↓（D-14）`[L2]`

**AC7 · 测试、三语、写操作底账**
**Then** 五页各四条 MockMvc 齐全；`check-i18n-keys.sh` 三包相等；切 ID 语言五页无截断 `[L0/L2]`
**And** 运行 `scripts/ci/list-admin-write-ops.sh` 与 Story 2.1 基线 diff：写端点仅 `tickets/warn` 多 `reason` 参数，无删除；退役的 GET 页面路由 = `reports`、`tickets/detail`、`anomalies/{id}`、`support-tickets/{token}`、`refunds/{token}` 五条 `[L0]`

## Dev Notes

### 角标查询的形状
一条 SQL / 一次 Service 调用返回 `Map<pageKey, count>`；不要五个 Controller 各查一次再拼——那样五页与角标必然漂移。`AdminNavController` 在 2-3a 建壳，本 story 填内容。
