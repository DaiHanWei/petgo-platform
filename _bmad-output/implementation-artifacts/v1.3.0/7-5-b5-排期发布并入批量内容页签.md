# Story 7.5: B5 排期发布并入批量内容页签

Status: review

> 自包含 story。与用户沟通用中文。纪律见根 `CLAUDE.md`。依赖 2.3a / 2.3b。写端点 `content-schedules/{rowId}/time` 与 `/cancel` 零变更；变化是 GET 页面 `/admin/content-schedules` 退役、内容并入批量内容页第二页签、POST 成功后重定向目标改为批量内容页页签。

## Story

As a 运营，
I want 在「批量内容」页第二页签直接看排期、改时间、取消，
so that 发完一批不换页就知道什么时候发、发没发。

## Acceptance Criteria

**AC1 · 页签结构**
**Given** `/admin/seed-batches`
**Then** 页顶两页签「批次」｜「排期发布」（htmx 局部切换 `#batches-tab`）；现状页尾用 `th:replace="~{admin/content-schedules :: scheduleSection}"` 内嵌的排期区块**改为第二页签内容**，不再与批次表同屏堆叠 `[L2]`

**AC2 · 排期页签内容（模板 B）**
**Then** 摘要条：待发布 · 今日已发（WIB）· 失败；筛选：发布账号 `authorId`（现状有）· 状态 · 日期；表格列 = 内容摘要 ｜ 发布账号 ｜ 计划时间（WIB）｜ 状态 ｜ 失败原因 ｜ 操作；默认计划时间升序；每页 20 `[L1/L2]`
**And** 失败行红点 + 原因悬浮完整展示；已发布行只读 `[L2]`

**AC3 · 改时间 = 行内编辑态**
**When** 点「改时间」
**Then** 该行变为 WIB 日期时间输入 + 保存 / 取消（不弹层，UI 稿 2-23 注记 2026-09-02）→ `POST /admin/content-schedules/{rowId}/time`（参数不变）→ htmx 返回该行 fragment `[L1]`

**AC4 · 取消**
**Then** `POST /admin/content-schedules/{rowId}/cancel`，data-confirm（`admin.schedule.cancelConfirm` 沿用）→ 行 oob 刷新 + 摘要条刷新 `[L1]`

**AC5 · 详情抽屉**
**When** 点行（非操作区）→ `GET /admin/content-schedules/{rowId}/drawer`
**Then** 完整内容预览（正文 + 图缩略 + 发布账号 + 类型 + 物种）+ 排期信息 + 操作条 `[L2]`

**AC6 · 独立页退役**
**Then** `GET /admin/content-schedules` 页面路由与 `content-schedules.html` 整页部分删除；`scheduleSection` fragment 迁为 `fragments/schedules-tab.html`；两个 POST 非 htmx 时重定向到 `/admin/seed-batches?tab=schedules`（带筛选参数回传）`[L1]`
**And** 导航无独立项（现状已无）；不做旧地址跳转（D-23）`[L1]`
**And** `SeedScheduleIntegrationTest` 中 6 处打 `GET /admin/content-schedules` 的用例改为 `GET /admin/seed-batches?tab=schedules`（或 htmx `GET /admin/seed-batches/schedules` fragment）`[L1]`

**AC7 · 三语与回归**
**Then** `admin.v130.schedules.*` 三包；`SeedScheduleIntegrationTest`、`SeedBatchListVisibilityIntegrationTest` 全绿；四条 MockMvc `[L0/L1]`
