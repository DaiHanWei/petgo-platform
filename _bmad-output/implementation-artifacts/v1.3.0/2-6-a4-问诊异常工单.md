# Story 2.6: A4 问诊异常工单

Status: ready-for-dev

> 自包含 story。与用户沟通用中文。执行纪律见根 `CLAUDE.md`。纯页面重构：两个写端点路径 / 参数 / 权限零变更；`anomaly-detail.html` 与其 GET 路由退役（D-23 不做跳转）。前置：2-3a、2-3b。

## Story

As a 运营，
I want 在双栏工作台里处理问诊异常工单，看会话、加备注、标记已处理，
so that 纠纷处置不用跳独立详情页。

## Acceptance Criteria

**AC1 · 页签与左栏**
**Given** `/admin/anomalies`（`VIEW_AUTH` = SUPER_ADMIN or `consult.view_anomalies`）
**Then** 页签 = 待处理（OPEN）｜ 已处理（RESOLVED），各带计数；左栏行第一行 = 工单号 + 异常类型标签 + 状态点，第二行 = 用户昵称 × 兽医名 + 生成时间；默认时间倒序；每页 20 滚动加载 `[L1]`
**And** 现状 `?status=open|resolved|all` 筛选参数兼容映射到页签 `[L1]`

**AC2 · 右栏四区**
**Then** ① 工单卡：工单号 / 类型 / 生成时间 / 状态；② 会话卡：会话号 / 会话状态 / 起止时间 + 「去取证」链接（跳 `/admin/consult-sessions?open=<会话号>`，新开标签，Story 9.2 落地 `?open=` 自动开抽屉，本 story 只生成链接）；③ 内部备注时间线（人 + 时间 + 内容）+ 底部追加输入框；④ 操作区 `[L2]`
**And** 处理图：`resolutionImageKey` 选填输入 + 已有处理图「查看处理图」预览（现状功能原样）`[L2]`

**AC3 · 操作表（零变更）**

| 按钮 | 端点 | 参数 | 权限（现状常量） | 确认 | 成功后 |
|---|---|---|---|---|---|
| 加备注 | `POST /admin/anomalies/{id}/note` | `note` | `HANDLE_AUTH` = SUPER_ADMIN or `consult.handle` | 无 | 停留本条（时间线追加） |
| 标记已处理 | `POST /admin/anomalies/{id}/resolve` | `resolutionImageKey?` | `HANDLE_AUTH` | 无 | 下一条 |

**Then** 路径 / 参数 / `@PreAuthorize` 与现状逐字一致 `[L0]`

**AC4 · 状态流与只读**
**Then** OPEN → RESOLVED 终态入「已处理」页签，右栏只读但**备注仍可追加**（现状允许）`[L1]`
**And** 有 `VIEW_AUTH` 无 `HANDLE_AUTH` → 两钮禁用 + 注明所缺权限中文标签 `[L2]`

**AC5 · htmx 动线**
**Then** 加备注：200 + 备注时间线 fragment（局部追加，不换条）；标记已处理：200 + 右栏 fragment（`data-next-id`）+ oob 左栏行与页签计数 + `HX-Trigger admin:badge-refresh`；422 行内 err；非 htmx 维持 PRG；无键盘 ↑/↓ `[L1]`

**AC6 · 退役**
**Then** `GET /admin/anomalies/{id}` 与 `anomaly-detail.html` 删除（并入 `GET /admin/anomalies/{id}/detail` fragment）；全库无 `th:href` 指向旧路由；不做跳转（D-23）`[L1]`

**AC7 · 测试与三语**
**Then** MockMvc 四条 + 备注追加不换条断言；既有 `AdminAnomalyController` / `ConsultAnomalyService` 测试全绿；新 key `admin.v130.anomalies.*`，复用 `admin.anomalies.*`；ID 无截断 `[L1/L2]`
