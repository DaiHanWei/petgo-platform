# Story 3.2: 灯箱四个手势

Status: review

## Story

As a 用户，
I want 用手势直接操作大图，
so that 看图像用主流看图 App 一样自然。

---

> **本批次最重的一条。** 四个手势项目内无同款、`pubspec.yaml` 无任何图片查看器类/手势类第三方包，**全部自实现，且不许引包**（AD-A22）。
>
> 依赖 Story 3.1（组件外壳已就位）。
>
> 🔴 **手势优先级顺序是防冲突的全部依据** —— 三种手势都是「手指往下或往旁边划」，不定优先级必然互相抢。

## Acceptance Criteria

### AC1 — 下滑关闭（L2）

**Given** 图片未放大
**When** 单指下拖
**Then** 图片跟手移动，背景随拖拽距离渐透明 `[L2]`
**And** 超过阈值松手则关闭；未超过则回弹复位 `[L2]`

### AC2 — 放大态下滑是平移（L2）

**Given** 图片**已放大**
**When** 单指下拖
**Then** 执行图内平移，**不触发关闭** `[L2]`

### AC3 — 双击缩放（L2）

**Given** 任一张图
**When** 双击
**Then** 在「适应屏幕」与「2.5 倍」之间切换 `[L2]`
**And** 以双击点为缩放中心 `[L2]`

### AC4 — 放大态防误翻页（L2）

**Given** 图片已放大
**When** 横向滑动
**Then** 先执行图内平移 `[L2]`
**And** 平移到图片边缘后继续拖，才切换到下一张 `[L2]`

### AC5 — 🔴 优先级顺序（L0）

**Given** 手势判定实现
**When** 检视代码
**Then** 顺序严格为：**已放大→图内平移 > 到边缘续拖→翻页 > 未放大下拖→关闭** `[L0]`
**And** 该顺序不可调换 `[L0]`
**And** 有测试或注释明确钉住这一顺序 `[L0]`

### AC6 — 与单击关闭不冲突（回归保护，L2）

**Given** Story 3.1 保留的「单击图片或黑边即关闭」
**When** 本 story 的手势接入后
**Then** 单击关闭仍然有效，不被双击判定拖慢到不可用 `[L2]`

### AC7 — 不引包（L0）

**Given** `pubspec.yaml`
**When** 本 story 提交
**Then** **未新增任何第三方依赖** `[L0]`

### AC8 — 不扩散（L0）

**Then** 过渡动画与加载态不在本 story（属 3.3） `[L0]`

## Dev Notes

### 🔴 这一条的验收几乎全在真机上

「顺不顺手」是本 story 的唯一价值。编译通过、单测全绿都说明不了它能不能用。**排期务必给真机调试留出实打实的时间**，不要按 L0 绿灯就当完成。

### 常见错法

- 把下滑关闭直接挂在最外层 → 放大后想平移却把页面关了
- 双击缩放注册后没处理与单击的竞争 → 单击关闭延迟 300ms，手感变钝
- 横滑翻页与图内平移各自独立判定 → 放大态一滑就翻页

**实现要点（复审着眼处）**：

1. **优先级判定抽成纯函数** `resolveLightboxGesture`（`lib/shared/media/lightbox_gestures.dart`）。AC5 要求「有测试或注释明确钉住这一顺序」—— 测试用**真值表逐格覆盖 8 种输入组合**，顺序一旦被调换必有一行变红。三条「常见错法」各配了一条反向断言。
2. **优先级是靠「接线方式」落实的，不是靠 if 分支**：
   - 已放大 → `onVerticalDragUpdate/End` 传 `null`，纵向拖拽自然落回 InteractiveViewer 的图内平移（AC2）；
   - 未放大 → `panEnabled: false`，InteractiveViewer 不抢单指拖拽，下滑关闭才拿得到（错法①的另一半）；
   - 横向 → `PageView.physics` 在「放大且未贴边」时为 `NeverScrollableScrollPhysics`（AC4）。
3. **单击 / 双击自己仲裁**（`kLightboxSingleTapDelay = 220ms`）。`GestureDetector` 的 `onTap` + `onDoubleTap` 同时注册时，单击要等满 300ms —— 那正是 story 点名的错法②。
4. **路由改为 `opaque: false`**：AC1 的「背景渐透明」要求下层那一页参与绘制，不透明路由之下的页面根本不画，调淡黑底只会露出虚空。
5. **每页各自的 `TransformationController`**，翻页时复位离开的那一页。

**没做（属后续 story）**：Hero 飞入飞出、加载态与失败重试、`lightbox_opened` / `lightbox_dismissed` 埋点 → 全在 **Story 3.3**（有断言钉住本 story 没提前做）。
