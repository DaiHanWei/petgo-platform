# Story 7.6: E1 种子内容发布（单发）与 E2 批量工作台套模板 E

Status: ready-for-dev

> 自包含 story。与用户沟通用中文。纪律见根 `CLAUDE.md`。依赖 2.3a / 2.3b 与 7.5（批量页页签条）。本 story 是本版**唯一主动删写端点**的地方（旧轻量批量 `/admin/seed-batch*`），删除判定见 Dev Notes，结果须写进 Epic 11 的写操作清单 diff 说明。

## Story

As a 运营，
I want 单发页只保留单条发布，批量工作台四步走完有统一的步骤条与上一步/下一步，
so that 两条发布路径分工清楚、视觉一致。

## Acceptance Criteria

**AC1 · E1 单发页只留单发表单（模板 E 单步）**
**Given** `/admin/seed-post`
**Then** 保留：关联物种下拉（含「留空由算法推导」）/ 内容类型 / 正文 ≤1000 字（`maxlength=1000` 现状）/ 图片 ≤9 张单张 ≤10MB（`data-seed-file` 上传控件 + `imageUrlsRaw` / `imageSizesRaw` 隐藏域 + URL 兜底）/ 绑定宠物（`GET /admin/seed-post/pets`）/ 发布身份确认页流程（`publish-identity-confirm`，`seed.publish_as_real` 门控）`[L1/L2]`
**And** 页内「逐行批量发布」与「Excel 导入并发布」两个旧区块**删除**（`seed-post.html` 123-140）`[L2]`
**And** `POST /admin/seed-post`、`POST /admin/seed-post/images`、`GET /admin/seed-post/pets` 不变 `[L1]`

**AC2 · 旧轻量批量端点删除**
**Then** `AdminSeedBatchController`（`admin/virtual/web/`）的 `GET /admin/seed-batch`、`GET /admin/seed-batch/template`、`POST /admin/seed-batch`、`POST /admin/seed-batch/import` **删除**；其静态方法 `mayPublishAsReal(AdminUserDetails)` **迁移**到 `AdminPublishIdentityService`（或 `admin/shared`）并更新两个调用点（`AdminWebController:399`、`AdminSeedBatchWorkspaceController:366`）`[L0]`
**And** `AdminSeedBatchControllerTest` 删除；`AdminPublishIdentityIntegrationTest` 中打 `POST /admin/seed-batch` 的用例改为走 `/admin/seed-batches` 四步流或删除并说明 `[L1]`
**And** 删除的两个写端点在 Epic 11 diff 中标注「Story 7.6 有意删除，能力由 `/admin/seed-batches/**` 承载」`[L0]`

**AC3 · E2 批量工作台套模板 E**
**Given** `/admin/seed-batches/{batchId}`
**Then** 顶部步骤条：0 批次设置 → 1 素材 → 2 录内容 → 3 预览确认；当前步高亮，完成步可点回 `[L2]`
**And** 每步底部吸底操作条「← 上一步 / 下一步 →」；第 2 步有未保存编辑行时先提示保存 `[L2]`
**And** 步 1 素材：批次共用图池（上传 / 废弃 `assets/{assetId}/delete`，被行引用中的素材废弃时该行标红）+ 页顶「图片命名与引用说明」折叠卡默认展开 `[L2]`
**And** 步 2 录内容：新增空行 = **行内编辑态**（紫底高亮：正文 + 挑图 + 身份 / 时间 + 保存行 / 取消）/ 整表粘贴（`rows/paste`）/ Excel 导入（`import`，模板 `template` 六列：正文 / 图片文件名 / 发布账号 / 内容类型 / 关联物种 / 计划时间）；行级发布账号可混多账号；字段支持「继承批次默认」`[L2]`
**And** 步 3 预览确认：`GET {batchId}/preview` 校验结果列，校验不过的行标红且不可确认；点任意行 → 成帖效果抽屉（App Feed 卡片同构、多图缩略网格、可翻行）；确认 `POST {batchId}/confirm` data-confirm 复述行数 `[L2]`
**And** 全部既有端点（`settings` / `assets` / `assets/{id}/delete` / `rows` / `rows/paste` / `rows/{rowId}` / `rows/{rowId}/delete` / `import` / `template` / `preview` / `confirm`）路径参数零变更 `[L1]`

**AC4 · 批次列表**
**Then** `/admin/seed-batches` 页签一「批次」：列 = 批次号 ｜ 来源 ｜ 创建时间 ｜ 各行状态汇总 ｜ 操作；「新建批次」`POST /admin/seed-batches` 不变；页签二由 7.5 承载 `[L2]`

**AC5 · 三语与回归**
**Then** `admin.v130.seed.*` / `admin.v130.batch.*` 三包；`AdminSeedPostIntegrationTest`、`SeedBatch*IntegrationTest`（Asset / Entry / Publish / StateMachine / ListVisibility）全绿；四条 MockMvc `[L0/L1]`

## Dev Notes

### 🔴 旧批量端点删除判定（已核实）
- `/admin/seed-batch*` 四个端点在 `AdminSeedBatchController`（Story 9.8 Part 2 轻量批量：选虚拟账号 + 多行文本逐条发）。
- 模板引用**只有** `seed-post.html` 123-140（`POST /admin/seed-batch`、`POST /admin/seed-batch/import`、`GET /admin/seed-batch/template`），grep 全库无其他模板引用。
- 代码引用：`AdminWebController:399` 与 `AdminSeedBatchWorkspaceController:366` 调用其**静态方法** `mayPublishAsReal(admin)`（真实身份发布门控，与 `AdminPublishIdentityController.REAL_AUTH` 同口径，注释明写「单条发布也用这一份，刻意不各写一遍」）——删控制器前必须把这个方法迁走，否则两处编译失败。
- 测试引用：`AdminSeedBatchControllerTest`（1 个 @Test）、`AdminPublishIdentityIntegrationTest`（5 处 `post("/admin/seed-batch")`，用它验证真实身份发布门控）。后者改用 `POST /admin/seed-batches/{id}/confirm` 路径验证同一门控，或删并在 Completion Notes 说明门控已由 `SeedBatchPublishIntegrationTest` 覆盖。
- **结论：删。** 能力（多账号批量、Excel）已由 `/admin/seed-batches/**` 四步流完整承载（Story 13.1～13.5）；`AdminSeedBatchService` 若仅被旧控制器用则一并删，若被工作台复用则保留。
