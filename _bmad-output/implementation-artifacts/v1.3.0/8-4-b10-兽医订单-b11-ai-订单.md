# Story 8.4: B10 兽医订单 + B11 AI 订单（抽屉吸收详情页）

Status: ready-for-dev

> 自包含 story，可本地或云端 L0 执行。与用户沟通用中文。执行纪律见根 `CLAUDE.md`。
> **零写端点变更**：唯一写端点 `POST /admin/consult-orders/{orderToken}/verify` 不动；两个独立详情页并入抽屉后删除。依赖 2.3a（`AdminExportWriter` / htmx 约定）与 2.3b（`tpl-b-list` / `admin-drawer.js`）。

## Story

As a 运营 / 财务，
I want 兽医订单和 AI 订单两页有摘要条，点行在抽屉里看成交快照、时间线并标记核查，
so that 订单排查不用跳独立详情页，两页形态一致。

## Acceptance Criteria

**AC1 · B10 兽医订单列表**
**Given** `/admin/consult-orders` 套模板 B
**When** 打开
**Then** 摘要条 **本期成交额 · 单数 · 待核查数**（「本期」= 当前筛选集；现状无筛选则为全量，摘要条随后续筛选联动）；表格列 **订单 ｜ 用户 ｜ 兽医 ｜ 金额 ｜ 分成（兽医到手）｜ 状态 ｜ 重播 ｜ 待核查标记 ｜ 成交时间（WIB）**（与现状 `AdminConsultOrderRow` 字段一致，去掉「操作」列）`[L1]`
**And** 「导出」按钮文案改为**「导出全部」**（UI 稿 4-1 ⚠️：现状 `GET /admin/consult-orders/export` 不接收筛选参数、永远导出全表，如实标注；不做筛选导出改造）；产物由 `AdminExportWriter.csv` 生成（RFC 4180，表头随 locale），权限 `order.export` 不变 `[L1]`

**AC2 · B10 抽屉**
**When** 点行 → `GET /admin/consult-orders/{orderToken}/drawer`
**Then** ① 成交快照卡：订单号 / 用户 ID / 兽医 ID / 宠物档案 ID / 状态 / 金额 / 渠道 / 兽医到手 / 分成比例 / **单价快照**（旁注「成交时点值，与当前配置价不同属正常」）/ 重播次数 / 成交时间 / 会话起 / 会话止（全部 `@adminTime.wib`）② 阶段时间线（节点 / 时间 / 备注，空态文案保留）③ 待核查标记操作：`status` 三选（清除 / TO_VERIFY / VERIFIED）+ `note` ≤255 → `POST {orderToken}/verify`（`order.edit`）；提交走 htmx，成功刷抽屉 + oob 列表行「待核查标记」列；「退款不在此处理」提示保留 `[L2]`
**And** 无 `order.edit`：标记区按钮禁用并注明所缺权限 `[L1]`

**AC3 · B11 AI 订单列表**
**Given** `/admin/ai-orders` 套模板 B
**Then** 顶部**收入汇总六格照搬**（总收入 IDR / QRIS 现金 / PawCoin / 已完成订单数 / 待支付 / 异常（对账））作为本页摘要条，口径提示「收入 = COMPLETED 金额之和」保留；表格列 **订单 ｜ 用户 ｜ 分诊任务 ｜ 金额 ｜ 渠道 ｜ 状态 ｜ 成交时间**；「导出全部」（同 AC1 说明，`order.export`，`AdminExportWriter.csv`）`[L1]`

**AC4 · B11 抽屉（全只读）**
**When** 点行 → `GET /admin/ai-orders/{orderToken}/drawer`
**Then** 订单号 / 用户 ID / 分诊任务 ID / 金额 / 渠道 / 支付意图 token / 状态 / 成交时间 / 创建时间；「AI 一次性解锁，无退款/分成入口」提示保留；无任何操作按钮 `[L2]`

**AC5 · 退役与零变更**
**Then** 删除 `consult-order-detail.html`、`ai-order-detail.html` 与 `GET /admin/consult-orders/{orderToken}`、`GET /admin/ai-orders/{orderToken}` 两条页面路由（D-23 不做跳转）；`POST /admin/consult-orders/{orderToken}/verify`（status / note，`order.edit`）、两个 `export`（`order.export`）、两个列表 GET（`order.view`）路径 / 参数 / 权限逐字不变 `[L0/L1]`

**AC6 · 三语与回归**
**Then** `admin.v130.consultOrders.*` / `admin.v130.aiOrders.*` 三语同批；`AdminConsultOrderIntegrationTest`、`AdminAiOrderIntegrationTest` 全绿（对详情页 GET 的断言改为 drawer）；MockMvc 四条 × 2 页 `[L0/L1]`

## Dev Notes

### 🔴 「导出全部」不是退步，是如实
UI 稿 4-1 / 4-2 核实：两页 export 端点无任何筛选参数，永远全表。支付记录页（8-5）的导出是「当前结果」。本 story 只改按钮文案避免运营误解，**不加筛选导出**（未排期）。

### 🔴 CSV 走统一写入器（规则 12 / AD-10）
现状两个 `exportCsv()` 自拼字符串并各自处理引号。改为 `AdminExportWriter.csv`：RFC 4180 转义、前导 `=` 防公式注入、表头随会话 locale。响应仍是 `text/csv; charset=UTF-8` + `Content-Disposition` 原文件名。
