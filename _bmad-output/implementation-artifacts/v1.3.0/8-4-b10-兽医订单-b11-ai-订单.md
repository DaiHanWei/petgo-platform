# Story 8.4: B10 兽医订单 + B11 AI 订单（抽屉吸收详情页）

Status: review

> 自包含 story，可本地或云端 L0 执行。与用户沟通用中文。执行纪律见根 `CLAUDE.md`。
> **零写端点变更**：唯一写端点 `POST /admin/consult-orders/{orderToken}/verify` 不动；两个独立详情页并入抽屉后删除。依赖 2.3a（`AdminExportWriter` / htmx 约定）与 2.3b（`tpl-b-list` / `admin-drawer.js`）。

## Story

As a 运营 / 财务，
I want 兽医订单和 AI 订单两页有摘要条，点行在抽屉里看成交快照、时间线并标记核查，
so that 订单排查不用跳独立详情页，两页形态一致。

**复审（对抗式）修掉的 4 条 CONFIRMED**

1. 🔴 **导出 CSV 缺 UTF-8 BOM，中文表头在 Excel 里整行乱码**。表头改成随 locale 之后首行不再是 ASCII，
   而 Excel（简中 Windows）按本地代码页解无 BOM 的 UTF-8 文件 —— 正文是 token / 数字 / 枚举反而正常，
   看起来像「表头坏了」。`AdminExportWriter` 的约定本就是「BOM 由调用方拼」（内容列表导出一直这么做），
   本 story 的两个端点漏了。已在两处 `.body('﻿' + …)`，并加一条端点级回归断言
   （`bothExportsCarryTheUtf8Bom`）—— 原来两个导出测试都只调服务层，端点这一层没人看着。
2. 🟠 **toast 的外壳被 htmx 丢掉，文字裸插且永不消失**。`hx-swap-oob="beforeend:#…"` 挂在
   `<div class="toast">` 上，而 htmx 1.9.12 只有 outerHTML 语义才换整个元素，`beforeend:` 搬的是
   **子节点**（`Ee` 里非 inline swap 时 fragment 被换成元素本身，再由 `Fe` 搬 childNodes）——
   落进宿主的只有一段裸文本：没有 toast 样式，`admin-core.js` 的 `armToast` 也找不到元素，
   于是**永远不消失**，连标几单就一直堆在页脚。改为**多包一层** `<div hx-swap-oob>`（外层被丢掉，正合适）。
3. 🟠 **两处测试假绿**。① 只断言了「`id="order-row-…"` 出现过」「`id="orders-summary"` 出现过」，
   没断言这两块带 `hx-swap-oob` —— 把 `row(${row}, true)` 手滑写成 `false`，测试仍全绿，
   而实机是行与待核查数一动不动、界面**零反馈**（那堆内容会被当作主 swap 塞进
   `#order-drawer-err`，而该节点此时已被抽屉体 oob 换成游离节点）。改为钉「`hx-swap-oob` 与 id
   落在同一标签」。② B11 列表用例没断言 `id="ai-order-drawer"`：`th:with="res='ai-order'"` 一旦被挪到
   带 `th:replace` 的标签上（8.3 实测踩过），抽屉壳会渲染成 `id="item-drawer"`、点行毫无反应，
   而 `AdminTemplateStructureTest` 只守「同标签」这一种写法，挪到别的祖先它不红。已补断言。
4. 🟡 **i18n 孤儿键 4 个 × 4 包**：`admin.consultOrderDetail.back`、`admin.aiOrderDetail.back`
   （随两个详情整页删除失去引用）、`admin.common.exportCsv`（被 `admin.v130.common.exportAll` 顶掉）、
   `admin.aiOrders.summary`（AI 页那个 `<h2>` 去掉后无人引用）。已删。
   现有 `noOrphanDynamicMessageCodes` 只扫 `admin.flash.*` / `admin.err.*`，所以 CI 不会红。

**顺带修掉的两处（复审列为 PLAUSIBLE / 死代码）**

- `verify` 的 htmx 分支原来是 `service.row(token)` + `service.summary(service.list())` 两次读，
  中间还隔着标记那次写 —— 两次之间新落一单，就会 oob 出「摘要写 11 单、表里数出来 10 行」的组合，
