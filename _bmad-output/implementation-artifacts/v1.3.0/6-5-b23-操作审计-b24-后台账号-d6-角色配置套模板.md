# Story 6.5: B23 操作审计、B24 后台账号 / D6 角色配置套模板

Status: review

> 自包含 story。**纯模板层 + 只读 drawer 端点**；Epic 1 已交付的功能端点（改名 / 换绑 / 改角色 / 改权限 / 停用 / 激活 / 角色 CRUD）**不改**。D1 运费配置不在本 story（归 10-6，商城组）。依赖 1-5（`/admin/roles` 功能与 `AdminPageCatalog`）、1-6（账号页接角色表）、2-3a / 2-3b。

## Story

As a 运营与超管，
I want 配置与安全组的操作审计、后台账号、角色配置三页视觉与交互统一，审计页时间按印尼时间显示，
so that 这一组从头到尾一个样，查审计时不用换算时区。

### 🔴 B23 的「改 WIB」在代码里已经是事实
