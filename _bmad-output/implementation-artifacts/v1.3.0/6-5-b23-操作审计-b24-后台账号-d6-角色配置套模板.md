# Story 6.5: B23 操作审计、B24 后台账号 / D6 角色配置套模板

Status: ready-for-dev

> 自包含 story。**纯模板层 + 只读 drawer 端点**；Epic 1 已交付的功能端点（改名 / 换绑 / 改角色 / 改权限 / 停用 / 激活 / 角色 CRUD）**不改**。D1 运费配置不在本 story（归 10-6，商城组）。依赖 1-5（`/admin/roles` 功能与 `AdminPageCatalog`）、1-6（账号页接角色表）、2-3a / 2-3b。

## Story

As a 运营与超管，
I want 配置与安全组的操作审计、后台账号、角色配置三页视觉与交互统一，审计页时间按印尼时间显示，
so that 这一组从头到尾一个样，查审计时不用换算时区。

## Dev Notes

### 🔴 B23 的「改 WIB」在代码里已经是事实

`audit-logs.html:61` 用 `@adminTime.wib(r.createdAt)`，i18n `admin.audit.col.time` 三语都是「(WIB)」。逐页规格 B23 写的「UTC 例外」是过期描述。本 story 只需把模板内**默认占位文案**「时间(UTC)」改成 WIB 保持一致，并加只读标识。哈希链用 `AdminAuditService.record` 里 `Instant.now().truncatedTo(MICROS)` 的 UTC 值参与计算，展示层不影响。

### 🔴 三页的写端点全部来自 Epic 1，本 story 一个不加

抽屉里的表单 `th:action` 必须与 1-2 / 1-3 / 1-6 / 现状端点逐字一致：`/admin/accounts`、`/{id}/rename`、`/{id}/rebind-email`、`/{id}/role`、`/{id}/permissions`、`/{id}/deactivate`、`/{id}/reactivate`；角色页 `/admin/roles*`。新增的只有两个只读 `GET …/drawer`。

### 🔴 D6 矩阵不进抽屉

UI 稿 7-8～7-10 拍板矩阵整页（35 维度 × 3 列在 480px 里放不下）。列表页套 B，矩阵页独立路由沿用 1-5 的 `GET /admin/roles/{id}/matrix`（以 1-5 实际实现的路径为准）。
