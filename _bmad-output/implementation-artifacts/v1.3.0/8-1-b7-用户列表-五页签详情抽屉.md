# Story 8.1: B7 用户列表 + 五页签详情抽屉

Status: ready-for-dev

> 自包含 story，可本地或云端 L0 执行。与用户沟通用中文。执行纪律见根 `CLAUDE.md`（后端→前端→联调、AC 标 L0/L1/L2、`mvn -B clean package`）。
> **零功能变更**（AB-19A 原则）：本 story 不新增、不删除任何写端点，只做页面形态重构 + 一条 PRD 例外（宠物档案增列性别 / 生日，纯读展示）。依赖 Story 2.3a（htmx 约定 / `AdminExportWriter`）与 2.3b（`tpl-b-list` 壳 / `admin-drawer.js`）。

## Story

As a 运营，
I want 用户列表有摘要条、点行在右侧抽屉里分页签看基本信息 / 宠物 / 内容 / 问诊，并在抽屉里直接停用、赠币、删除，
so that 处置一个用户不用跳独立详情页来回切。

## Acceptance Criteria

**AC1 · 列表套模板 B（逐页规格 B7）**
**Given** `/admin/users`
**When** 打开
**Then** 自上而下：筛选栏（关键词 ID / 昵称 / 邮箱 / 手机号 + 显式「查询」钮；状态下拉 `data-autosubmit`；手机号已填/未填筛选保留）→ 摘要条 **总用户数 · 今日新增 · 已停用 · 已删除**（单条 `COUNT(*) FILTER` 聚合，随筛选联动）→ 表格列 **ID ｜ 昵称 ｜ 注册邮箱 ｜ 注册时间（WIB）｜ 手机号 ｜ 状态**，默认注册时间倒序，每页 20，行高 ~48px，状态用色点 + 徽标 `[L1]`
**And** 「查看详情」按钮列删除，点行 → 抽屉（AC2）；`?open=<userId>` 自动开抽屉 `[L2]`
**And** 「导出召回名单」按钮保留：手机号筛选为「已填」时激活，否则禁用置灰 + 提示（现状行为）；改走 `AdminExportWriter`（xlsx，表头随 locale，规则 12）；权限 `user.phone_export` 不变 `[L1]`

**AC2 · 五页签抽屉吸收 `user-detail`**
**Given** 点某一行
**When** `GET /admin/users/{userId}/drawer`（`HX-Request`）
**Then** 480px 右滑抽屉，五页签：
1. **基本信息**：昵称 / 注册邮箱 / 手机号（`user.phone_view` 门控，无权限显示掩码或不渲染，与现状一致）/ 注册时间 / PawCoin 余额（`user.grant_pawcoin` 门控）/ 账号状态 `[L2]`
2. **宠物档案**：卡片网格（一宠一卡：头像位 + 名字 + 物种胶囊 + 品种 / **性别** 一行 + **生日** + KTP ID），只读，不分页；**性别 / 生日为 PRD §5 ③ 第 2 条例外**，数据取 `PetProfile.sex`（`PetSex`）/ `PetProfile.birthday`（`LocalDate`）`[L2]`
3. **发布内容**：ID / 类型 / 内容 / 状态，只读；点行 → 跳 `/admin/content?open=<postId>`（B1 抽屉，Story 7.1）`[L2]`
4. **历史问诊**：会话 / 兽医 / 时间 / 状态 / 评分，只读，顶部保留「仅元数据，不含对话内容」提示；点会话 → `/admin/consult-sessions?open=<sessionId>`（Story 9.2）`[L2]`
5. **处置**：三张卡一项一行——停用（必填 `reason`，data-confirm）/ 重新激活；赠送 PawCoin（`coins` + `reason` + 隐藏 `idempotencyToken`，data-confirm 复述昵称 + 金额）；删除账号（`type` 单选 `USER_REQUEST` / `VIOLATION` 必选 + `note` 必填，**双重 data-confirm** 复述昵称）`[L2]`
**And** 处置提交走 htmx：成功 200 + 抽屉 fragment 重渲染 + `hx-swap-oob` 刷该行；失败 422 处置卡行内 err；无权限 403 禁用态 + 注明所缺权限名 `[L1]`

**AC3 · 端点与参数零变更**
**Then** 写端点保持：`POST /admin/users/{userId}/grant-pawcoin`（coins / reason / idempotencyToken，`user.grant_pawcoin`）、`POST …/deactivate`（reason，`user.deactivate`）、`POST …/reactivate`（`user.deactivate`）、`POST …/delete`（type / note，`user.delete`）、`GET /admin/users/phone-recall.xlsx`（phone，`user.phone_export`）；路径、参数名、`@PreAuthorize` 表达式逐字不变 `[L0]`
**And** 服务层 `AdminUserService` 五个业务方法不改签名；审计动作码不变 `[L0]`

**AC4 · 退役**
**Then** 删除 `templates/admin/user-detail.html` 与 `GET /admin/users/{userId}` 页面路由；不做跳转兜底（D-23）；全库 grep 无残留 `th:href` 指向 `/admin/users/{id}` 页面 `[L0/L1]`

**AC5 · 边界**
**Then** 已删除账号：列表行置灰、抽屉全只读、处置页签不渲染任何按钮；已停用账号处置页签显示「重新激活」而非「停用」 `[L2]`
**And** 处置页签按权限逐钮禁用并注明缺失权限（`user.deactivate` / `user.grant_pawcoin` / `user.delete`）`[L1]`
**And** 无 `user.view` 的账号：导航不渲染「用户」项；直访 403 `[L1]`

**AC6 · 三语与回归**
**Then** 新增文案全部走 `admin.v130.users.*` key，zh / en / id 三包同批；切 ID 无截断（摘要条 2×2 网格、页签 nowrap）`[L0/L2]`
**And** 既有 `AdminUserIntegrationTest` / `AdminUserDeactivationIntegrationTest` / `AdminUserDeletionIntegrationTest` / `AdminUserPhoneIntegrationTest` 全绿；新增 MockMvc 四条（整页 200 / drawer fragment / 422 / 403）`[L1]`

### ⚠️ 现状与逐页规格的两处差异（如实处理，不扩范围）

1. 现状关键词搜索是 `hx-get` 即输即查；模板 B 通用规格要求「文本搜索必须配显式查询钮」。改为显式钮，去掉 `hx-trigger` 即时搜索。
2. UI 稿 3-1 写「导出召回名单 = 手机号筛选后才激活」，代码已如此（`exportNeedsFilter` 三态），照搬即可。

### `@adminTime` 已存在

`admin/web/AdminTime.java` 已是 bean（模板里 `@adminTime.wib(...)` 在用）。架构 §结构树写的 `admin/shared/time/AdminTime` 由 Story 2.3a 负责搬迁或直接沿用现有 bean；本 story 只调 `@adminTime.wib`，不自己格式化。

### 抽屉页签间跳转的目标

- 发布内容 → `/admin/content?open=<postId>`：依赖 Story 7.1 的 `?open=` 支持；7.1 未合入前链接照常渲染但落到列表页顶部，不算本 story 失败。
- 历史问诊 → `/admin/consult-sessions?open=<sessionId>`：依赖 Story 9.2，同上。

### 测试标准

- 沿用 `test/.../admin/usermgmt/` 四个 `IntegrationTest extends ApiIntegrationTest`；抽屉 fragment 断言用 `content().string(containsString("id=\"users-drawer\""))`。
- L1 本地跑法：flush Redis DB0 → 重建 scratch 库 → `DB_NAME` env。

### Project Structure Notes

- 改动全部在 `admin/usermgmt/**` + `templates/admin/{users.html, fragments/drawer-users.html}`；无迁移、无新表。
- 三语 key 前缀 `admin.v130.users.*`；`sec:authorize` 与 `@PreAuthorize` 逐字一致（历史事故：按钮在、点了 403）。
