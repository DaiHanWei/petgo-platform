# Story 2.3: 互动栏与输入框合并为固定底栏

Status: ready-for-dev

## Story

As a 用户，
I want 点赞和分享一直在手边，
so that 我不用为了点个赞把页面滚回图片下方。

---

> **这不只是挪位置，是多了一个交互状态**（UI 稿 D1 原话：「比"挪位置"更深的交互状态变化」）。不定死的话，两个实现会对「打字时点赞按钮还在不在」「评论数在哪显示」给出不同答案。
>
> 🔴 **本 story 会重排详情页的整体结构**（`_interactionBar` 从 `SingleChildScrollView` 内迁到 `CommentComposer` 同级），**必须先于 Story 2.5 / 2.6**，否则评论区要改两遍。

---

## Acceptance Criteria

### AC1 — 合并为单条底栏（L2）

**Given** 详情页
**When** 页面渲染
**Then** 互动栏与评论输入框合并为**同一条固定底栏** `[L2]`
**And** 正文下方不再单独存在互动栏 `[L2]`
**And** 点赞/分享始终悬浮可点，不需滚动 `[L2]`

### AC2 — 两态互斥（L2）

**Given** 输入框未聚焦
**When** 查看底栏右侧
**Then** 显示点赞 + 分享 `[L2]`
**Given** 输入框已聚焦或已开始输入
**Then** 右侧切换为发送 `[L2]`
**And** 同一时刻只存在一组（两态互斥，无第三种组合） `[L0]`

### AC3 — 评论数口径（L0 / L2）

**Given** 评论数
**When** 在页面上查找
**Then** 只在评论区标题「KOMENTAR (N)」出现一次，底栏不再展示 `[L2]`
**And** N = 该帖**全部未删除评论数（含二级回复）** `[L0]`
**And** 与 Feed 卡片的评论数**同源同口径** `[L1]`

> 🔴 禁止「标题算一级、卡片算全部」这类分叉 —— 用户会看到首页显示 24、点进去标题写 9。

### AC4 — 热区（L0 / L2）

**Given** 点赞与分享图标
**Then** 可见尺寸 19px、间距 22px `[L2]`
**And** 可点击热区不小于 44×44（隐性扩展，不改变可见大小） `[L0]`

### AC5 — 明确不改（回归保护，L2）

**Given** 详情页顶栏
**Then** 分享入口**不在**顶栏；顶栏「···」仍为举报合规入口（2026-08-14 既有决策） `[L2]`
**And** 举报与删除互斥关系不变 `[L2]`
**And** `?focus=comments` 评论锚点行为不变 `[L2]`

### AC6 — 双击不点赞（L2）

**Given** 详情页图片
**When** 双击
**Then** **不**触发点赞 `[L2]`

> 2026-08-31 取消。理由：单击开灯箱会被双击判定拖慢 300ms，且与灯箱内「双击=缩放」语义冲突。点赞只走底栏。

### AC7 — 不扩散（L0）

**Then** 不改动评论列表项本身（属 Story 2.5） `[L0]`
**And** 不改动回复态（属 Story 2.6） `[L0]`

底栏是固定的，键盘弹起时的避让、以及避让过程中两态切换的时序，**只能真机验**。
