# Story 1.10: 场所分享到站外

Status: review

## Story

As a 想约朋友一起去的用户,
I want 把这个场所发到 WhatsApp 给朋友,
so that 朋友不用装 App 就能看到这地方长什么样、在哪儿。

## Acceptance Criteria

**AC1 — 分享按钮** `[L2]`
详情页点分享 → 唤起系统分享面板，分享内容是 **H5 场所页链接**。

**AC2 — 链接形态（AD-5 / NFR-1）** `[L0]`
路径为 `/place/{不可枚举 token}`。🔴 **不得**用场所名或自增 id 拼链接。

**AC3 — 页面内容** `[L2]`
服务端直出，含场所名 / 类型 / 标签 / 文字地址（可复制）/ 照片 / 简介 + **Open Graph 预览卡** + App 下载引导双 CTA。

**AC4 — OG 例外要写进注释** `[L0]`
🔴 本页放 `og:image` 是对名片页 / 里程碑页「不放预览图」边界的**有意例外**（场所照片不含个人与宠物隐私）。
该理由**写进代码注释**，防被后人当漏做"修正"掉。

**AC5 — 🔒 审核前不给图** `[L1]`
照片尚未通过三方审核（先发后审期间）→ **不下发 `og:image`**（2026-09-15 拍板）。
⚠️ **理由必须写进代码注释**：社交平台会主动抓取并**缓存**预览图。审核放行前就给图，等于任何人都能造个场所、传张违规图、把链接甩进群 —— 等运营下架时，**预览卡已经躺在几百个聊天记录里，且不随下架消失**。H5 页面会变，预览卡不会，这是两个东西。
审核通过后再给图；此期间分享出去的卡片仍有场所名 / 邀约文案 / 地址，只是没有大图。

**AC6 — 唤起已装 App** `[L2] [L0]`
点页面主 CTA 先尝试唤起进 App（唤起链沿用名片页：pagehide 判成功 + 超时回落商店）。
**安卓清单已声明对应深链 host**，否则安卓侧唤起必失败。

**AC7 — 下架态** `[L1]`
场所已下架 → 统一「场所不存在」文案 + 404 + noindex（防枚举），**链接本身长期有效**。

**AC8 — 不接分享奖励** `[L0]`
**不接入 FR-96 分享奖励**（奖励渠道只有年龄卡 / Tailsonality 卡 / 护照卡三个）。

### 🔴 安卓清单不加声明 = 唤起必失败

Dart 侧的深链映射（`petgo_app/lib/app.dart` 的 `deepLinkToLocation`）与安卓清单的 intent-filter 是**两处**，漏一处唤起就不工作，而**所有测试照样绿**（深链是系统行为）。

仓库里已有一条守门测试：`petgo_app/test/deeplink_manifest_test.dart` —— App 认得的每个 `tailtopia://` host，安卓清单必须有对应声明。**本 story 加 host 时它会自动把你网住**。

### 照片可用性

场所照片存在**公开桶 + CDN**，长期有效、不是会过期的临时链接 —— 这是 og:image 可行的前提。

### Completion Notes List

**已交付（L0 全绿）**

1. **H5 页面**（AC2/AC3）：`GET /place/{publicToken}` → `PlaceSharePageController` +
   `templates/place_share.html`（照 `content_share` / `card` 两页的形状）。
   页面含：首图 hero + 邀约文案 + 名称 / 类型 / 标签 / 描述 / **文字地址（一键复制）** +
   其余照片缩略 + 吸底 CTA。语言恒印尼语（H5 无登录态，拿不到语言偏好 —— 与既有三页同口径）。
   路径里是**不可枚举 token**，不是场所名也不是自增 id（AC2 / AD-1 Rule 3）。
2. **🔴 OG 例外的理由写进了代码**（AC4）：`/p/`（名片）与 `/m/`（里程碑）刻意不放 `og:image`，
   本页放 —— 场所照片拍的是店门口 / 座位区 / 菜单，不含个人与宠物隐私，而这页的全部意义
   就是"发到群里让朋友一眼看到这地方长什么样"。**控制器类注释与模板注释都写了，
   并有一条测试断言那段注释还在** —— AC4 逐字要求的就是"防被后人当漏做修正掉"。
3. **🔴 审核前不给 og:image**（AC5）：判据是照片行上的 **`og_eligible`**，
   比"对外可见"更严（见下面 code-review 第 2 条）。没有合格照片时卡片仍有
   场所名 / 邀约文案 / 地址，只是没有大图。
4. **下架态**（AC7）：统一复用名片失效页 `card_gone` + 404 + noindex，**不区分原因**；
   失效页上不带任何场所信息。**链接本身长期有效** —— token 不回收。
5. **唤起链**（AC6）：模板里的 CTA **逐条照抄 `card.html`** 那套
   （pagehide 判成功 + 900/700ms 守卫回落 + `market://` 少一跳），不另发明计时方案。
   Dart 侧加 `tailtopia://place/{token}` → `/places/{token}`；安卓清单加 intent-filter。
6. **分享按钮**（AC1）：详情页分享的 payload 从「名称 + 地址」换成
   **「名称 + H5 链接」**（`placeShareUrl`）。
7. **🔴 不接分享奖励**（AC8）：FR-96 的渠道只有年龄卡 / Tailsonality 卡 / 护照卡三个 ——
   一条扫源码的测试钉着详情页里不出现任何 `shareReward` / `pawcoin` 字样。

**🔴 新写的守门测试当场抓到一个存量漏网**

Dev Notes 说「仓库里已有 `test/deeplink_manifest_test.dart`」—— **实际上没有**，
所以本 story 把它写了出来。它做的事：**App 认得的每个 `tailtopia://` host，
安卓清单里必须有对应声明**（反向也查：清单声明了 Dart 侧不认识的 host 同样红）。

写下来当场就红了一条：**`tailtopia://post`（V1.1.6 Story 9.3 的单条内容分享）
只加了 Dart 映射、没加清单声明** —— 那条深链在安卓上从来没工作过，
而所有测试一直是绿的（深链是系统行为）。已一并补上清单声明。

**code-review 复审后修掉的（4 findings 全修）**

1. **新 H5 前缀没进错误页白名单**：`/place/` 只加了 SecurityConfig，漏了
   `GlobalExceptionHandler.isH5Path` 与 `H5ErrorController.H5_PREFIXES` ——
   页面上抛任何异常时，站外访客看到的是一坨 ProblemDetail JSON（还带 traceId），
   而不是失效页。→ 两处都加上；**`/c/` 是同样的存量漏网，一并补**。
2. 🔴 **AC5 的门控原先只判 `VISIBLE`，挡不住它要挡的那个场景**：
   标记场所时那批走先发后审 —— 三方 `RISKY`（有点像）/ `DEGRADED`（压根没查成）
   **照样落 VISIBLE 对外展示**（Story 1.3 的产品口径，不改）。于是"挑三方挂掉的时候
   造个场所、传张违规图、把链接甩进群"原样成立，而那正是 AC5 的原文场景。
   → 加 `place_photos.og_eligible` 列（**比"对外可见"更严**）：
   只有**干净 PASS** 的图才置 true；补充照片在异步 approve 时才拿到资格。
   **页面上展示是一回事，交给社交平台永久缓存是另一回事。**
3. **品牌图裂图**：模板抄了 `content_share.html` 的 `/brand/wordmark_brand.svg`，
   而后端 `static/brand/` 里**只有 `logo.svg`**（那个文件只存在于 App 的 assets 里）——
   每个分享页顶上一个裂图。→ 改用 `/brand/logo.svg`（`card.html` 本来就是对的）。
4. **跨仓守门测试放错了仓**：「H5 深链 host 换了而 App 没换」原先写在 `petgo_app/test/` 里
   读后端文件，而 `frontend-ci.yml` 的 `paths:` 只认 `petgo_app/**` ——
   **纯后端 PR 改掉那个 host 时这条根本不会跑**，绿灯合入而安卓唤起静默失效。
   → 拆成两侧各钉同一个字面量：App 侧断言自己认得 `tailtopia://place`，
   后端侧断言模板把 `deeplink` 带给了 CTA。

**范围边界（有意不做）**

- **不做分享埋点**：名片页那套 `pet_card_cta_*` 事件是 Story 10.1 的交付物，
  场所页没有对应的埋点设计 —— 照抄一份会往看板里塞一组没人定义过的事件；
- **不接分享奖励**（AC8）；
- **页面上没有**通往标记人主页 / 评论区 / 其它场所的任何链接：
  这是一条分享出去的地点信息，不是一个可浏览的入口。
