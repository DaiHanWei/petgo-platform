## Story

As a 运营，
I want 配送区域、免运门槛、退货收件地址三组配置各自一张卡、改哪张存哪张，
so that 不会误提交别的组，且与运营配置页手感一致。

## Acceptance Criteria

**AC1 · 三卡各自保存**
**Given** `/admin/shop/shipping`（查看 `config.view` 或 `config.edit`；编辑 `config.edit`）
**Then** 卡①可配送区域表（Kecamatan / Kota / Provinsi / 运费 / 启用开关；**行内编辑 + 新增行**；`POST shipping/zones` 保存、`POST shipping/zones/toggle` 启停）· 卡②免运门槛（`POST shipping/threshold`）· 卡③退货收件地址（`POST shipping/return-address`）；**每卡自带保存钮**（未修改禁用 → 修改激活标「已修改」→ 高危确认复述新旧值 → 提交，PRG）`[L1/L2]`
**And** 组头不标红；校验错误行内 err；端点与参数零变更 `[L1]`
**And** 区域行启停开关即时提交（`zones/toggle`），不受卡保存钮控制（现状语义）`[L1]`

**AC2 · 归组**
**Then** 导航归**商城组**（UI 稿泳道 5 第 17 帧；D-8），`AdminPageCatalog` 登记 SHOP 组；逐页规格文字写在「配置与安全」标题下属历史归类，以 UI 稿为准 `[L0]`

**AC3 · 回归**
**Then** `AdminShippingController` 四个 POST 路径 / 权限不变；相关 IT 全绿 `[L0/L1]`
