# Story 7.3: B3 顶置管理

Status: ready-for-dev

> 自包含 story。与用户沟通用中文。纪律见根 `CLAUDE.md`。依赖 2.3a / 2.3b。端点零变更：新建 / 改时间 / 终止三个 POST 路径与参数不动，只把常驻页尾的新建表单收进抽屉。

## Story

As a 运营，
I want 顶置坑位列表有摘要条，新建 / 改时间 / 终止都在抽屉里完成，
so that 换坑位不用在长页面上下翻。

## Acceptance Criteria

**AC1 · 壳与摘要条**
**Given** `/admin/content-pins` 套 `tpl-b-list`
**Then** 筛选：坑位 `slot`（现状 data-autosubmit 保留）· 状态（生效中 / 待生效 / 已结束）；摘要条：生效中 · 待生效 · 已结束（随筛选联动，单条聚合）`[L1]`

**AC2 · 表格**
**Then** 列 = 类型（顶置内容 / 推广卡片）｜ 内容 / 标题 ｜ 生效时间（**WIB 标注**，起止）｜ 状态 ｜ 操作；默认生效时间倒序；每页 20 `[L2]`

**AC3 · 详情抽屉**
**When** 点行 → `GET /admin/content-pins/{id}/drawer`
**Then** 坑位内容预览（顶置 = 帖子快照：首图 + 正文摘要 + 作者；推广卡 = 卡面预览：图 + 标题 + 跳转链接）+ 时间设置（起止 WIB，行内可编辑）+ 操作条 `[L2]`

**AC4 · 新建走抽屉表单**
**When** 右上「＋新建」→ 抽屉表单
**Then** 字段 = 坑位 `slot` · 类型二选 `objectType`（CONTENT / PROMO；切到 PROMO 表单替换为 `promoImageFile` 或 `promoImageUrl` + `promoTitle` + `promoLinkUrl`）· 内容选择器（`GET /admin/content-pins/pick`，搜索 + 分页 + 筛选，**大结果集 1.2.0 既有要求保留**，keyup 300ms 防抖）· `startsAt` / `endsAt`（WIB）→ `POST /admin/content-pins`（参数名逐字不变）`[L1]`
**And** 现状页尾「新建顶置」常驻表单删除 `[L2]`

**AC5 · 操作（端点零变更）**
| 按钮 | 端点 | 权限 | 确认 |
|---|---|---|---|
| 新建 | `POST /admin/content-pins` | `content.pin_manage`（`AdminPermissions.CONTENT_PIN_MANAGE`） | 无 |
| 改时间 | `POST /admin/content-pins/{id}/edit` | 同上 | 无 |
| 终止 | `POST /admin/content-pins/{id}/terminate` | 同上 | data-confirm（`admin.pins.terminateConfirm` 沿用） |
**Then** htmx：200 + 抽屉 + oob 行 + 摘要条；422 行内 err `[L1]`
**And** 查看权限 `content.pin_view` 无 manage 时操作条禁用注明 `[L1]`

**AC6 · 边界**
**Then** 同一坑位同时段唯一：冲突时 422 行内报错并**显示冲突项**（id + 起止），服务层校验现状沿用 `[L1]`
**And** 已结束坑位抽屉只读 `[L2]`

**AC7 · 三语与回归**
**Then** `admin.v130.pins.*` 三包；`AdminContentPinIntegrationTest` 全绿；四条 MockMvc `[L0/L1]`

### 现状与改动边界

| `admin/pin/web/AdminContentPinController.java` | `GET /admin/content-pins`（VIEW）、`GET /pick`（VIEW）、`POST /admin/content-pins`（MANAGE，参数 slot/objectType/contentId/promoImageUrl/promoImageFile/promoTitle/promoLinkUrl/startsAt/endsAt）、`POST {id}/edit`、`POST {id}/terminate` | + `GET {id}/drawer`、`GET new/drawer`；POST 加 htmx 分支 | 全部参数名 |

### 🔴 内容选择器

### 🔴 推广卡片字段
UI 稿 2-12 注记「类型切到推广卡片后表单替换为推广标题 / 图 / 跳转」，与现状 `promo*` 参数一一对应。**不新增字段**。

### 端点零变更清单
`POST /admin/content-pins` · `POST /admin/content-pins/{id}/edit` · `POST /admin/content-pins/{id}/terminate`。新增 GET：`{id}/drawer`、`new/drawer`。

### 测试标准 / 三语 / Project Structure
沿用 `AdminContentPinIntegrationTest`；冲突 422 fragment 断言含冲突项 id。key `admin.v130.pins.*`。改动落 `admin/pin/**`、`templates/admin/content-pins.html`、`fragments/drawer-content-pin.html`。
