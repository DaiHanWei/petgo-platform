**🔴 两条 AC 偏差，都不改代码、按现状记账：**

1. **`GET /admin/vets/{id}/qualification` 与 `/admin/vets/{id}/ratings` 不删**。AC1 把它们列进退役表，但 Story 9.1b 实际是把它们改成了**抽屉页签的懒加载片段**：htmx 请求返 `drawer-vets :: qual-panel` / `:: rating-panel`，非 htmx 直达则 302 回列表并开抽屉。**整页模板确实删了**（`vet-qualification.html` / `vet-ratings.html` 不存在），退役的语义已经达成；删路径等于把抽屉的两个页签一起干掉。同路径的 `POST /admin/vets/{id}/qualification*` 更是 AC1 自己「保留（勿误删）」名单里的。已在 Story 11.1 的底账里把这两条的备注从 ⛔ 改成 🔄，避免下一个人照着 ⛔ 去删。
2. **商城两条不动**：Epic 10 前置是 v1.4.0 电商线合入（AD-12），本轮未执行，`/admin/shop/**` 整组没重构。它们已在 11.1 白名单里作为**预授权删除项**写着，Epic 10 落地时删掉不会让守门报事故。

**AC2 · 旧地址返 404**（`AdminRetiredRoutesTest`，L1，14 条参数化）：钉的是**严格 404**，不是「非 2xx」。退役页有两种「还活着」的形态都不算删干净——**302**（留个 redirect 壳把旧地址转到新页，看着体贴，实际是永远删不掉的尾巴：书签 / 外部文档 / 硬编码全靠它续命，D-23 明确不做旧地址跳转）和 **200**（压根没落地）。用**超管**跑：普通账号缺权限拿到的是 403，403 和 404 都是「进不去」，但只有 404 能证明**路由不存在**。

**AC3 · 无残留引用**（`AdminRetiredRoutesStaticTest`，L0，4 条）：AC3 给的是一串 `grep`，但直接照抄会**恒红** —— 全仓有十几处注释写着「整页 `vet-edit.html` 已删，内容并入抽屉」，那正是应该写的东西。所以实现为**剥掉注释后**再查，且分成四条各管一件事：

- `everyRetiredPageTemplateIsActuallyGone` —— 模板文件真的不在了；
- `noControllerStillReturnsARetiredTemplate` —— 没有 Controller 还 `return "admin/<退役模板>"`。**这是「模板删了、返回值没删」的唯一机器证据**：视图名是字符串，编译期不报错，运行期才 500，而且只有真的访问那条旧地址才触发；
- `noTemplateStillLinksToARetiredPage` —— 没有链接还指向退役整页（跨页跳转一律改 `?open=<id>` 页内深链，D-23）。
  🔴 **一条路由的各种写法都要认得**：第一版只匹配 `th:href="@{...}"` 一种字符串，
  换成**单引号**、换成 `hx-get`、写成 Java 里的 `redirect:` 就静默放过 —— 而这三种在本仓库都是常见写法。
  改成正则（属性名可带 `th:`/`hx-` 前缀 + 单双引号 + 可选 `@{` + 路由 + 合法后继字符）并加 Java 侧 `redirect:` 扫描。
  后继字符集里 **`}` 不能漏**：`th:href="@{/admin/ratings}"` 正是最常见的形态，漏了它这条断言对绝大多数真实残留都不响（实测两种写法全漏）。
  五种写法逐条注入实测：单引号 `th:href` / `hx-get` / 双引号 `th:href` / 带参 `@{...(tab='x')}` / Java `redirect:` —— **全部报出**，还原后全绿；
- `navigationHasNoEntryPointingAtARetiredPage` —— 侧导航**与 `AdminPageCatalog`** 里都没有退役页。查 catalog 是必须的：导航由 catalog 驱动，只查模板的话，catalog 里留一条死页面照样会渲染出菜单项。**「菜单看得见、点了打不开」是三种半成品里最难受的一种。**

四条全绿。⚠️ 商城两条**故意不写进这个测试的名单**：Epic 10 未执行，写进去这条护栏从落地起就是红的，而**一条从来没绿过的护栏等于没有**。

**AC4 · 孤儿 key 处置**：按判据（key 在 `src/main` 的 java/html/js/sql 里一次都没出现，且不属于任何动态拼接前缀）扫出 **164 个**孤儿 key，分 26 组。**保留不删**，登记两处：

- `messages_zh_CN.properties` 顶部注释（AC4 原文要求的位置），列出涉及的前缀与红线；
- 逐条清单 + 归属 story：`_bmad-output/implementation-artifacts/v1.3.0/i18n-孤儿key登记-20260910.md`。
