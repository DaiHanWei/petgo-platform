# Story 1.6: 灯箱抽成公共组件并接入场所照片

Status: ready-for-dev

## Story

As a 想看清场所照片细节的用户,
I want 点开照片能全屏看、能放大、能左右翻,
so that 我能看清门口有没有台阶、座位区够不够大。

## Acceptance Criteria

**AC1 — 抽组件不改行为** `[L0]`
把内容详情页里那个私有灯箱（可左右翻页 + 双指缩放）抽成公共组件。
🔴 **内容详情页的行为一字不变**，既有测试全绿。

**AC2 — 场所照片接入** `[L2]`
场所详情页点某张照片 → 打开同一个公共灯箱，可左右翻页与缩放。

**AC3 — 与批次 A 的关系** `[L0]`
记录「批次 A 新版灯箱（FR-115）落地后整体替换」的后续动作。**本 story 不等批次 A**。

## Tasks / Subtasks

- [ ] **T1 抽组件**（AC: 1）
  - [ ] 从 `content_detail_page.dart` 抽出 `_Lightbox` / `_LightboxState` 到共享位置
  - [ ] 内容详情页改为引用公共组件，行为与参数保持一致
  - [ ] 跑既有内容详情相关测试确认全绿
- [ ] **T2 接入场所**（AC: 2）
- [ ] **T3 记录后续**（AC: 3）

- 让内容详情页的既有验收失效
- 与批次 A 的新版灯箱撞车（那才是重做灯箱的地方）
