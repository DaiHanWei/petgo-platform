## Story

**AC2（无写死单语）· 新建 `scripts/ci/check-admin-hardcoded-text.sh`。**

🔴 **不能用 AC2 原文里的 `grep -rnP "[\p{Han}]"`**：GNU grep 未必带 PCRE（本环境的 3.11 就不带），`-P` 会**静默匹配不到任何东西** —— 守门看起来绿、其实一个字都没查。改用 python3（GitHub runner 自带），按 CJK 码点区间扫。

**第一版有 6 类漏报 + 3 处会静默失守的解析缺陷，复审全部实测复现，已逐条修掉：**

| 问题 | 第一版的错法 | 现在 |
|---|---|---|
| 属性白名单漏项 | 只查 `placeholder/title/alt/aria-label/label` | **属性值里出现中文即违规**，不再维护白名单。`th:attr="data-confirm='中文'"` 是本仓库确认弹层的标准写法，白名单对它完全不设防 |
| 只认双引号 | `\s*=\s*"([^"]*)"` | 单双引号都吃（`placeholder='中文'` 原来直接溜过去） |
| `th:text` 值里写死中文 | 只看「属性名在不在」 | 值里的中文由「属性值含中文即违规」那条抓 —— **判在值上，不判在正文上**（`th:text="${notice}"` 那种正文占位仍照常放行，全站几十处） |
| 未闭合标签 | 栈只在遇到闭合标签时弹 | 加 HTML5 隐式闭合（`p/li/option/td/th/tr/dd/dt`）。少写一个 `</p>`，该文件**后半段全部失守**且无任何提示 |
| 注释与 `<script>` 的处理顺序 | 先去注释、再切 script | **一遍顺序扫**。两个顺序各有致命对手：先去注释 → JS 字符串里一个 `<!--` 会吞到下个 `-->`；先切 script → **注释里写的 `<script>` 示例**会跟几十行后真正的 `</script>` 配对（`dashboard-charts.html` 顶部注释里就有一个，实测让该文件报出 3 处假阳性 + 1 处解析失败） |
| 正则字面量 | 状态机不认 `/.../` | 认。`const re = /it's/;` 里的引号原来被当成字符串开始 → 从那行起状态机错位，**admin-core.js 开头十几行中文注释会全部变成「裸文案」**，CI 红成一片且无从理解。另加「结束态非 None 直接报错」，把静默错切变成显式失败 |
| JS 只查中文 | `HAN.search(line)` | 加**来源约束**（AC2 原话：toast / confirm 文案须来自 `data-*` 或 `#{}`）：`alert(`/`confirm(`/`toast(`/`.textContent =`/`.title =`/`.innerHTML =` 后面直接跟字母字符串字面量即违规，**不论中英印**。`toast('Saved successfully')` 原来一路绿灯 |
| 枚举下拉框 | 没查 | 新增一类：`<option th:each=… th:text="${x}">`（值里无 `#{`）→ 切 ID 显示 `ACTIVE`/`ILLEGAL`/`GENERAL` |
| JS 目录不递归 | `glob('*.js')` | `**/*.js` + 显式排除 `vendor/` 与 `.min.js`。原来靠目录碰巧是扁平的，拆子目录就静默漏掉整个目录 |
| 设计态占位属性 | 会误报 | 同标签有同名 `th:xxx` 时跳过（`th:placeholder="#{a}" placeholder="占位提示"`，与 `<h1 th:text="#{x}">标题</h1>` 同理） |

⚠️ 明确**不防编码规避**（`'保存'`、`&#x64CD;`），已写进脚本注释。这条守的是「顺手写死」，不是「刻意绕」。
