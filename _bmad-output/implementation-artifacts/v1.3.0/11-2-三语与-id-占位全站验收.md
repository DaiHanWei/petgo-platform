# Story 11.2: 三语与 ID 占位全站验收

Status: ready-for-dev

> 自包含 story。L0 部分（key 集合 CI）云端可跑；L2 部分（切 ID 逐页截图）须本地或 stag 浏览器。与用户沟通用中文。

## Story

As a 产品，
I want 三个语言包的 key 集合完全一致，并且切到印尼语后 49 帧对应的每一页没有任何截断，
so that 印尼运营同事拿到的后台不是半中文半乱码。

## Acceptance Criteria

**AC1 · key 集合相等（CI）**
**Given** `scripts/ci/check-i18n-keys.sh`（Story 2.2 建）
**When** CI 运行
**Then** `messages_zh_CN` / `messages_en` / `messages_id` / `messages`（默认包）四份 key 集合两两相等；`admin.v130.*` 前缀下无缺 `[L0]`
**And** 脚本对 key **集合**比对，不比行数（2026-09-09 核实：en 2141 行 / id 2088 行的差全是注释与空行，集合相等）`[L0]`

**AC2 · 无写死单语**
**Then** `grep -rnP "[\p{Han}]" petgo-backend/src/main/resources/templates/admin --include=*.html` 结果只允许出现在 `th:text` 的**占位默认文本**位置（即同一标签带 `th:text="#{…}"`）；任何无 `th:text` 的裸中文 = 失败 `[L0]`
**And** 同规则查 `admin-*.js` 里的用户可见字符串（toast / confirm 文案须来自 `data-*` 属性或 `#{}` 注入）`[L0]`

**AC3 · ID 占位逐页核对（UX-DR12）**
**Given** stag 或本地后端，顶栏切 `?lang=id`
**When** 按 UI 稿 8 泳道逐页打开（清单见 Dev Notes）
**Then** 每页：侧导航 8 组名与全部菜单项 / 页签 / 按钮 / 表头 / 徽标 / 抽屉标题 **无截断、无溢出、无换行错位**；表单标签置于输入框上方；按钮 `min-width` 自适应 `[L2]`
**And** 每页一张截图，命名 `id-<泳道>-<页>.png`，存 `_bmad-output/_archive/l2-shots-v130-i18n/`（gitignore png，只提交 `RESULTS.md`）`[L2]`
**And** 发现截断 → 记入 `RESULTS.md` 并回对应页面 story 修 CSS（不在本 story 改业务）`[L2]`

**AC4 · 角色名 / 状态枚举三语**
**Then** 预置角色名（`admin_roles.name_key`）、`PlaceStatus` / `FollowupStatus` / `QualificationStatus` 等新旧枚举展示文案均走 key，切 ID 有翻译 `[L2]`

### 🔴 ID 文案平均比中文长 40%+

逐页规格三语约束：表单标签置上；按钮 `min-width` + 自适应；表头 / 徽标 `nowrap` + 省略号悬浮全文；导航与页签按 ID 最长文案校验。本 story 只**验收**这些规则，CSS 修在 2.3b（壳）或对应页 story。

### 与 11.5 的关系

11.5 是形态比对（对 UI 稿），本 story 是语言比对（对 ID）。两者可共用同一次 stag 部署与同一套截图脚本，但产出分开两份报告。
