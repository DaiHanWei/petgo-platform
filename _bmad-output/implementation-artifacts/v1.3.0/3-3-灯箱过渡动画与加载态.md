# Story 3.3: 灯箱过渡动画与加载态

Status: review

## Story

As a 用户，
I want 打开和关闭大图时画面是连续的、加载失败时能重试，
so that 体验不突兀、不卡死。

---

> 依赖 Story 3.1（组件接口，尤其 `heroTagPrefix`）。
>
> 现状：`_ImageCarousel` 的缩略图失败态只是一个灰色容器（`errorBuilder` 返回纯色块），**没有重试**。

---

## Acceptance Criteria

### AC1 — 双向过渡动画（L2）

**Given** 详情页某张缩略图
**When** 点击打开查看器
**Then** 图片从原位置放大飞入全屏 `[L2]`
**When** 关闭查看器
**Then** 图片缩回原缩略图位置 `[L2]`
**And** 开关双向都有动画，不是只有打开有 `[L2]`

### AC2 — 🔴 Hero tag 由调用方给前缀（L0 / L2）

**Given** 同一张图在一屏内出现多次
**When** 生成 Hero tag
**Then** tag 由调用方提供的 `heroTagPrefix` 保证唯一 `[L0]`
**And** **不从图片 URL 推导 tag** `[L0]`
**And** 构造一个「同图两处同屏」的用例验证不抛异常 `[L2]`

> 🔴 同 tag Hero 同屏时 Flutter **直接抛异常**。批次 B1 的场所页典型版式就是「头图 + 照片网格」，同一张图必然出现两次。本批次虽然没有这种版式，**接口仍须留口**。

### AC3 — 加载中模糊过渡（L2）

**Given** 原图尚未加载完成
**When** 查看器打开
**Then** 先显示已有缩略图，模糊过渡到清晰 `[L2]`
**And** 缩略图来源沿用 `_ImageCarousel` 现有的 `thumbWidth:1080`，不另取 `[L0]`

### AC4 — 失败重试（L2）

**Given** 图片加载失败
**When** 查看器渲染该张
**Then** 显示失败提示与**重试按钮** `[L2]`
**And** 点击重试重新加载 `[L2]`

### AC5 — 埋点值域（L0 / L1）

**Given** 任一次打开 / 关闭查看器
**When** 上报
**Then** `lightbox_opened` / `lightbox_dismissed` 携带 `source` 与 `max_zoom_used` `[L1]`
**And** `dismiss_gesture` 取值域四值之一：`close_button` / `tap` / `swipe_down` / `system_back` `[L0]`
**And** **系统返回键与 iOS 侧滑退出必须上报为 `system_back`**，不得漏报 `[L2]`

> ⚠️ `system_back` 这条路径此前没人管。不报的话，「关闭方式的分布」这份数据是错的。

**实现要点（复审着眼处）**：

1. **两条上报都挂在生命周期，不挂在按钮回调**：`lightbox_opened` 在 `initState`，`lightbox_dismissed` 在 `dispose`。挂在 ✕ 的回调里就只有 ✕ 会上报，系统返回键与 iOS 侧滑**静默丢失** —— 而那正是 AC5 点名的缺口。`_dismissGesture` 默认值取 `systemBack`：凡是没被 ✕ / 单击 / 下滑显式认领的退出，都是从系统那边走掉的。
2. **`dismiss_gesture` 的四个值只从枚举的 `wire` 出来**（`LightboxDismissGesture`）。到处写字符串就会出现 `swipe_down` / `swipeDown` / `drag` 三种写法指同一件事 —— AD-A26 明文要防的看板事故。测试逐字断言这四个值与顺序。
3. **埋点治理表扩了一个前缀**：`lightbox_` 与后缀 `_dismissed` 加进 `test/analytics/v112_events_test.dart` 的白名单。灯箱是**跨模块共享组件**（本批次挂详情页、B1 挂场所页），挂进 `post_` 会让场所那边的打开数被算成内容帖的。事件名由 PRD §4 定死、AD-A23 明令不得改名，所以**扩表、不改名**。
4. **`AppImage.widget` 新增可选 `frameBuilder`**（加载淡入用）。纯追加参数，不传时行为与改前逐字相同 —— 既有 30+ 处调用一处没动。
5. **重试靠换 key**：`ValueKey('lightboxImage_<i>_<tick>')`，tick+1 → Element 重建 → 重新发起加载。不换 key 的话 `Image` 认为自己没变，失败态就此固化、按钮点了没反应。
6. **缩略图沿用轮播的 1080 档**（AC3 明文），不另取一档 —— 另取等于同一张图在两处各缓存一份。
