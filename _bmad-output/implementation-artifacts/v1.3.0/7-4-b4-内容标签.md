# Story 7.4: B4 内容标签（抽屉多页签，打标入口收拢）

Status: ready-for-dev

> 自包含 story。与用户沟通用中文。纪律见根 `CLAUDE.md`。依赖 2.3a / 2.3b。端点零变更（5 个 POST 路径参数不动）；变化在页面组织：主表只留标签一张表，分配记录进抽屉页签，独立「给内容打标」按钮废除。

## Story

As a 运营，
I want 内容标签页只看一张标签表，点开标签在抽屉里编辑、看分配记录、加内容，
so that 打标只有一个入口，不会在两张表之间迷路。

## Acceptance Criteria

**AC1 · 主表只有标签**
**Given** `/admin/content-tags` 套 `tpl-b-list`
**Then** 摘要条：生效标签数 · 生效中分配数；表格列 = 胶囊样式预览 ｜ 标签码（**系统自动 `ct-<id>` 不可填**，2026-09-02 代码已改）｜ 名称 ｜ 说明文案 ｜ 生效中分配数 ｜ 状态；现状页内第二张「分配记录」表与其筛选栏**删除** `[L2]`

**AC2 · 抽屉页签一「编辑」**
**When** 点行 → `GET /admin/content-tags/{id}/drawer`
**Then** 表单：名称（三语）/ 说明 / 胶囊样式 `badgeStyle`（枚举 `ContentTagBadgeStyle`，含「打标影响排序」提示 1.2.0 既有）/ 图标 `iconFile`（PNG / WebP，≤512KB，最短边 ≥42px，推荐 112×112，编辑时可不换）；未修改保存禁用 → `POST /admin/content-tags/{id}/edit`（multipart，参数不变）`[L1]`
**And** 下线 / 重新上线：`POST /admin/content-tags/{id}/retire`，data-confirm 复述**生效分配数**（沿用 `admin.tags.retireConfirm`）`[L1]`

**AC3 · 抽屉页签二「分配记录」**
**Then** 该标签生效中分配列表：内容（id + 摘要）｜ 打标时间 ｜ **起止时间（WIB，永久显「永久」）｜ 状态（生效中 / 已到期）** ｜ 操作人 ｜ 移除；分页 `[L2]`
**And** 「＋添加内容」= **唯一打标入口**：抽屉内选择器（`GET /admin/content-tags/pick`，正文关键词 / 帖子 ID，防抖 300ms）→ `POST /admin/content-tags/assign`（标签定死为当前抽屉标签，参数 `tagId` 隐藏传）`[L1]`
**And** 移除 → `POST /admin/content-tags/assignments/{id}/remove`，data-confirm `[L1]`
**And** 现状页内独立「给内容打标」区块与顶部按钮废除 `[L2]`

**AC4 · 新建标签**
**When** 右上「新建标签」→ 抽屉空表单（名称 / 说明 / 样式 / 图标必传）→ `POST /admin/content-tags`
**Then** 成功后**自动打开新标签抽屉并停在「分配记录」页签** `[L2]`
**And** 标签码不出现在表单里（自动生成）`[L1]`

**AC5 · 权限与 htmx**
**Then** 查看 `content.tag_view`（`CONTENT_TAG_VIEW`）；写 `content.tag_manage`（`CONTENT_TAG_MANAGE`）；无 manage 抽屉操作禁用注明；全部 htmx 200/422/403 fragment `[L1]`

**AC6 · 三语与回归**
**Then** `admin.v130.tags.*` 三包；`AdminContentTagIntegrationTest` 全绿；四条 MockMvc；图标校验（`AdminTagIconService.MIN_SIDE=42`、`MAX_BYTES=512KB`）回归 `[L0/L1]`

### 🔴 起止时间已有，缺的是「状态」列
现状分配记录已显示 `startsAt` / `endsAt` / `permanent`（`content-tags.html` 212-232）。PRD §5 ③ 第 9 条要的增量是**状态列**（生效中 / 已到期）与把这张表挪进抽屉。不要重做时间字段。

### 🔴 标签码
2026-09-02 起 `ct-<id>` 由服务层生成，表单里若还有 `code` 输入请删掉（grep `name="code"`）。

### 端点零变更清单
`POST /admin/content-tags` · `{id}/edit` · `{id}/retire` · `/assign` · `/assignments/{id}/remove`。新增 GET：`{id}/drawer`、`new/drawer`。

### 与 Story 8.2 的同构
用户标签（B8）与本页同动线；8.2 复用本 story 的抽屉页签结构，但**没有徽章底色预设**（`UserTagBadgeColor` 已废弃）。先做本 story，8.2 照抄壳。
