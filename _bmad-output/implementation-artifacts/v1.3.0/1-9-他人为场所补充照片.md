# Story 1.9: 他人为场所补充照片

Status: ready-for-dev

## Story

As a 也去过这家店但照片更全的用户,
I want 给这个场所补几张照片,
so that 后面的人能看到更真实的样子，而不是只有标记人拍的那几张。

## Acceptance Criteria

**AC1 — 非标记人可补充** `[L2]`
场所详情页，非标记人的用户也可以为该场所补充照片，走既有上传链路与公开桶。

**AC2 — 标注上传者** `[L2]`
补充的照片**标注上传者**（2026-08-28 确认保留）。

**AC3 — 审核与 EXIF** `[L1]`
走既有三方自动审核（先发后审）+ EXIF 剥离服务端兜底。

## Tasks / Subtasks

- [ ] **T1 后端：照片归属**（AC: 1, 2, 3）
  - [ ] 场所照片需记录**每张的上传者**（Story 1.1 的照片列表若只是 URL 数组，本 story 要扩成带上传者的结构）
- [ ] **T2 前端：补充入口与标注**（AC: 1, 2）
- [ ] **T3 联调**（AC: 3）

## Dev Notes

### ⚠️ 这条会动 Story 1.1 建的结构

1.1 建表时照片可能只存了 URL 列表。本 story 需要**每张照片知道是谁传的**，因此要么扩成结构化列、要么另起一张 `place_photos` 表。

**动手前先看 1.1 的实际落地形态再决定**，并在 Completion Notes 写明选了哪种及理由。若另起表，表名带模块前缀（CROSS-STORY C3）。
