# Story 1.4: 地图选点

Status: review

## Story

As a 想标记一个我现在不在现场的地方的用户,
I want 在小地图上拖动大头针选位置,
so that 我回到家也能把白天去过的那家店标出来。

## Acceptance Criteria

**AC1 — SDK 使用边界（AD-3）** `[L0]`
只使用**显示地图 + 渲染我们自己的经纬度标记**两项能力。
🔴 **没有任何**地点搜索 / 自动补全、地址与坐标互转、路线规划调用。

**AC2 — 密钥管理** `[L0]`
密钥经 **env 注入**，示例文件只放占位，仓库内无明文密钥。

**AC3 — 选点交互** `[L2]`
在新建表单点「位置」打开选点弹层：地图默认落当前位置，大头针可拖动选任意位置，底部「确认位置」回填坐标。

**AC4 — 无定位兜底** `[L2]`
未授权定位时地图落在合理默认位置（如雅加达市中心），不空白、不崩。

**AC5 — 地图出现位置** `[L0]`
全 App 只有**选点弹层**与**详情页小地图**两处；**列表页不得嵌地图**（PRD ⑥「不做地图浏览视图」）。

## Dev Notes

### 🔴 越界即计费

地点搜索 / 自动补全、地址与坐标互转、路线规划**才是按次收钱的**。本项目**平台不做地理编码**（PRD ① 明定），所以天然不需要它们。谁要加，先回来改 AD-3。

**移动端原生地图显示本身免费且不限量**（2026-09-11 核实官方价目）；后台 Web 端每月前 1 万次免费，运营用量远在额度内。

### 密钥三套，别混用

iOS / Android / 后台 Web 各一套。本 story 只涉及前两套。每把加平台限制 + 每日调用配额上限——真正有泄漏计费风险的是后台那把 Web 密钥。

⚠️ **绑卡是前置条件**：Google Cloud 项目未开通结算时，密钥在正式包里不工作。这属于发版检查单 RC-2，不是本 story 能解决的——若拿不到可用密钥，本 story 阻塞，在 Completion Notes 写明。

### 与 Story 1.3 的衔接

1.3 交付时位置来源是"当前定位"。本 story **替换**那条路径为选点弹层，同时保留"默认落当前位置"的行为——即打开地图时针就在你所在处，不动它直接确认 = 与 1.3 等价。

### 验证层级

L0：AC1/2/5 · L2：AC3/4（需真机或模拟器给虚拟定位）

### Completion Notes List

**已交付（L0 全绿）**

1. **引入 `google_maps_flutter ^2.18.0`**（AC1）—— 本批次唯一一处 App 新依赖（AD-3）。
2. **🔴 边界做成了机械检查**（AC1/AC2/AC5）：`test/place/map_usage_boundary_test.dart`
   扫全仓源码 + pubspec + 两端原生配置，共 9 例：
   - **没有任何 Places / Geocoding / Directions 的调用面**（13 个特征串 + 4 个包名）。
     这条为什么必须机械守：**那三类才是按次收费的大头**，而加一行 geocoding 调用
     不会让任何测试变红、不会让界面出错，只会在下个月的账单上出现。
   - **`GoogleMap` 只允许出现在白名单文件里**（当前只有选点弹层；详情页小地图落地时
     把那个文件**加进白名单**，不是把测试删掉）。列表页另有一条专门断言它不含地图 ——
     那是 PRD ⑥ 明确排除的「地图浏览视图」。
   - **仓库内无明文密钥**：Android manifest 只有 `${googleMapsApiKey}` 占位符、
     iOS plist 只有 `$(GOOGLE_MAPS_API_KEY)` 构建变量，且两处都用
     `AIza[0-9A-Za-z_-]{30,}` 正则断言"不存在真实密钥形状的串"。
   - 模板文件存在且只放占位符；真实密钥文件**按整行**确认已 gitignored（见下方修复 5）。
3. **密钥 env 注入**（AC2）：
   - **Android**：`GOOGLE_MAPS_API_KEY_ANDROID` 环境变量 → 退到 gitignored 的
     `android/maps.properties` → 退到空串。经 `manifestPlaceholders` 注入，manifest 里没有明文。
     **刻意不让构建失败** —— 绝大多数开发/CI 任务与地图无关（同 release 签名缺失回退 debug 的取舍）。
   - **iOS**：gitignored 的 `ios/Flutter/Maps.xcconfig`（可选 `#include?`，文件不存在也能构建）
     → Info.plist 的 `GMSApiKey` → AppDelegate 读它初始化 SDK。
   - 两侧各有一个 `.example` 模板（只放占位符，**入库**），写明「只开 Maps SDK，
     不要开 Places/Geocoding/Directions」与「未绑卡则密钥在正式包里不工作（RC-2）」。
4. **选点弹层**（AC3/AC4/AC5）：`PlaceMapPickerSheet`。
   - 只用「显示地图 + 渲染我们自己的一个坐标点」；**刻意关掉** `myLocationEnabled`
     （蓝点会让地图 SDK 自己去要定位权限，而权限统一走 permission_handler）、
     `mapToolbarEnabled`（那个工具条直接跳 Google 地图的**路线规划**）、`zoomControlsEnabled`。
   - **默认落当前位置**，不动针直接确认 = 与 Story 1.3 等价（Dev Notes 明确要求保留这个行为）。
   - **无定位兜底落雅加达市中心**（AC4：不空白、不崩）。
   - 表单侧「在地图上选」**无论有没有定位权限都可点** —— 「人不在现场也能标」正是
     2026-08-28 把「必须现场标记」改成地图选点的原因，藏在权限后面等于把那条决策废掉一半。

**code-review 复审后修掉的（5 findings 全修）**

1. 🔴 **手势被弹层吃掉**：`GoogleMap` 默认不参与手势竞技场，而它在一个
   `enableDrag: true` 的 BottomSheet 里 —— 用户竖向平移地图或拖那个针，实际是把弹层拖走了，
   `onDragEnd` 永远不触发，只剩点击能用（而提示文案写的是「拖动大头针或点地图」）。
   → 加 `EagerGestureRecognizer` + 弹层 `enableDrag: false`（关闭走右上角 ✕）。
2. 🔴 **iOS 没配密钥会崩，不是灰地图**：`google_maps_flutter_ios` 建地图时走
   `[GMSServices sharedServices]`，而 SDK 在**从未 provideAPIKey** 时直接抛异常 ——
   原先「空值就不调用」的写法让未配置的包**一打开选点弹层就崩**，而 AC4 明写「不空白、不崩」。
   （Android 侧「空串 → 灰地图」是对的，两端在这一点上不一样。）
   → 改为**总是调用**，没配时传一个非空但显然无效的哨兵串：SDK 正常初始化、地图落标准
   「授权失败」空白态并在控制台留原因，而不是把 App 带走。
3. 🔴 **无定位时一进来就能确认 = 静默把市中心当成店址**：而场所**既不能编辑也不能删除**，
   这是一条永久坏数据。
   → 无定位时「确认位置」**禁用到用户真的动过针**（提示文案同步换成「点地图标出位置」），
   且初始缩放从 16 拉远到 12 —— 街道级缩放会让那个起点看起来像「系统已经帮你定好了」。
4. **已授权用户早点按钮会拿到雅加达兜底**：`ref.read(...).value` 在定位链路仍在跑
   （最长 5 秒 GPS 超时）时是 null。→ 改为 `await ref.read(placeLocationProvider.future)`。
5. **「密钥已 gitignored」那条测试形同虚设**：它用 `contains` 搜 .gitignore 文本，
   而两个文件名在**说明注释里也出现** —— 把真正那条忽略规则删掉，测试照样绿，密钥就这么进了仓库。
   → 改为**按非注释的整行**比对；另加一条反向断言：模板 `.example` **不得**被一起忽略
   （被忽略掉的话下一个人 clone 下来看不到它、不知道密钥放哪儿）。

**范围边界（有意不做）**

- **详情页小地图**归 Story 1.5（白名单里现在只有选点弹层一个文件）；
- **后台 Web 那套密钥**归 admin 主题 / 冷启动录入，本 story 只涉及 iOS + Android 两套；
- Google Cloud **开通结算 / 申请密钥**属发版检查单 **RC-2**，不是代码能解决的 ——
  **本 story 不阻塞**（没有可用密钥时地图是空白授权失败态，App 正常跑）。
