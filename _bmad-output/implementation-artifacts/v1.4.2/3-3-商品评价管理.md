## Story

As a 运营,
I want 隐藏违规评价并控制何时展示,
So that 历史评价先过一遍再上线.

## Acceptance Criteria

1. 商品编辑页 **Then** 加「商品信息 / 评价」页签，原表单不动（J1）〔L1〕
2. 评价列表含已隐藏、分页；空态 J2〔L1〕
3. 隐藏须选原因（J3），恢复须确认（J4），无删除入口〔L1〕
4. 隐藏后 App 不显示，均分条数重算〔L1〕
5. 运营配置「商品评价展示」开关默认关，打开须确认（J5、J6），权限 `config.edit`〔L1〕
6. 隐藏、恢复、开关写审计；不通知用户〔L1〕

- 后台分页查询走 `AdminProductReviewsService`（JDBC，`review_status = PUBLISHED`，含已隐藏，20 条/页，摘要：总数 / 显示中 / 已隐藏 / 显示中均分）；用户列只显示社区昵称（不回落 `display_name`，复审修）。
