### R. stag 上不可执行或需特殊造数的项

| 项 | 情况 | 处理 |
|---|---|---|
| 真实 QRIS 付款 / 网关回调 | stag 网关 P04 不出码 | 支付模拟 + 改库假码；真实回调与 GemPay 过期码查单（C-12）只能在生产前另测 |

| 迟到款 | 支付模拟不接受终态意图 | 改意图回 PENDING 再模拟（见 G 节说明），`paid_after_close` 以实际为准 |
| 多退少补 | 网关实收恒等于现金段 | 集成测试覆盖，⏭ |
| Biteship 真实报价 / 下单 / 保价字段 / 偏远邮编精度 | stub 模式，无测试 key | 生产前用沙箱 key 另测 |

| 飞书通知（发货提醒、告警）| stag 未配置 | 只看后端日志 |

**金额口径（全文共用，Rp，点分千位）**

- 应付 `T = total_amount`；原币段 `C = coin_amount`；原现金段 `= cash_amount`。
- 用户实付运费 `= shipping_fee + shipping_discount`（`shipping_discount ≤ 0`）；保价费 `= insurance_fee`；商品实付 `= T − 用户实付运费 − 保价费`。
- 两段拆分：币段 `= ⌊本次退款 × C / T⌋`，零头入现金段。
- 平台原因：退 `T − 已退`；用户原因：退 `商品实付 − 已退`、不补偿不退券；丢件破损：保价 = 商品实付，未保价 = 协商额（≤ 商品实付）、给补偿退券。
- UI 参照样例（D3~D7）：T=146.500、C=50.000、现金 96.500、实付运费 9.000、保价费 700、商品实付 136.800 → 用户原因 136.800 拆 46.689 / 90.111（UI 示意 46.690 为四舍五入，以计算器向下取整为准）；协商 100.000 拆 34.129 / 65.871；部分取消一行 38.000 拆 12.969 / 25.031；最后一行转整单剩余 108.500 拆 37.031 / 71.469（= 原币段 − 已退币段）。
- 期望值 SQL 模板：`SELECT display_no,total_amount T,coin_amount C,cash_amount,shipping_fee,shipping_discount,insurance_fee,discount_coupon_amount,refunded_total,refunded_coin FROM shop_orders WHERE display_no='…';`
