## Story

As a 运营,
I want 商城菜单按新结构排列、过期的复购页消失,
So that 后续页面有落点.

## Acceptance Criteria

1. 超管登录 **Then** 商城组出现「订单」（`/admin/shop/order-list`，订单履约前）、「退款打款」（`/admin/shop/refund-payouts`，退货审核后）、「优惠券」（`/admin/shop/coupons`，顶部 Banner 后），三页先渲染占位页〔L1〕
2. 新增权限码 `shop.coupon_view`、`shop.coupon_edit`，四份 properties 补文案，不预授〔L0〕
3. 无权限账号看不到对应菜单，直访 403〔L1〕
4. `/admin/shop/repurchase-dashboard` 返回 404；Controller、Service（无其他调用方时）、模板、Catalog 项、文案删除〔L0〕
5. 商品编辑页不再显示「未填每日建议喂量」警告与喂量卡顶部提示；角色页脚注去掉复购那句；喂量字段保留〔L1〕
6. `AuditActions` 按 PRD 文档头表补全动作码〔L0〕
7. `AdminPageCatalogTest`、`AdminPagesRenderSmokeTest` 同步更新〔L0 / L1〕
