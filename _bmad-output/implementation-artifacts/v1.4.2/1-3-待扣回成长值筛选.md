## Story

As a 运营主管,
I want 筛出待扣回成长值的订单,
So that 不用逐单翻.

## Acceptance Criteria

1. 下拉「全部 / 待扣回成长值」，选中后 URL 带 `filter=exp-reverse`，刷新保留〔L1〕
2. 结果只含 `reversible` 订单；常规退款中、无入账、已扣回、存量均不出现〔L1〕
3. 摘要条按筛选结果统计；导出仍是全表〔L1〕
4. 筛选下扣回成功后该行立即消失，摘要一致；抽屉里标记待核查后摘要仍按筛选集〔L1〕
6. 筛选结果为空显示「暂无待扣回成长值的订单」，删掉最后一行后不留空表头；未知 filter 值按全部〔L1〕
5. `summaryScope` 提示改写，不再写「本页暂无筛选」，四份 properties 同步〔L0〕
