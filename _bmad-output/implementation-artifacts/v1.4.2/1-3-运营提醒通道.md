## Story

As a 客服 / 运营 / 技术,
I want 需要人处理的事件发到各自飞书群,
So that 不用盯着后台.

## Acceptance Criteria

1. `OpsAlertService.send(channel, dedupeKey, text)` **Then** 三个 channel 各读 `LARK_SHOP_{CS,OPS,TECH}_WEBHOOK_URL` / `_SECRET`，空值只写 WARN〔L0〕
2. 事务提交后才发送，事务回滚不发；发送失败不影响业务〔L1〕
3. 同 `dedupeKey` 只发一次（迁移 `V20261106_1000`）〔L1〕
4. 文案不含手机号、地址、收款账户（测试断言）〔L0〕
5. 电商线告警按调用点分流：技术类走 TECH，运营类（确认收货、运单取消失败）走 OPS〔L0〕
6. `.env.example`、runbook 登记新 env〔L0〕
