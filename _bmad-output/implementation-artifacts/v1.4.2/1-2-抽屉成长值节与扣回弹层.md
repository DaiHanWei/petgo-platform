# Story 1.2：抽屉成长值节与扣回弹层

Status: review

> V1.4.2 · 主题 exp-reverse · 分支 `feat/1.4.2-exp-reverse`（从 `dev_1.4.2` 切出）。
> 口径优先级：`决策日志-exp-reverse.md` > PRD `电商/1-4-2退款扣回成长值修复prd.md` > `architecture-v1.4.2-exp-reverse-delta.md`。

## Story

As a 运营主管,
I want 在兽医订单抽屉确认并扣回成长值,
So that 不用找研发改数据.

## Acceptance Criteria

1. 抽屉有「成长值」节：当初入账、已扣回；无入账显示「—」，不显示按钮（E-4）〔L1〕
2. `reversible` 且有权限 **Then** 显示「待扣回」行与「扣回成长值」按钮〔L1〕
3. 只有 `order.view` 的账号看不到按钮，直接调两个端点返回 403；超管可成功执行〔L1〕
4. 点按钮打开公共确认弹层：入账、此前已扣回、本次扣回与说明；额度不可改，无原因输入〔L1〕
5. 确认后弹层关闭，提示实扣额，抽屉和列表行刷新，按钮消失并显示已扣回值〔L1〕
6. 弹层打开期间他人已扣回 **Then** 确认时错误显示在弹层内，弹层不关；抽屉过期时点按钮错误显示在抽屉内〔L1 断言 422 + L2 浏览器实点〕
7. 文案取 PRD §5 三语表，四份 properties 同步〔L0〕
