## Story

作为后台账号，
我想要下载答案附带的文件，
以便把明细转发给同事。

## Acceptance Criteria

1. **[L1]** 任务生成了文件时，文件卡显示文件名、大小和下载（C2）；**[L0]** 文件按对话写入独立目录，历史文件不会被重发。
2. **[L1，agent stub]** 用户下载本人对话的文件：ops 校验归属后从 agent 取回文件；写入 `AI_QUERY_DOWNLOAD`，摘要只含 token 和文件名。
3. **[L0 + L1]** 文件属于他人，或文件名含路径穿越：分别返回 404 和拒绝；agent 的 `name` 只允许匹配该任务文件清单。
4. **[L1]** 文件已被清除时，显示“已清除”和重新导出提示（C4）。
5. **[L2]** 已按明确指令部署到 stag 后，提问并要求导出文件，可以下载到正确文件。
6. **[L2]** 对照 `mockups/C2`、`C4` 还原度不低于 95%。

## Tasks / Subtasks

- [x] agent `files.mjs`：导出目录 `<EXPORT_DIR>/<对话>/<任务>/`，每个任务全新空目录；清单只取顶层普通文件（拒绝符号链接、子目录、隐藏文件）；任务结束后目录收回写权限（AC1、AC3）
- [x] agent `GET /jobs/{token}/files/{name}`：name 必须在该任务清单里；打开用 `O_NOFOLLOW` + `fstat` 复核；`pipeline` 流式输出（AC3）
- [x] agent 把导出目录经系统提示与 `AIQ_EXPORT_DIR` 告诉 claude；说明书 §4 写明导出规则；Dockerfile / 部署脚本加 `/exports` 卷（AC1）
- [x] ops `GET /admin/ai-query/{对话}/files/{消息}/{文件名}`：归属校验 → 流式取回 → `AI_QUERY_DOWNLOAD` 审计；他人 / 不存在 404，非法文件名 400，已清除 410，agent 不可用 502（AC2–AC4）
- [x] 文件卡（C2）与已清除态（C4，按该轮完成时间超过保留期判定）（AC1、AC4）
- [x] 测试：agent `test/files.test.mjs`；ops `AiQueryDownloadIntegrationTest`

## Dev Notes

- 文件名规则两端一致：不含 `/ \ NUL 换行 % ; ? #`、不以点开头、≤200 字。`% ; ? #` 会被后台 Spring Security 防火墙拒绝（编码后出现在路径里），列出来也下载不了。
- 「已清除」判定：该轮完成时间早于保留期起点；agent 返回 404 时同样显示已清除（410 页面）。文件本体随对话在 30 天后清理（Story 2.2）。
- 同一 uid 的限制：claude 各任务同 uid 运行，目录权限只能做到「不可列举 + 结束后不可改写」，靠不可枚举 token 防止发现别人的目录；残留风险已在 runbook §7 记录。
