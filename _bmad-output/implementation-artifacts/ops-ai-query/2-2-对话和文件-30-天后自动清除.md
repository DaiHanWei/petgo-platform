# Story 2.2: 对话和文件 30 天后自动清除

Status: review

<!-- 主题 ops-ai-query，不归属任何版本。分支 feat/ops-ai-query，基于 main。 -->

## Story

作为系统管理员，
我想要到期数据自动清除，
以便查询结果不会长期留存。

## Acceptance Criteria

1. **[L1，agent stub]** 对话最后更新超过 `AI_QUERY_RETENTION_DAYS`（默认 30）时，每日任务先调 `DELETE /conversations/{token}`，成功后再删库。
2. **[L1，agent stub]** agent 不可达时，清理跳过该对话，下轮重试，不删库。
3. **[L0]** agent 收到删除请求时，删除该对话的导出目录和 Claude 会话记录，重复调用保持成功。
4. **[L1]** 对话被清除后，审计记录保留，且不含问题原文。

## Tasks / Subtasks

- [x] agent 对话索引 `data/conversations/<token>.json`：任务开始即登记任务 token 与会话 id；新会话用 `--session-id` 预分配 UUID，超时 / 中断的任务也能找到会话记录（AC3）
- [x] agent `DELETE /conversations/{token}`：按索引删除会话记录（`~/.claude/projects/*/<sessionId>.jsonl` 及同名目录）、导出目录、任务结果与索引；幂等；仍有排队 / 运行中任务时 409（AC3）
- [x] 部署：agent 容器加回 `CAP_DAC_OVERRIDE`（删除 claude uid 创建的文件 / 子目录；切到 claude uid 时能力清空）；runbook §6 写明清理流程
- [x] ops `AiQueryCleanup`：每日 cron（默认 02:40 WIB，`AI_QUERY_CLEANUP_CRON`，`-` 关闭），游标遍历全部过期对话，先删 agent 成功后再删库（消息级联），失败跳过（AC1、AC2）
- [x] 测试：agent `test/cleanup.test.mjs`；ops `AiQueryCleanupIntegrationTest`（AC1–AC4）

## Dev Notes

- 清理与 `AI_QUERY_MODE` 无关：保留期是隐私要求，功能关闭期间照常清理；agent 未配置视同不可达，跳过并记 warn（导出文件与会话记录在 agent 上，不能只删库）。
- 删库用 `DELETE … WHERE id = ? AND updated_at < cutoff`：清理期间被追问刷新的对话不会误删。
- 审计表与对话表无外键，清理不影响审计；审计摘要本来就不含问题原文（Story 1.4 / 2.1）。
