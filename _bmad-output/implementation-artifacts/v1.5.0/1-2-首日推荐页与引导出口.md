## Story

As a 刚走完注册引导的新用户,
I want 引导最后看到一屏和我家宠物相似的毛孩子，能直接追更或点赞,
so that 我第一天就和别人有了互动。

## Acceptance Criteria

**AC1 — 发出首条后进推荐页（PRD AC1）** `[L0]` `[L2 Android 模拟器 + stag 后端]`
新注册、选有宠物、建档、在建档庆祝页点「Rekam Momen Pertama」进发布页（URL 带 `from=onboarding`），发布成功（有即时庆祝则庆祝关闭后）→ 进 `/onboarding/recommend?entry=after_post&landing=profile`，不再进 `/publish/done`。在发布页改发 Moment / Tips 同样进推荐页。

**AC2 — 没宠物（PRD AC2）** `[L0]` `[L2]`
宠物状态页选「没宠物 / 计划养 / 爱好者」→ 直接进推荐页（`entry=no_pet`），结束落 `/home`。

**AC3 — 跳过建档 / 不发帖（PRD AC3）** `[L0]` `[L2]`
建档引导点「Nanti saja」→ 推荐页（`entry=skip_profile`，落 `/home`）；建档庆祝页次链接 → 推荐页（`entry=skip_post`，落 `/profile`）；带 `from=onboarding` 的发布页返回 / 关闭不发 → 推荐页（`entry=skip_post`，落 `/profile`）。

**AC4 — 跳过 / 完成（PRD AC4）** `[L0]`
初始底部按钮「Lewati」（描边）；追更或点赞成功 ≥1 次后变「Selesai」（填充主色，A2）；右上角「Lewati」始终在；任一按钮 → `go(landing)`。顶栏无返回箭头；系统返回键等同「Lewati」。

**AC5 — 只出现一次（PRD AC5）** `[L0]` `[L2]`
进推荐页前读 `GET /me/onboarding-marks`：含 `first_day_recommend` → 不进推荐页、直接 `go(landing)`；推荐页首帧渲染成功后 `POST {key:"first_day_recommend"}`（best-effort，失败静默）。读标记失败 → 视为未看过（照常展示）。

**AC6 — 失败或空（PRD AC6）** `[L0]`
`GET /me/pet-recommendations?limit=6` 失败或 `items` 为空 → 不出现空白页，直接 `go(landing)`（同时写标记，避免下次再进）。加载中显示 A4 骨架。不足 6 只按实际只数渲染（A3）。

**AC7 — 卡片（A1 / A2）** `[L0]`
2 列网格，间距照 `pet_recommendation_grid.dart`（16 / 12）；卡片复用 `RecommendedPetCard`：大图右上角点赞胶囊（心形 + `coverLikeCount`，绑定 `coverPostId`，用现有 `LikeButton` 的状态机 / 乐观更新；`coverPostId == null` 不显示胶囊）、卡下 `PetFollowButton` 的 `listCompact`；**头像 / 名字点击不跳转**（推荐页里关闭卡片的 onTap）。点赞胶囊、追更按钮可点区域 ≥ 44×44（视觉尺寸不变）；赞数用 `FontFeature.tabularFigures()`。追更失败 → A5 toast（沿用按钮现有失败提示）。

**AC8 — 第二行改品种（FR-174 卡片第二行）** `[L0]`
`RecommendedPetCard` 第二行改「`breed` · Bersama N hari」，`breed` 为空回落现有物种名；所有使用处（Diary 空态网格、集合页、推荐页、游客区）一起变。`PetStripTile`（社区横条小卡）不改。

**AC9 — 文案** `[L0]`
标题复用 `petRecommendSectionTitle`；副标题新增两条（有宠物带默认宠物名 / 没宠物），ID / EN 逐字照整合稿「新增文案」表：
- 有宠物：ID `Ini geng anabul yang mirip {name} 🐾 Yuk, ikuti atau kasih like!` / EN `Meet {name}'s lookalike gang 🐾 Follow them or send a like!`
- 没宠物：ID `Banyak anabul gemas nungguin kamu nih 🐾 Ikuti yang bikin kamu jatuh hati!` / EN `So many cuties are waiting for you 🐾 Follow the ones that steal your heart!`
「Lewati / Selesai」沿用现有 key。

**AC10 — 埋点（PRD §4 FR-173）** `[L0]`
- `onboarding_recommend_viewed {entry, card_count}`（首帧渲染时一次）
- `onboarding_recommend_action {action: pet_follow|post_like, pet_id, position, match}`（成功后；`position` 从 0 起；`match` = 后端字段转小写 `same_breed|same_species|global`）
- `onboarding_recommend_exited {button: skip_top|skip_bottom|done, follow_count, like_count}`
事件名 / 属性写字面量，登记到埋点守卫测试（`test/analytics/` 下现有事件清单测试），不放宽正则。

**AC11 — 互动计入现有链路** `[L1 本地后端]`
推荐页点赞与帖子详情点赞完全一致（同一接口：赞数 +1、作者收到点赞通知、点赞者得成长值）；追更走 `POST /api/v1/me/pet-follows/{petId}`。
