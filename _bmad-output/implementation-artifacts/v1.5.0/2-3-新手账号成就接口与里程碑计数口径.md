## Story

As a 没有宠物（或有多只宠物）的用户,
I want 账号级成就单独成一块、不重复计入每只宠物的进度,
so that 进度数字准确，没宠物也能看到自己的成就。

## Acceptance Criteria

**AC1 — 账号级里程碑接口** `[L0]` `[L1]`
`GET /api/v1/me/account-milestones`（USER）返回：
```json
{ "items": [
    {"flagKey":"FIRST_FOLLOW_USER","code":"C-S19","completed":true,"completedAt":"2026-11-15T03:00:00Z","pendingCelebration":false},
    {"flagKey":"FIRST_COLLECT_CONTENT","code":"C-S20","completed":false,"completedAt":null,"pendingCelebration":false},
    {"flagKey":"LULUS_PEMULA","code":"C-S16","completed":false,"completedAt":null,"pendingCelebration":false} ],
  "completedCount": 1, "totalCount": 3 }
```
- 顺序固定：Teman pertama / Simpan pertama / Lulus Pemula。`completed` 以 `user_milestone_flags` 是否有行为准；`completedAt = occurred_at`。
- `code` 取账号默认宠物（`DefaultPetPolicy`）物种的编码；无宠物取 CAT 编码。
- `pendingCelebration` 只对 `LULUS_PEMULA`：flag 存在且 `celebrated_at IS NULL`。

**AC2 — 账号级庆祝回报** `[L1]`
`POST /api/v1/me/account-milestones/celebrations {codes:[...]}`：codes 里的账号级编码（任一物种写法都认）→ 置对应 flag `celebrated_at`（只置 NULL）+ 该账号全部宠物同 flag 完成行 `celebrated_at`（只置 NULL）；非账号级编码静默忽略；返回 `{marked}`。best-effort 语义同现有宠物回报端点。

**AC3 — 宠物里程碑列表新口径（PRD AC26）** `[L0]` `[L1]`
≥ 1.5.0 客户端 `GET /api/v1/pet-profiles/me/milestones?petId=`：
- 新增 `accountGroup`（结构同 `MilestoneGroupResponse`，`level = "ACCOUNT"`，3 项，顺序同 AC1，每项照常带完成 / 庆祝状态）；
- S 组去掉这 3 个编码；顶层与 S 组 `completedCount / totalCount` 都不含它们（猫 / 狗 35 → 32，其他 20 → 17）；
- 两只宠物之间切换，`accountGroup` 内容一致（都是账号事实，因 2-2 完成行同时写；以 flag 为准渲染完成态，避免某只宠物 roster 缺行导致不一致）。

**AC4 — 旧版不变** `[L0]`
< 1.5.0：`LegacyMilestoneCompat.forClient` 输出与改动前逐字一致（1.4.2 ≤ v < 1.5.0 三个编码仍在 S 组且计入计数；< 1.4.2 仍去掉 1.4.2 两个编码）。注意：Lulus 编码原本就在 S 组，旧版继续在 S 组。

**AC5 — 同一口径的其他计数** `[L0]` `[L1]`
新增 `profile/service/MilestoneCounting`（唯一计数入口：`isAccountLevel(code)` + 宠物计数 `(completed, total)` 排除账号级）：
- 作者态 Diary 统计（`ArchiveStatsResponse` 的里程碑完成数 / 总数，`TimelineService` 或其所在服务）：≥ 1.5.0 新口径，旧版旧口径（与该版本列表页一致）；
- 访客视图 `VisitorStats` / `VisitorProjectionService` 与 H5 名片 `CardPageController`：一律新口径（服务端直出、他人宠物，不分版本）；
- 凡是还有别处自己算里程碑数的（`grep milestoneCompleted|completedCount|totalCount`），改为调 `MilestoneCounting`，不能一处算一处不算。

**AC6 — 账号成就保持（PRD AC25 后端部分）** `[L1]`
无宠物账号完成「第一次关注一个人」后建第一只宠物 → 新宠物列表 `accountGroup` 中该项已完成（1.4.2 `applyExistingFlagsToPet` 写「已完成且已庆祝」），`/me/account-milestones` 照旧完成。
