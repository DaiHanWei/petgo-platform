## Story

As a 产品操作者,
I want 推送与召回在真库、真机推送上逐条验过，并拿到一份上线开关清单,
so that 上线当天知道谁、什么时候、开哪个开关、出事怎么关。

## Acceptance Criteria

**AC1 — L0 汇总** `[L0]`
后端 `./mvnw -B clean package -DskipTests` + Epic 5 ~ 6 各 story L0 测试类全绿；App `flutter analyze`、Epic 7 相关 `flutter test` 全绿；`bash scripts/ci/check-flyway-versions.sh origin/main` 通过。

**AC2 — L1 全链路** `[L1 本地 Docker postgres + redis]`
Epic 5 ~ 6 全部 `*IntegrationTest` + `notify` 包集成测试全绿；`spring-boot:run` 健康 UP；把三个日扫的 cron 临时改成近一分钟（env 覆盖）手工触发一次，核对 `scheduled_push_marks`、`lifecycle_push_marks`（variant `<层>_<变体>`）、`user_post_notify_log` outcome 分布。

**AC3 — L2 真机推送** `[L2 Android 真机 / 模拟器 + stag 后端 + 真 Google 登录 + 腾讯推送]`
- 关注更新：A 关注 B，B 发 Moment / Diary / 私密 / 当天第 2 条 → 推送与通知中心行为（PRD AC1 ~ AC6）；TailUs 账号发帖无推送；关分类后不推照写。
- 上限：A 当天第 4 条关注 / 追更更新不推（PRD AC8）。
- 纪念日：stag 造建档 30 天宠物（双宠同天、只读宠物）→ 19:00 推送 → 点开直达发布页选中该宠物（PRD AC10 ~ AC14），App 杀掉后点推送同样直达（AC23）。
- 生日：11:00 推（AC27 / AC28）。
- 召回：造 D1 五类用户（A ~ E）+ 当天已打开一个 + D7 刚毕业 / 4/7 → 文案、落点、毕业补弹（PRD AC15 ~ AC22）；旧版包用户不收召回、收关注更新通知不推。
- UI：16 屏逐屏截图对照，还原度每屏 ≥ 95%，分数写进 Completion Notes。

**AC4 — 运营文档** `[L0]`
更新 `docs/ops/retention-push-copy-matrix.md`：文案矩阵换成附录 A 定稿（节点 × 分层 × 落点 × copy 键）、「已上线」说明改为「1.5.0 起 D1 / D3 / D7 线上开启、召回节点默认关」、删掉召回节点「默认可用」的描述；补纪念日 19:00 / 生日 11:00 / 关注更新上限三条。

**AC5 — 上线清单** `[L0]`
在本 story Completion Notes 写上线清单（同时追加到 `docs/runbooks/` 下现有发布 runbook 的 1.5.0 段，若无合适文件则写进上面的运营文档末尾「上线步骤」节）：
| 时点 | 动作 | env | 谁 |
|---|---|---|---|
| 部署前 | 确认 prod / stag env：`LIFECYCLE_PUSH_ENABLED=true`、`LIFECYCLE_PUSH_DAILY_CAP=300`、`LIFECYCLE_WINBACK_ENABLED=false`（不写即默认 false）、`FOLLOW_UPDATE_PUSH_ENABLED` / `ANNIVERSARY_PUSH_ENABLED` 不写（默认 true） | 服务器 `~/.env.petgo` / stag 对应文件 | 研发 + 运维（操作者确认后） |
| 部署 | 按部署脚本重建容器（`docker restart` 不重读 env） | — | 研发 |
| 第 1 ~ 2 天 | 看推送分类关闭率（`push_category_toggled`）与投诉，护栏 ≤ 上线前 1.5 倍 | — | 产品 |
| 第 3 天 | 删 `LIFECYCLE_PUSH_DAILY_CAP`（回默认 2000），重建容器 | 同上 | 研发 |
| 回滚 | 生命周期 `LIFECYCLE_PUSH_ENABLED=false`；关注更新 `FOLLOW_UPDATE_PUSH_ENABLED=false`；纪念日 `ANNIVERSARY_PUSH_ENABLED=false`；均重建容器生效 | 同上 | 研发 |
并注明：前后端须同批发布（新落点 / 直达依赖 1.5.0 App）；🔴 云端与本地 agent **不执行任何部署**，清单只供操作者使用。
