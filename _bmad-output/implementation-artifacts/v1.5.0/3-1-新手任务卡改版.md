## Story

As a 新用户,
I want 任务卡直接告诉我下一件该做什么、点一下就能去做,
so that 我能一步步完成新手任务。

## Acceptance Criteria

**AC1 — 收起态（C1）** `[L0]`
显示标题「Tugas Pemula」、进度 `x/7 selesai` 与进度条、浅紫底块（小标题「Habis ini, coba 👇」+ 按 ①→⑦ 取的**第一项未完成**任务行，带其「去完成」按钮）、下方「+N tugas lainnya」（N = 7 − 1）展开。现有「露前 4 项」改掉。

**AC2 — 展开态（C2 / C3）** `[L0]`
7 项按序，每项图标（完成 `check_circle` / 未完成 `radio_button_unchecked`）+ 任务名 + 右侧动作：
| # | 未完成时右侧 |
|---|---|
| ① | 有宠物「Yuk!」→ `/publish?preset=growth-calendar`；无宠物（`hasPet=false`）「Buat profil」→ `/profile/create` |
| ② | ① 未完成：「Yuk!」→ 发布页（同 ①）；① 已完成：不放按钮，只显示提示「Posting Diary dulu, nanti teman-teman mampir kasih like 😉」 |
| ③ | 「Yuk!」→ `/pet-recommendations` |
| ④ ⑤ | 「Yuk!」→ `/home`（社区首页） |
| ⑥ | `replyGoPostId != null`：「Yuk!」→ 该帖评论区（帖子详情并滚到评论 / 打开评论输入，复用现有「去评论区」入口参数）；否则不放按钮，提示「Tunggu ada yang komen di postinganmu ya 👀」 |
| ⑦ | 不放按钮，显示「{n} hari lagi!」（`oneWeekDaysLeft`，等宽数字） |
已完成项不显示动作。「Lihat lebih sedikit」收起。

**AC3 — 完成横幅（C4）** `[L0]`
`lulusPemulaUnlocked == true`（含按旧 6 项解锁的老用户）**或** `completedCount >= total` → 只显示 🎓 完成小横幅（沿用现状样式），不显示未完成项。

**AC4 — 失败态（C5）** `[L0]`
接口失败 → 现有 `newbieCardError` + 重试；404 不再出现（新接口无宠物也 200），保留按错误处理的兜底。

**AC5 — 文案** `[L0]`
7 个任务名、「Yuk! / Buat profil」、②⑥提示、⑦剩余天数、收起小标题，ID / EN 逐字照整合稿「新增文案」表写进 `app_id.arb` / `app_en.arb`；`features/profile/domain/newbie_task_labels.dart` 改为 7 个新 key 的映射（旧 6 key 删除；未知 key 兜底改为不渲染该行，而不是露原始 key）。

**AC6 — 热区与数字** `[L0]`
「Yuk!」等按钮可点区域 ≥ 44×44（视觉尺寸不变）；`x/7`、`{n} hari lagi!` 用 `FontFeature.tabularFigures()`。

**AC7 — 埋点（PRD §4 FR-176）** `[L0]`
`newbie_task_card_viewed {page: pet_milestones|account_milestones, done_count}`（卡片首次成功渲染）；`newbie_task_go_tapped {task: 1–7}`。登记到埋点守卫测试。

**AC8 — 进度刷新** `[L0]`
从「去完成」返回里程碑页后刷新新手任务（`ref.invalidate`）；`newbieTasksProvider` 登记到换账号缓存重置（`app.dart` `resetUserScopedCaches`，若尚未登记）。
