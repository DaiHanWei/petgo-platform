## 为什么有这条 story

V1.5.0 九份 PRD 分六个云端会话并行。① 健康提醒、③ 推送与召回、⑥ 运营活动都要往 `ck_notifications_type` 加值（该约束已漏过 4 次），② 超值礼包与 ④ 物种扩展都要往 `OpsAppPage` 末尾加值，① 与 ③ 要共用「App 最后上报版本 ≥ 1.5.0」判定，① 还要读 ③ 提供的「召回日」「纪念日占位」。这些若各分支自己做，并行开发时会各造替身、合并时约束丢值。本 story 把它们一次落进 `dev_1.5.0`。
