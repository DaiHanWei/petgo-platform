## Story

As a 还没登录的游客,
I want 在 Diary 展示页看到真实的宠物和它们的最新帖子,
so that 我知道这里有真实的社区、愿意注册。

## Acceptance Criteria

**AC1 — 真实宠物区（PRD AC11）** `[L0]` `[L2 Android 模拟器]`
`diary_guest_page.dart` 在情感文案块之后、吸底按钮之前插入横滑区：标题照 B1、卡宽 140、最多 6 张；卡片复用 `RecommendedPetCard`（第二行品种 · 陪伴天数、大图右上角点赞胶囊、卡下追更按钮）。示例条、页头、示例时间线、吸底按钮**一律不动**。

**AC2 — 点图进帖子** `[L0]`
点卡片大图 → `/content/{coverPostId}`（游客可看）；`coverPostId == null` 时点图无动作。头像 / 名字点击沿用卡片现有行为（`requireLogin` 后进宠物页）。

**AC3 — 追更 / 点赞弹登录、不自动补做（PRD AC12）** `[L0]`
游客点追更或点赞胶囊 → 现有硬登录（`requireLogin`），`entry_source = 'guest_real_pets'`；登录（新注册则走完引导）后**不**自动追更 / 点赞（沿用 `PetFollowButton` / `LikeButton` 现有游客行为，不加 pendingAction）。

**AC4 — 断网 / 失败 / 空（PRD AC13）** `[L0]`
接口失败、超时或 `items` 为空 → 整块（含标题）不渲染，页面其余部分照常；加载中显示 B2 骨架（不阻塞页面其他部分渲染）。不出现报错条。

**AC5 — 埋点（PRD §4 FR-175）** `[L0]`
- `guest_real_pets_viewed {card_count}`（区块首次成功渲染时一次）
- `guest_real_pets_tapped {action: open_post|pet_follow|post_like, pet_id, position}`
- 登录成功事件经现有 `entry_source` 传播即可区分（新值 `guest_real_pets`）；登记到埋点守卫测试。
