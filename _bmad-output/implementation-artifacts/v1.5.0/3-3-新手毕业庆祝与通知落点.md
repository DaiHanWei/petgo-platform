## Story

As a 刚完成全部新手任务的用户,
I want 点通知或进里程碑页时看到一次 Lulus Pemula 庆祝、并能分享到社区,
so that 毕业有仪式感。

## Acceptance Criteria

**AC1 — Lulus 编码并入账号级** `[L0]`
`milestone_account_codes.dart` 加 `C-S16 / D-S16 / G-S9`；由此补庆祝取多宠数据、回报后整组失效、多宠庆祝页布局（显示全部 ACTIVE 宠物头像与名字、不显示 KOLEKSI）三处自动覆盖 Lulus（`milestone_list_page.dart:129 / :169-175`、`widgets/milestone_celebration.dart:224 / :343`），测试钉住。

**AC2 — 庆祝文案（E2 / E3）** `[L0]`
`milestone_celebration_copy.dart` 给三个 Lulus 编码加条目：标题 ID「Lulus Pemula! 🎓」/ EN「Beginner graduate! 🎓」，正文 ID「Semua Tugas Pemula beres! Selamat datang resmi di geng TailTopia.」/ EN「All Beginner Tasks done! Welcome to the TailTopia gang, officially.」（逐字照整合稿），不带宠物名。徽章大图 `lulus_pemula.webp`。

**AC3 — 补弹一次（PRD AC22）** `[L0]` `[L1]`
- 有宠物：进宠物里程碑页时，现有补庆祝机制弹一次（Lulus 未庆祝行），回报走宠物端点（后端同时置 flag，2-2 AC9）。
- 无宠物：进账号级里程碑页（`/me/achievements`）时，`/me/account-milestones` 中 Lulus `pendingCelebration == true` → 弹一次（E4 布局），展示成功后异步回报 `POST /me/account-milestones/celebrations`（best-effort，失败下次再弹）。
- 整个账号只弹一次：任一处弹过并回报成功后，另一处不再弹。

**AC4 — 没有正常宠物时分享（E4）** `[L0]`
庆祝页「Bagikan ke Komunitas」保留：有 ACTIVE 宠物 → 照 1.4.2 预选 Diary 并选中全部 ACTIVE 宠物；没有 ACTIVE 宠物 → 发布页预选 **Moment**（带里程碑卡），预填正文 ID「Yeay, aku baru buka tonggak "{title}"! 🎉」/ EN「Yay, I just unlocked the "{title}" milestone! 🎉」（`milestone_compose_preset.dart` 加分支）。

**AC5 — 通知中心毕业通知（E1）与落点** `[L0]`
`MILESTONE_SM_NODE` 且 `targetRef` 是 Lulus 编码：标题 / 正文按 Lulus 文案本地化（现有 `_milestoneCopy` 走 code 查表即可覆盖）；点击 → `/me/milestones-entry?celebrate=lulus`（`deep_link_routes.dart` 给 `MILESTONE_SM_NODE` 加这一条映射，其余 `MILESTONE_SM_NODE` 维持进通知中心现状）。目标页收到 `celebrate=lulus` 时优先触发补弹（若已庆祝则不弹）。

**AC6 — 成长值明细** `[L0]`
`growth_labels.dart` 加 `NEWBIE_GRADUATED`：文案（新 arb key，ID「Lulus Pemula」/ EN「Beginner graduate」）+ 图标 `Icons.school_rounded`；等级页规则列表若按后端 `RULE_ORDER` 渲染需要标签同样补上。
