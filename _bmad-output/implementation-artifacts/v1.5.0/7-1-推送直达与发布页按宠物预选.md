## Story

As a 收到推送的用户,
I want 点开推送直接到要做事的那一页（纪念日直接选好这只宠物的发布页）,
so that 不用先进通知中心再找。

## Acceptance Criteria

**AC1 — 直达名单（PRD AC22 / AC23）** `[L0]`
`core/push/push_service.dart` `kPushDirectTypes` 追加 `USER_POST_PUBLISHED`、`PET_DIARY_POSTED`、`COMPANION_ANNIVERSARY`、`LIFECYCLE_D1`、`LIFECYCLE_D3`、`LIFECYCLE_D7`（保留现有 3 个；🔴 只加本线 6 个，健康提醒 / 运营活动线会往同一集合加，合并取并集）。App 在后台或被杀掉时点这些推送 → 直接到落点，不经过通知中心；点推送照常把对应通知标已读（现有行为不变）。

**AC2 — 落点映射（`deep_link_routes.dart` `pushPayloadToLocation`）** `[L0]`
| type | targetRef | 落点 |
|---|---|---|
| `USER_POST_PUBLISHED` | 帖子 id（数字） | `/content/{id}`；非数字 → `/notifications` |
| `COMPANION_ANNIVERSARY` | 宠物 id | `/publish?preset=growth-calendar&petId={id}&entry=push_anniversary`（新旧通知同一映射，PRD AC14） |
| `LIFECYCLE_*` + `DISCOVER` | — | `/pet-recommendations` |
| `LIFECYCLE_*` + `NEWBIE_TASKS` | — | `/me/milestones-entry` |
| `LIFECYCLE_*` + `GRADUATED` | — | `/me/milestones-entry?celebrate=lulus` |
| `LIFECYCLE_*` + `RECORD` | — | 现有发布页预选 Diary，追加 `&entry=push_lifecycle` |
| 其余现有 | — | 不变（`FEED` → `/home`、`CREATE_PROFILE` / 未知 → `/profile/create`、`REVIEW` → `/profile`） |
`PET_DIARY_POSTED` 落点不变（`/content/{id}`），只是变成直达。

**AC3 — 帖子已删（A4）** `[L0]`
直达 `/content/{id}` 帖子已删 → 详情页现有失效态（`EmptyState`：search_off + 「Konten ini sudah tidak ada」+「Kembali ke Sosial」），不新做。

**AC4 — 发布页 `petId`（PRD AC11 / AC24，B3）** `[L0]`
- `app_router.dart` `/publish` 解析 `petId`（int）与 `entry`（只认 `push_anniversary / push_lifecycle`），经 `PublishLandingPage` 透传为 `PublishComposePage` 的 `initialPetIds: [petId]` 与 `entry`。
- `PublishComposePage`：`petId` 不在本账号 **ACTIVE** 宠物里（别人的、已删、只读）→ 忽略，走现有默认宠物逻辑，不报错、不提示。
- 有效时：类型 Diary、只选中这一只（默认宠物不选）、正文占位随选中宠物变（现有 `publishHintGrowth`）；不预填正文、不带 `milestoneCode`。
- 冷启动直达发布页：关闭 / 发布后回上一页，无上一页 → 首页（`PublishLandingPage` 现有兜底）。

**AC5 — 发布成功埋点 `entry`（PRD §4）** `[L0]`
`diary_published` 在 `entry` 非空时带 `entry: push_anniversary | push_lifecycle`；其余入口不带（不改现有 `source` 属性）。登记埋点守卫。

**AC6 — 召回落点页面行为** `[L2]`
D1 / D3 `DISCOVER` 进推荐宠物集合页（排序按 1-1：有宠物同品种在前）；D7 进里程碑页（有宠物 → 宠物里程碑页新手任务卡；无宠物 → 账号级里程碑页）；`GRADUATED` 进页后弹 Lulus 庆祝一次（3-3 的 `celebrate=lulus`）。
