# Story 1.6: 运营活动名按语言下发（后端）

Status: ready-for-dev

> 版本 v1.5.0 · 会话 ⑥ ops-activity · 分支 `feat/1.5.0-ops-activity`
> 口径优先级：`decision-log.md`（11-12 名称 ID / EN 都必填按界面语言显示；11-13 PawCoin 记录显示「Event · 活动名」）> PRD §3.7、§6「新版 EXP 明细接口有活动 ID 时按用户界面语言返回对应名称」「PawCoin 流水 `_txnLabel` 先看 `refType = ACTIVITY`」> 架构 OA-19、§4.1、§6。
> 前置：1-2（`growth_ledger.activity_id` 已有）。
> 范围层：**只后端**。App 显示归 3-2。

## Story

As a 用界面语言为英语（或印尼语）的用户,
I want EXP 明细与 PawCoin 记录里的活动名按我的语言显示,
so that 「Event · {活动名}」读得懂。

## Acceptance Criteria

### AC1 — EXP 明细 `[L0]` `[L1]`
`B/growth/service/GrowthLedgerPageQuery`：
1. `PAGE_SQL` 改为 `SELECT g.…, a.name_id AS act_name_id, a.name_en AS act_name_en FROM growth_ledger g LEFT JOIN ops_activities a ON a.id = g.activity_id WHERE g.user_id = :u AND (g.created_at, g.id) < (:ts, :id) ORDER BY g.created_at DESC, g.id DESC LIMIT :limit`（保持原排序与游标语义）。
2. `page(userId, cursor)` / `recent(userId, n)` 取 `AccountQueryService.localeOf(userId)`：有活动名时 `note` = EN → `act_name_en`，否则 `act_name_id`；无活动 id 的行 `note` 原样（手动发放 / 批量发放 / 运营调整不变）。
3. `GrowthLedgerRow` 结构**不变**（旧版 App 同样拿到按语言的名称，无副作用）。
4. L0：`GrowthLedgerPageQueryTest`（若无则新建，用 Mockito 的 `NamedParameterJdbcTemplate` 或纯函数 `noteFor(rawNote, actNameId, actNameEn, locale)`）：EN / ID / 无活动三路。
5. L1：`GrowthLedgerActivityNameIntegrationTest`：同一用户的活动发放行 + 扣回行，EN 用户看到英文名，ID 用户看到印尼语名；手动 `OPS_CAMPAIGN` 行原样。

### AC2 — PawCoin 流水 `refLabel` `[L0]` `[L1]`
1. pay 包新增端口 `B/pay/service/PawCoinRefLabelResolver`：`String refType()`、`Map<Long, String> labels(Collection<Long> refIds, java.util.Locale locale)`。
2. `PawCoinQueryService.view(...)`：注入 `ObjectProvider<List<PawCoinRefLabelResolver>>`（或 `List<PawCoinRefLabelResolver>`，可为空）；对本页行按 `refType` 分组、每组一次批量解析；`locale` 取 `AccountQueryService.localeOf(userId)`。**不跨模块 join**（保持该类注释约定）。
3. `PawCoinTxnItem` **末尾追加** `String refLabel`；保留 `from(PawCoinTransaction t)`（`refLabel = null`）并加 `from(t, refLabel)`；全局 NON_NULL，非活动行 JSON 不出现该键；`refId` 仍不下发。
4. opsactivity 实现 `OpsActivityPawCoinLabelResolver`（`refType() = "ACTIVITY"`）：`SELECT id, name_id, name_en FROM ops_activities WHERE id IN (:ids)`，按 locale 取名；活动已删（不会发生：只有草稿可删）→ 不返回该 id（App 落「Bonus」）。
5. L0：`PawCoinQueryServiceTest` 补：活动行带 `refLabel`、其他行不带、无解析器时不报错；`PawCoinTxnItemJsonTest`：`refLabel` 为 null 时 JSON 无该键。
6. L1：`PawCoinActivityLabelIntegrationTest`：活动发 PawCoin 后，`GET` PawCoin 流水接口（现有路径）该行 `refType = "ACTIVITY"`、`refLabel` 按语言。
