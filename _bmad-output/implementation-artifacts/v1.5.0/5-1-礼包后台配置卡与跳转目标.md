## Story

As a 运营,
I want 在运营配置页改三档价格、一键停售，并能把开屏弹窗 / 系统通知跳到礼包页,
so that 我能控制礼包的售卖与推广。

## Acceptance Criteria

### AC1 — 配置卡 H `[L0]` `[L1]`
1. 新片段 `T/fragments/config-card-value-pack.html`，套 `tpl-d-config-card`，在 `T/config.html` 里插在 `config-card-pet-slot` 之后。
2. 三个价格字段照 `config-card-pet-slot` 的价格行（`min=100`、`max=100000000`、Rp 前缀、行内报错）；每档旁显示参考价「单买合计 Rp{0}（按当前单价）」——服务端用 `StarterPackTier.separateTotal(pricing)` 算（4-2）。
3. 总开关用复选框（同 `config-card-share-reward`）；**取消勾选保存**时走 `data-confirm` 原生确认（停售确认文案），重新勾选不确认；停售时卡片标题旁显示「已停售」标签。只读权限：总开关灰显（H5 修过的样子）。
4. `AdminConfigService.updateStarterPack(StarterPackConfigForm form, long adminId)`：价格 ≥ 100 且 ≤ `MAX_TIER_AMOUNT`（否则 422，码 `admin.err.config.starterPackPriceMin` / `…Max`，文案「价格须为 ≥100 的整数（IDR）」三语）；真变化才写 `config_change_logs`（PRICING，字段名 = 列名）+ 审计 `commit(logs, adminId, "VALUE_PACK", "pricing_config")` → action `CONFIG_UPDATE_VALUE_PACK`；无变化不写不审计。
5. flash 三条按变化类型取：只改价「超值礼包价格已更新（仅影响之后的新购买；操作留审计）」、关「超值礼包已停售（已买的次数照常可用；操作留审计）」、开「超值礼包已恢复销售（操作留审计）」；同时改价和开关 → 取开关那条。
6. 权限沿用 `CONFIG_VIEW` / `CONFIG_EDIT`。
7. L0：`AdminConfigServiceTest` 补：价格下限 / 上限、无变化不审计、开关变化审计。
8. L1：`AdminConfigIntegrationTest` 补：卡片渲染、保存、只读。

### AC2 — 跳转目标 N `[L1]`
1. `OpsAppPage.STARTER_PACK` 已由地基加入，弹窗与系统通知的「App 页面」下拉**自动出现**；本 story 只改说明文案：`admin.opsPopups.form.targetHint`、`admin.opsNotify.form.targetHint` 按 PRD B §8 N 泳道原文（三语）改写。
2. 弹窗编辑抽屉：选了「超值礼包页」且 `starterPackEnabled = false` → 抽屉内出 `banner warn`「超值礼包已停售：App 里点按钮只会关闭弹窗，不会跳转。」（三语）。系统通知编辑页同样提示（PRD：停售时点开通知 App 只弹 toast 不跳转）。
3. **不改** `OpsAppPage` 枚举、不改 `admin.opsPopups.appPage.STARTER_PACK`（地基已加）。后台稿里写的 `VALUE_PACK` 一律按 `STARTER_PACK` 落地。
4. L1：`OpsPopupAdminIntegrationTest` 补：停售时 banner 出现、开售时不出现。
