## Story

As a 没宠物的用户（或有多只宠物的用户）,
I want 在「我的」页能进自己的成就页、在宠物里程碑页单独看到账号成就,
so that 账号级的成就不会被重复计算或找不到。

## Acceptance Criteria

**AC1 — 宠物里程碑页账号成就区（C1 / C3，PRD AC26）** `[L0]`
`milestone_list_page.dart` 在 L / M / S 分区**上方**加「Pencapaian akun」区，右侧 `x/3`，3 个徽章（Teman pertama / Simpan pertama / Lulus Pemula 🎓），数据取列表响应的 `accountGroup`；S 组不再出现这 3 个；页头卡总数用响应的 `completedCount / totalCount`（新口径，如「3 / 32 milestone」）。切换宠物时该区内容一致。点账号成就徽章 = 现有已完成徽章「重温庆祝」/ 未完成详情行为（与 S 组徽章同交互）。

**AC2 — 「我的」页入口（D1，PRD AC24）** `[L0]`
`me_page.dart` 在 `_EditProfileButton` 与 `_PetZone` 之间加入口「🏆 Pencapaian kamu」（样式同 Diary 里的 🏆 Pencapaian 进度卡），**只在账号下没有任何宠物（ACTIVE 与只读都没有）时显示**（含选了 HAS_PET 但没建档的）；点进账号级里程碑页。建第一只宠物后入口消失（PRD AC25）。埋点 `me_milestone_entry_tapped`（登记守卫）。

**AC3 — 账号级里程碑页（D2）** `[L0]`
新页 `/me/achievements`：顶栏「Pencapaian kamu」、新手任务卡（3-1 组件，`page=account_milestones`，① 显示「Buat profil」）、「Pencapaian akun」区（数据 `GET /me/account-milestones`）。无页头卡、无 L/M/S。

**AC4 — 失败态（D3）** `[L0]`
任一接口失败 → 整页 D3 失败态 + 重试（照拆页），不显示半截内容。

**AC5 — 分发路由** `[L0]`
新增 `/me/milestones-entry`：有宠物 → `/profile/milestones`（默认宠物 / 当前 `effectivePetId`），无宠物 → `/me/achievements`；透传 query（如 3-3 / 7-1 用的 `celebrate=lulus`）。7-1 的召回 D7 落点、3-3 的毕业通知落点都走它。

**AC6 — 文案** `[L0]`
「Pencapaian akun / Account achievements」「Pencapaian kamu / Your achievements」写进 arb（整合稿「新增文案」表逐字）。

**AC7 — 缓存** `[L0]`
`accountMilestonesProvider` 登记到 `resetUserScopedCaches`；建档成功后失效「我的」页入口依赖的 provider（入口立即消失）。
