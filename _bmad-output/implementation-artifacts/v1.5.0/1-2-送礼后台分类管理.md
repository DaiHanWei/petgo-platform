## Story

As a 运营,
I want 在礼物目录页管理分类并给每个普通礼物选分类,
so that App 送礼面板的分组由我决定，与价格脱钩。

## Acceptance Criteria

### AC1 — 分类服务与校验 `[L0]` `[L1]`
`B/admin/gift/service/AdminGiftCategoryService`（新），规则写进 `GiftCatalogRules`（服务层拦成 422 人话，不让约束以 500 露出）：
1. 新建 / 编辑：名称 EN、名称 ID 必填，trim 后各 ≤ 40（`NAME_MAX`）；排序 0 ~ 9999（`SORT_ORDER_MAX`）；与**已有分类（含已下线）**不分大小写重名 → 422，错误文案用 K5 句式「名称 {0}「{1}」已被分类「{2}」使用，换一个名称。」（{0} = EN / ID，{2} = 冲突分类的中文显示名即 EN / ID 名）；并发撞唯一索引 → 同一条 422。
2. 下线：服务端再查该分类在线礼物数，> 0 → 422（K4 置灰只是前端提示）；已下线再下线幂等。重新上线不弹确认（同礼物）。
3. 审计：`AuditActions` 新增 `GIFT_CATEGORY_CREATED` / `GIFT_CATEGORY_UPDATED` / `GIFT_CATEGORY_OFFLINED` / `GIFT_CATEGORY_ONLINED`，并在 `messages.properties`、`messages_en`、`messages_id`、`messages_zh_CN` 加 `admin.audit.action.<CODE>`（`AuditActionLabelsTest` 守卫）。
4. L0：`AdminGiftCategoryServiceTest`（Mockito）：EN / ID 重名（含已下线、大小写不同）被拒；有在线礼物下线被拒；排序越界被拒。

### AC2 — 礼物保存校验 `[L0]` `[L1]`
`AdminGiftCatalogService` 改：
1. 普通礼物（`kind = NORMAL`）必须带 `categoryId` 且该分类在线，否则 422「请选择分类」（`admin.v150.giftCategory.err.required` 三语）进错误槽；专属礼物忽略并清空 `category_id`。
2. 礼物重新上线：所在分类已下线 → 422「所在分类已下线，先改选分类。」（L5）。
3. 改分类沿用 `GIFT_CATALOG_UPDATED` 审计，摘要记前后分类 id。
4. `GiftCatalogForm` 加 `categoryId`；只读视图加「分类」行。
5. L0：`AdminGiftCatalogServiceTest` 补：普通礼物无分类 / 选下线分类被拒、专属礼物分类被清空、分类已下线的礼物不能重新上线。

### AC3 — 页面与路由 `[L1]`
照后台稿执行说明 ③ 逐条实现，权限全部复用礼物目录的 `VIEW_AUTH` / `EDIT_AUTH`，**不新增权限、不新增导航项**：
1. `T/gift-catalog.html`：标题下加页签「礼物 / 分类」（写法照 `T/growth.html` 的 `.tabs` / `tab--on` / `data-gtab`，纯前端切换）；URL 带 `tab=category` 默认停在分类页签；页头主按钮随页签切换「新建礼物 / 新建分类」，无编辑权限隐藏。
2. 新片段 `T/fragments/gift-category-list.html`（K1 说明 + 表格 + K2 空态；列：名称（EN / ID）、礼物数（在线 / 全部，在线加粗）、排序、状态、更新时间；在线但 0 个在线礼物的行加 `.badge-muted`「App 不显示」）。
3. 新片段 `T/fragments/drawer-gift-category.html`（K3 ~ K8，结构照 `drawer-gift.html`；错误槽 `#gift-category-drawer-err`；新建抽屉保存在页脚、详情抽屉保存在表单内、未改动时置灰；底部统计「{0} 个在线礼物 · 共 {1} 个」+「查看礼物 ›」→ `?tab=gift&category={id}`；「下线」不可用时按钮 `disabled`（`.btn[disabled]` 半透明红）+ 上方警示色原因（K4）；可用时走原生 `data-confirm`（K6）；只读权限换成只读展示 + 缺权限说明（K8））。
4. 路由挂在 `AdminGiftCatalogController` 的 `BASE` 下：`GET /categories/new/drawer`、`GET /categories/{id}/drawer`、`POST /categories`、`POST /categories/{id}/edit`、`POST /categories/{id}/status`；成功提示复用 `admin.flash.gift.saved / offlined / onlined`，新建用新 key「分类已新建」。
5. `T/fragments/gift-catalog-list.html`：名称后加「分类」列（EN / ID 两行，专属「—」，分类已下线加灰字「· 已下线」）；筛选栏最前加「全部分类」下拉（列全部分类含已下线），参数 `category`。
6. `T/fragments/drawer-gift.html`（新建、编辑都改）：「类型」下加 `<select name="categoryId" required>`，只列在线分类、按排序；并入现有最低等级的显隐脚本（普通显示分类、专属显示最低等级，隐藏的那个同时去掉 `required`）；编辑时当前分类已下线：额外渲染带「（已下线）」的选中项 + 红框 + 红字（L5），底部「重新上线」置灰并写原因。
7. L1：`AdminGiftCatalogIntegrationTest` 补：分类页签渲染、只读权限看不到新建和编辑、`category` 筛选、有在线礼物时 `POST /categories/{id}/status` 下线被拦。
