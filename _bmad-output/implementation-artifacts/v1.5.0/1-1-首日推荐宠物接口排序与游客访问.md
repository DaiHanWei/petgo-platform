## Story

As a 刚注册的新用户（或还没登录的游客）,
I want 推荐给我的宠物先是和我家同品种、同物种的，并且能直接给它最新一条帖子点赞,
so that 我首日就愿意和别人互动。

## Acceptance Criteria

**AC1 — 三段排序（PRD AC7）** `[L0]` `[L1]`
Given 查看者默认宠物（`DefaultPetPolicy.pick`）为 DOG、`breed=" Corgi "`，When `GET /api/v1/me/pet-recommendations?limit=10`，Then 结果先是 `lower(btrim(breed))='corgi'` 的狗（段 0），再是其他品种或无品种的狗（段 1），最后是非狗（段 2）；每张卡 `match` 依次为 `SAME_BREED / SAME_SPECIES / GLOBAL`；段内顺序与改动前一致（`WIB 日期 DESC, interactions DESC, last_at DESC, pet_id DESC`）。默认宠物无品种 → 跳过段 0。

**AC2 — 没宠物 / 游客只看全站（PRD AC8）** `[L0]` `[L1]`
账号无宠物 → 只有段 2 且不加物种条件，`match` 全为 `GLOBAL`。

**AC3 — 翻页跨段** `[L1]`
`limit=4`、段 0 只有 2 只时，第一页 = 段 0 两只 + 段 1 前两只；`nextCursor` 原样回传后，第二页从段 1 第 3 只续取；全部取完 `hasMore=false`。旧格式游标（无 tier）按段 0 解析；坏串按第一页（现有口径）。

**AC4 — 排除口径不变（PRD AC10）** `[L0]` `[L1]`
不含查看者自己的宠物、已追更的、双向拉黑主人的、主人注销 / DEACTIVATED 的、无头像的；只读宠物照常出现；同主人可出现多只。

**AC5 — 封面帖字段（FR-174 返回内容）** `[L1]`
每张卡追加 `breed`（可空）、`coverPostId`、`coverImageUrl`（与 `coverPostId` 同一条帖子的首图，去 EXIF 缩略图串不变）、`coverLikeCount`（该帖当前赞数）、`coverLikedByViewer`、`match`。封面帖 = 这只宠物最近一条**带图公开帖**（`content_pets` 关联、`PUBLIC`、`PUBLISHED`、未删、`image_urls` 为非空 JSON 数组；**不限 `GROWTH_MOMENT`**）；没有带图公开帖 → `coverPostId / coverImageUrl` 为 null、`coverLikeCount=0`。查看者已赞该帖 → `coverLikedByViewer=true`（本页一次批量查）。

**AC6 — 游客端点（PRD AC9）** `[L0]` `[L1]`
`GET /api/v1/public/pet-recommendations?limit=6` 无 token 返回 200：只有全站段、只取第一页（`limit` 上限 10，`hasMore` 恒 false、`nextCursor` 恒 null）、不含已删宠物；不做拉黑 / 已追更排除；`coverLikedByViewer` 恒 false；响应不含任何账号私密字段（与登录版字段集相同，没有新增敏感字段）。带有效 token 调用也返回同一份全站结果（不按查看者算）。

**AC7 — 游客 10 分钟快照（OR-5）** `[L0]`
`PublicPetRecommendationSnapshot`：首个请求构建（固定 `limit=10`、全站段），`petgo.public-pet-recommendations.ttl`（默认 `PT10M`）内的请求直接返回快照（按请求 `limit` 截断）；过期后下一个请求重建，重建期间并发请求读旧值；构建抛异常 → 有旧值返回旧值、没有则抛（控制器转 RFC 9457 500，App 侧按失败处理整块不渲染）。不引入 Caffeine / Redis / 任何缓存依赖。

**AC8 — 新引导标记键** `[L0]`
`OnboardingMarkKey` 末尾加 `FIRST_DAY_RECOMMEND("first_day_recommend")`；`POST /api/v1/me/onboarding-marks {key:"first_day_recommend"}` 成功、重复幂等；未登记键仍 422。

**AC9 — 回归** `[L0]` `[L1]`
`PetRecommendationServiceTest`、`PetRecommendationControllerTest`（若有）、`OnboardingMark*Test` 全绿；现有三个推荐位（社区首页横条走的是另一个接口则不受影响；Diary 空态网格、集合页）调用形状不变。

### 注意
