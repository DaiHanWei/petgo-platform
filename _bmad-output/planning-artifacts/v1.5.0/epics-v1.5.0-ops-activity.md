### NonFunctional Requirements

- 资金 / 权益正确性：总份数与每人上限在并发下准确；同一幂等键重放不重复到账；一份奖励在一个事务里发（任一项出错整份回滚、记失败、可重发）；优惠券库存 / 限领不足只跳过券。
- 多实例安全：排名生成 `FOR UPDATE SKIP LOCKED` 抢占；发放记录行锁串行；卡住的「待发」由扫描任务置失败。
- 旧版 App 不受影响（架构 §6）。
- 护栏：不引新中间件（`@Async` + `@Scheduled` + DB 状态机）；`ddl-auto=validate`；Flyway 时间戳号段 `V20261115_0600 ~ 0659`；共享 CHECK（`ck_user_coupons_source`）DROP + ADD 重列全集；**不改** `ck_notifications_type`；日志不记昵称 / 正文 / 金额以外 PII。
- 文案逐字取 PRD 附录 A（App ID / EN 进后端 `messages_*`；后台中 / EN / ID）。
