## 2026-11-05 架构按推荐定下（未单独拍板，可推翻）

- Biteship 询价用 5 位邮编；游客地区靠 `shipping_zones.postal_code`（运营补齐前该区按不支持配送）。
- Biteship Webhook：路径密钥 + 回查真实状态，不信任载荷。
- 报价落库 30 分钟复用，提交用 `quoteToken` 锁定快递与运费。
- 迟到款重新下单沿用原单锁定的快递与运费，不重新询价。
- 取消退款新建 `shop_order_refunds`，不复用退货单。
- ~~「我的券」可用列表不显示被待付款订单占用的券~~（已被 C-3 推翻：显示并置灰）。
- 自动送达兜底 7 天 → 14 天；物流异常订单暂停自动送达 / 完成。

## 2026-11-05 story 编写后收口

**操作者拍板：**

| 编号 | 问题 | 决定 | 落到 |
|---|---|---|---|
| S-10 | 默认选券「满减取抵扣最大」在个别情况下会跌破免运门槛、让应付变多（例：302,000 用 5,000 券后应付 317,000，不用券 302,000） | **照 PRD：满减券默认取抵扣额最大**，用户可手动换；用一条测试钉住该例 | Story 1.2、3.1、7.1 |

**按推荐定下（可推翻）：**

- **C-1 stag 入口**：`/admin/stag/shop/**`，后台会话 + `SUPER_ADMIN` + `@StagOnly`，后台链仅对该前缀免 CSRF；不走商家内部端口（`/internal/**` 已被商家内部接口占用）。架构 D-24 已列全 12 个入口。
- **C-2 错误码风格**：统一连字符（`coupon-not-found`、`product-delisted` 等），与 `ErrorTypes` 现有 40 余个一致。
- **C-3 「我的券」显示被占用券**：可用列表**显示**被待付款订单占用的券，标「已被待付款订单占用」、不可点（PRD「不可选」+ UI G1），推翻此前「不显示」。
- **C-4 应付为 0 的订单**（满减 + 免运券抵光）：提交即走 `markPaid(source=ZERO_PAY)`，不出码，同纯 PawCoin。
- **C-5 生产缺 Biteship key**：**不拒绝启动**（避免卡住同版本其他线发布）；询价返回 `quote-failed`、结算不可提交，启动时 ERROR 日志。
- **C-6 物流异常类型**：`LOST_DAMAGED` 拆为 `LOST`、`DAMAGED`（埋点 `exception_type` 需三值：退回 / 丢件 / 破损）。
- **C-7 平台原因整单取消**：若存在可取消的 Biteship 运单，`cancelWhole` 先调 `cancelWaybill`，失败记日志并提醒运营，不阻断取消。
- **C-8 通用 `/orders`**：电商行同样按 `displayStatus`（宽限期待支付显示已取消），与 `/me/shop-orders` 一致。
- **C-9 出参补字段**（只加字段）：退款单 `payoutAccountLast4`、`payoutChannel`、`payoutFee`、`compensationAmount`、`paidOutAt`（账户只给末 4 位）；已使用券 `usedAt`、`usedOrderNo`、`usedOrderToken`；新单 `reorderedFromOrderToken`；地区树每级带 id；商品详情规格 `sellable`；评价 `nickname`、`specName`；详情带 `reviewListEnabled`；商品列表 `totalCount`。
- **C-10 推送点开**：券快过期、重新下单两类推送按 PRD 直达对应页面（我的券 / 新订单）。
- **C-11 文案缺口**：PRD §6 未列、UI 稿有的约 15 处文案（「Mulai belanja」「Total dibayar」券面「Min. / Maks.」等）先按 UI 原文实现、标待设计侧确认；PRD §6 与 UI 冲突（推荐栏头「Untuk {pet}」、详情「标题 → 价格」顺序、确认收货提示）以 PRD §6 为准。
- **C-12 上线前实测**：GemPay 对「过期未付」码的查单返回值未实测——上线前在 stag 下单不付、等 65 分钟后查单，确认能返回明确 EXPIRED；否则订单关不掉（只靠连续失败告警）。
- **C-13 stag 部署前置**：1.1 上 stag 后存量 SKU 全部「暂不可售」，部署前须用 SQL 补包裹参数、发货地邮编与区域邮编。
- **遗留**：评价出参暴露自增 id（存量问题，分页扩大暴露面），另开 story 改 token。
