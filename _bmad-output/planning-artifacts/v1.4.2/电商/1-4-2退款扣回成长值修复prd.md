# TailTopia 退款扣回成长值修复 PRD — V1.4.2

**版本：** 1.4.2
**状态：** 定稿（2026-11-06；2026-11-04 新建）
**上游依赖：** V1.4.0 Tailrent 等级 PRD（`../V1.4.0/Tailrent等级/1-4-0Tailrent等级prd.md`，FR-143 扣回规则）、V1.4.2 电商 PRD（`1-4-2电商prd.md` FR-134 ③）、V1.4.2 电商后台 PRD（`1-4-2电商后台prd.md` AB-28）
**编号：** 本文档是对 1.4.0 FR-143 的修复，**不新增 FR / AB 编号**。

---

## 1. 背景

1.4.0 约定：退款成功时扣回这笔消费得到的 Tailrent 成长值（FR-143）。2026-10-30 核对发现，两条现金退款路径没有接上扣回，Roadmap 列为 1.4.2 修复项：

| 路径 | 归属 | 本次处理 |
|---|---|---|
| 电商异常订单取消的现金部分 | 电商 | 已写入 `1-4-2电商prd.md` FR-134 ③ 与 `1-4-2电商后台prd.md` AB-28「成长值扣回」：全部自动扣回——PawCoin 部分退回、现金部分选退为 PawCoin 时退回即扣；选线下打款的在财务点「标记已打款」时扣 |
| 问诊被封禁挂起后的 QRIS 退款 | 问诊 | **本文档** |

电商这条路径的现金退款都经过系统（退为 PawCoin 或「退款打款」页标记已打款），扣回可以自动执行；问诊这条路径没有系统内的出款与打款记录，扣回由客服在后台人工执行（2026-11-04 拍板）。

## 2. 现状（2026-11-04 核线上 1.4.1，petgo-platform `origin/main`）

- 兽医被封禁、付费问诊被挂起后，到期或用户主动结束时系统会自动退款（`ConsultSuspensionService`）：
  - **PawCoin 支付**：立即全额退回 PawCoin，订单变为「已退款」，**成长值自动扣回**（正常）
  - **QRIS 支付**：订单停在「退款中」，只记一个「已申请退款」节点，代码注明实际打款留给后续开发。**不扣回成长值**
- 停在「退款中」的这类订单**进不了常规退款流程**：常规流程（客服建退款单 → 批准 → 用户选退为 PawCoin 或填收款账户 → 主管审批 → 财务经 Iris 出款）在批准这一步要求订单是「已完成」，对「退款中」的订单直接报错。系统里没有其他把它推进到「已退款」的路径
- 对比：走常规退款流程的问诊订单，退款完成时成长值会自动全额扣回（`RefundService`），不在本次修复范围

**结论：** 问诊挂起的 QRIS 退款，钱只能靠客服 / 财务在系统外人工退，订单永远停在「退款中」，成长值也从未扣回。

## 3. 需求

### 已确认项（2026-11-04 拍板）

- 问诊挂起的 QRIS 退款，成长值由**客服在后台人工扣回**
- 扣回规则沿用 FR-143。问诊一律整单退款，按这单当初入账的成长值**全额扣回**；同一订单累计扣回不超过入账值；等级可随之下降

### 扣回入口（2026-11-04 拍板）

- 位置（2026-11-06）：💰 订单与资金 →「兽医订单」→ 订单详情抽屉。抽屉新增「成长值」一节（当初入账、已扣回；写法同电商「订单」抽屉的「退款与成长值」，见 `ui-admin-1-4-2-shop-integrated-v1.html` F7）。订单为「问诊挂起 + QRIS + 退款中」且本单成长值未扣回时，这一节显示「扣回成长值」按钮；扣回后按钮不再显示，显示本单已扣回的成长值
- 不放「退款管理」：该工作台走客服发起 → 主管审批 → Iris 出款，这类订单进不了这个流程
- 权限（2026-11-06）：新增独立操作权限「扣回成长值」，不与兽医订单页的「编辑」权限绑定（沿用 V1.3.0 后台「改用户资产的操作单列权限」的规则，同用户页「赠送 PawCoin」）。默认只给客服主管与超级管理员，普通客服需要时由管理员在角色权限页勾选。权限码由研发按现有命名定。无权限的账号不渲染按钮
- 二次确认用后台公共确认弹层（与电商后台各页一致）。弹层显示当初入账、此前已扣回、本次扣回额（问诊为全额）；扣回额由系统算好，客服不能修改，也不用填原因，点确认即执行
- 提交后写入成长值流水，用户等级随之重算，不通知用户
- 写入操作审计（人工操作，按电商后台 PRD 文档头「操作审计」口径）：操作人、时间、订单号，当初入账、此前已扣回、本次扣回的成长值，扣回前后的等级
- 兽医订单列表新增筛选项「待扣回成长值」：系统按「问诊挂起 + QRIS + 退款中 + 成长值未扣回」筛出
- **存量不处理**：1.4.0 上线（2026-10-25）以来已发生的此类订单不补扣（2026-11-04 拍板）
