29 屏已按 petgo-platform 分支 origin/dev_1.3.2 的后台真实代码（Thymeleaf + htmx，令牌取自 admin.css）填好结构：侧栏、顶栏、配置卡模板 D、列表模板 B + 480 抽屉、分步模板 E、空态、toast 都沿用现有写法。本步只核对结构，不做美化。后台默认中文，三语文案（中 / EN / ID）后续补。

第四步 · 核对结论（2026-10-12）：后台模板与 admin.css 在最新 origin/dev_1.3.4 上与第二步所读版本相比，只有「一次性解锁定价」卡变了（10-09 新增 Tailsonality 配型解锁价一行）——该卡在 G 泳道里只是半透明示意位置，不影响本稿。配色全部取自 admin.css 令牌；后台文案为中文，EN / ID 三语待补。PRD「不做」条款核对无违反（无曝光 / 点击 / 打开数、跳转无「优惠券」）。与代码现状的差异（已在各屏说明写明、PRD 已覆盖，不需要再拍板）：配置卡的高危确认由原生 window.confirm 改为服务端 modal；「输入值确认」「圈人群」「CSV 上传」为新组件。

请核对三件事：① 既有页面（运营配置页）原有内容有没有被挪乱；② 新增的两个侧栏项和新页面结构对不对；③ 字段、状态、操作是否和 PRD 一致。

查代码发现、需要你知道的 3 件事：
① 现有配置卡的「高危确认」其实是浏览器原生 window.confirm 纯文本框，1.3.2 稿里的带样式弹层没有落地。AB-22 要「手动输入版本号确认」，原生框做不到，所以 G3 / G4 统一改用后台已有的服务端 modal。

2026-10-09 已确认：I4 多个条件之间为「且」。
