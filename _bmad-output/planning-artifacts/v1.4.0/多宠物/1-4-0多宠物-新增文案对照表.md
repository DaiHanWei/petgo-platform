# V1.4.0 多宠物 · 新增文案对照表

- **对应稿件：** `ui-1-4-0-multi-pet-integrated-v1.html`（同目录，2026-10-15 定稿）。「屏」列是稿件里的屏号。
- **怎么用：** 本地运营在「印尼语（提议）」列直接改，确认后填「审核结果」列（✅ 通过 / 改成什么）。研发按审核后的版本同时加进 `app_id.arb` 和 `app_en.arb`，不要硬编码。
- **占位符：** `{name}` 宠物名，`{n}` 数字，`{date}` 日期（如 16 Okt），`{price}` 金额（如 Rp5.000）。`{price}` 和天数都取后台配置，不要写死。
- **不在本表里的：**
  - 代码里已有的文案（已对照 `origin/dev_1.3.4` 的 `app_id.arb`）；
  - 示例数据（宠物名、帖子正文、日期等）；
  - ① Tailrent 等级的文案（已由本地运营审核），例如「Level naik!」「+1 slot hewan」「Lihat Level Saya」；
  - KTP 卡面文字（沿用 1.3.4 卡面插画）。
- **共 69 条新增：** A 名额已满 7 · B 只读提示 3 · C 删除宠物 2 · D 名额管理与租用 33 · E 只读拦截 3 · F 发布与详情 3 · G 打卡 4 · H 问诊 7 · I KTP 2 · K 通知与庆祝 5（其中 K-1 ~ K-4 放后端文案）；另有 3 行只是说明「沿用现有文案」、1 条改写已有文案（R-1）、2 项由其他分支提供。
