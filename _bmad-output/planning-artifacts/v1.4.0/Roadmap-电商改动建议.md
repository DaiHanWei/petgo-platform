# Roadmap.md 电商相关条目 · 定点改写建议

**目标文件：** `1.项目总述/Roadmap.md`（基准 `docs/v1.1.2-split` @ `1dc9bda`）
**原因：** 产品于 2026-08-10 拍板电商采用**精选自营**（平台采购备货、自负履约），**直接覆盖** Roadmap 现有的 Phase A（导流）与 Phase B（商家自行履约）两条路线。两者建立在「零库存、零履约、商家供货」的前提上，与自营互斥。
**本文件不直接修改 Roadmap**，仅给出定点改写建议，由 Dai 合入。

> ⚠️ **第 3 条最紧急**：那是一条带时限的商务动作（「月2启动合作商家签约」）。若不改写，商务侧会继续按「签约商家供货」推进，方向完全错误。

## 2. 1.4.0 电商条目（约 L147）

**原文：**
```
- **精选电商 Phase A（导流模式）：** 平台精选合作商家商品展示（初期品类：宠物食品 + 健康相关/驱虫/营养品）；点击跳转商家 Tokopedia/Shopee 页面完成购买；成长档案页新增商品推荐区，根据宠物品种/年龄/健康记录推荐相关品类；Phase A 免费入驻，用流量转化数据谈判 Phase B 合作条件；KOL带货模式预留，商家量达标后上线；**商务侧需月2启动合作商家签约**（否则上线无商品可展示）
```

**建议改为：**
```
- **精选自营电商（2026-08-10 改版，覆盖原「Phase A 导流模式」）：** 平台自采自营（初期品类：宠物食品 + 驱虫/营养品 + 零食 + 洗护），**在 App 内完成下单与支付、由平台自负履约**，不再跳转 Tokopedia/Shopee、不引入第三方商家入驻；收入为进销毛利而非抽佣。占用底部 Tab 预留位（Toko）；成长档案页新增商品推荐区，按宠物品种/年龄/体重推荐；**复购引擎**（结构化健康记录驱虫/疫苗周期触发 + 粮量见底预估）为本版本核心；KOL 带货模式预留不变。**商务侧需启动自营供应商/经销商签约与首批采购**（否则上线无商品可售）。详见 `V1.4.0/v1-4-0电商PRD.md`（FR-93 起）
```

**改动要点：**
- 「导流跳转」→「App 内成交 + 平台履约」
- 「合作商家展示 / 免费入驻」→「自采自营」，删除入驻概念
- 「按健康记录推荐品类」升级为明确的**复购引擎**（这是本版本的核心主线，原表述过轻）
- 补 PRD 指路

## 3. 「关键提醒」表 · 电商签约行（约 L484）⚠️ 最紧急

**原文：**
```
| 电商合作商家签约启动（宠物食品/健康品，目标5-10家精选） | **月2启动**（否则1.4.0上线无商品可展示） | 商务 + 运营 |
```

**建议改为：**
```
| 自营电商供应商/经销商签约与首批采购（宠物食品/驱虫营养品，目标5-10家本地授权经销商） | **月2启动**（否则1.4.0上线无商品可售）；同期需 Legal 出具 NIB/KBLI 网络零售经营范围结论与品牌授权书要求 | 商务 + 运营 + 法务 |
```

**改动要点：**
- 「合作商家签约」（对方供货并履约）→「供应商/经销商签约与采购」（我方进货）。**这是两件完全不同的商务工作**
- 增列法务前置：经营范围（NIB/KBLI）与品牌授权书是备货的硬阻塞项，原表中无对应条目

## 5. 「定价结构 · 平台抽佣」表（约 L510 后）

自营电商收入是**进销毛利**，不是抽佣。混在抽佣表里会导致财务口径错误（把零售价全额当 GMV 再乘抽佣率）。

**建议新增一行，并加注说明：**
```
| 精选自营电商 | **不适用（进销毛利，非抽佣）** | 1.4.0 | 平台自采自营，收入 = 零售价 − 进货成本，毛利率目标 15–25%；GMV 与撮合业务的 GMV **不可合并后统一乘 blended take**，需单列核算 |
```

## 6. 顺带修正：支付渠道口径（非电商专属，但本次一并发现）

Roadmap 内两处仍写「GoPay / OVO」，与 1.1.0 条目自身 2026-07-15 的更正（**目前仅支持 QRIS，DANA 尚未接入，不支持 GoPay/OVO 直连**）矛盾：

| 位置 | 原文片段 | 建议 |
|---|---|---|
| 2.1.0「在线支付」 | 接入 GoPay / OVO（复用 1.1.0 支付体系） | 改为「复用 1.1.0 支付体系（当前为 QRIS）」 |
| 2.1.0 电商 Phase B | 复用 GoPay/OVO | 随第 4 条一并删除 |

另：`V1.1.0/v1-1-0PRD.md` FR-43 正文写「支持渠道（已确认）：QRIS、DANA」，与 Roadmap 的「DANA 尚未接入」不一致。**这两处应统一**，本次电商 PRD 按较新的 Roadmap 口径（仅 QRIS）设计。
