## 分支模型与开工顺序

- 集成分支 **`dev_1.4.0`**（2026-10-18 从 main `5ec8a2e4` 切出，已含 1.3.4 全部合入）。
- **先做 Story 0.1「四条线共用地基」**（`implementation-artifacts/v1.4.0/0-1-四条线共用地基.md`），合入 `dev_1.4.0` 后，四个功能分支**都从地基之后的 `dev_1.4.0` 切出**。地基把 ① PRD §6.2 列为「① 负责的共用部分」中跨分支的那几项提前落地，避免 ②③④ 编译期缺接口、自造替身、私改共享约束。
- 合并顺序仍按 ① PRD §6.1：① → ② → ③ → ④。**不往功能分支反向合并 dev**；后合并的分支与 dev 冲突时，从 dev 切对齐分支处理。
- 跨分支契约（谁拥有哪些类 / 迁移、谁不许改）记在 `../../implementation-artifacts/CROSS-STORY-DECISIONS.md`「2026-10-18 V1.4.0 四条线共用地基」一节，**冲突时以它为准**。
