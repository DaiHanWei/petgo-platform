⚠️ 本版本覆盖 Roadmap 既有电商设计

Roadmap 1.4.0「精选电商 Phase A」= 跳转 Tokopedia/Shopee 导流；2.1.0「Phase B」= App 内下单但商家自行履约。两者均为零库存零履约模式，与本版本的精选自营（平台采购备货、自负履约、收进销毛利）互斥。已拍板由自营直接覆盖 —— Roadmap 需同步改写，见 Roadmap-电商改动建议.md。

系统内首次出现实物商品。既有全部收费场景（AI问诊解锁 / 兽医咨询 / PawCoin充值 / 身份证下载）都是虚拟商品，因此收货地址、物流、实物退货、库存四类能力从零新建；支付（FR-43）、订单壳（FR-54）、客服工单（FR-52）、退款（AB-5E/AB-6A）均为复用。

PawCoin 可用于购物（2026-08-10 拍板），规则见 FR-100A。其中最承重的一条是防套现：PawCoin 支付的部分退款只能退回 PawCoin——因为实物可退货，若允许退真钱就形成「充值 → 买货 → 退货退真钱」的变相提现路径，直接击穿 FR-50D「不支持一般性提现」。这不是电商局部规则，而是对 FR-50 封闭币体系的实质性扩展。
