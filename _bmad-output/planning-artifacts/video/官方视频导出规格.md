# 官方视频导出规格（给运营）

> 第一期 App 不会压缩视频，会**原样上传**你选的文件（决策 V-33）。所以视频要在电脑上按下面的规格导出，App 上传前会检查，不符合的会提示原因。
> 软件版本不同，选项名称可能略有差异，以实际界面为准。第一次导出后，请按「验收」一节确认一遍。

## 一、规格

| 项 | 要求 |
|---|---|
| 格式 | MP4 |
| 视频编码 | **H.264**（不要选 HEVC / H.265） |
| 分辨率 | **720P**（竖屏 720×1280；横屏 1280×720） |
| 帧率 | **30fps**（25fps 也可以；不要用 60fps） |
| 码率 | 约 **2Mbps**（2000kbps），不超过 3Mbps |
| 色彩 | 普通（SDR），**关闭 HDR** |
| 音频 | AAC，128kbps（可以没有声音） |
| 时长 | 3–90 秒 |
| 体积 | ≤ 100MB（按上面的设置，90 秒约 25MB） |

## 二、剪映 / CapCut（电脑版）

1. 点右上角「导出」。
2. 视频导出设置：
   - 分辨率：**720P**
   - 码率：选「自定义」，填 **2000**（kbps）；没有自定义选项的话选「推荐」
   - 编码：**H.264**
   - 格式：**mp4**
   - 帧率：**30fps**
   - 如果有「HDR」开关，**关闭**
3. 音频导出：格式选 AAC（默认就是）。
4. 第一次设置好后，保存为导出预设，以后直接选这个预设。

## 三、HandBrake（备用：剪映导出的视频没通过检查时，用它转一遍）

1. 打开视频，预设任选一个 720p30 的，然后按下面调整：
2. Summary：格式选 **MP4**，勾选 **Web Optimized**（这一项就是「边下边播」）。
3. Dimensions：分辨率上限 **720p**。
4. Video：编码器 **H.264 (x264)**；帧率 **30**，选 **Constant Framerate**；码率选 **Avg Bitrate 2000 kbps**。
5. Audio：**AAC**，**128**。
6. 保存为自定义预设，命名「TailTopia 官方视频」。

## 四、技术同事用的命令行（ffmpeg）

```bash
ffmpeg -i 输入.mp4 \
  -vf "scale='if(gt(iw,ih),-2,720)':'if(gt(iw,ih),720,-2)',fps=30,format=yuv420p" \
  -c:v libx264 -profile:v high -b:v 2M -maxrate 3M -bufsize 4M \
  -c:a aac -b:a 128k \
  -map_metadata -1 -movflags +faststart \
  输出.mp4
```

这条命令会同时完成：缩放到短边 720、转为 30fps、H.264、AAC、去掉所有元数据（包括位置），并设置边下边播。已用调研样片实测：竖屏、横屏、带旋转标记的 1080P 原片都能输出合规文件（90 秒约 24MB）。

⚠️ **这条命令不处理 HDR**：HDR 原片（例如 iPhone 拍的杜比视界）转出来仍带 HDR 标记，会被 App 拦下。HDR 原片请用下面这条，它需要带 `zimg` 的 ffmpeg 构建（先运行 `ffmpeg -filters | grep zscale` 确认有输出；Homebrew 默认的构建没有，可以用 evermeet.cx 或 BtbN 的静态构建）。**这条命令没有在本机验证过**，第一次使用后请按「五、验收」检查：

```bash
ffmpeg -i 输入.mp4 \
  -vf "zscale=t=linear:npl=100,format=gbrpf32le,zscale=p=bt709,tonemap=hable:desat=0,zscale=t=bt709:m=bt709:r=tv,scale='if(gt(iw,ih),-2,720)':'if(gt(iw,ih),720,-2)',fps=30,format=yuv420p" \
  -c:v libx264 -profile:v high -b:v 2M -maxrate 3M -bufsize 4M \
  -color_primaries bt709 -color_trc bt709 -colorspace bt709 \
  -c:a aac -b:a 128k \
  -map_metadata -1 -movflags +faststart \
  输出.mp4
```

AI 生成的视频一般不是 HDR，用第一条命令就够了。

## 五、验收（第一次导出时做一次）

1. 在官方号的 App 里选这段视频，**能直接通过检查、开始上传**。
2. 如果提示不符合，按提示调整导出设置。常见原因：
   - 「编码是 HEVC」：导出时编码改成 H.264
   - 「不支持边下边播」：用 HandBrake 勾选 Web Optimized 再转一遍
   - 「HDR」：关闭 HDR 开关
   - 「含拍摄地点」：用 HandBrake 或命令行转一遍
3. 发布后，在一台低端安卓机上点开，确认能正常播放。
