## 模板 A 通用规格（处置工作台，本组共用；各页只写内容与差异）

**布局：** 双栏。左栏固定 360px = 队列列表；右栏自适应（≥720px）= 选中项详情 + 处置操作区。顶部两条：页签行（子队列切换，各带计数）+ 筛选行。窄屏（<1024px）降级为列表/详情两屏切换。**全组不做键盘 ↑/↓ 手动切换条目**（D-14），只保留处置后自动选中下一条。

**左栏队列行（行高 ~56px，两行式）：** 第一行 = 主标识（对象名/单号，最长 18 字截断）+ 右对齐状态色点；第二行 = 摘要（单行截断）+ 右对齐相对时间。选中行左侧 3px 主题色竖条 + 浅底高亮。**分页统一每页 20 行**（沿用现有 PAGE_SIZE=20），滚动到底加载下一页。

**常驻原则（2026-09-01）：** 选择参数类操作（原因/粒度/期限/金额/处置方式）一律**常驻操作区**、参数不全按钮禁用，不做「点按钮→展开面板」的二级步；确认弹层只留给不可逆高危动作。
- **规则 12（2026-09-03）：导出文件必须按字段分列**——CSV 正确转义、XLSX 一字段一列、表头随界面语言；历史版本曾整行挤一列，验收逐个导出打开核查

**处置动线（核心交互）：** 右栏操作提交走 **htmx 局部更新**（左栏该行 + 右栏刷新，不整页跳转——模板 A 内现状的 PRG 整页刷新退役，后端端点与参数不变）；处置成功 → 右下角短 toast（2s）+ **自动选中队列下一条**。失败在操作区行内报错（沿用 err 样式），不弹整页。

**状态色点语义（全组统一）：** 🔵 待处理 · 🟡 处理中/等待外部（寄回中、待联系等）· 🔴 超时/高优 · ⚪ 终态（已处理/已驳回/已完结）。终态行只在「已处理」页签出现。

**通用件：** 各页签计数 = 该页签当前状态行数，与左侧导航角标同源、处置后即时刷新；空态 = 插画 + 「队列已清空 🎉」；**登录者无该页任一查看权限 → 待办中心组内不渲染该菜单项**；有查看权无处置权 → 右栏操作区按钮禁用并注明所缺权限名；高危操作走 `data-confirm` 二次确认（确认文案须复述对象与后果）；全部写操作照旧落审计。
