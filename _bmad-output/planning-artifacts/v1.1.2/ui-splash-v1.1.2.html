本轮新增的 5 项改动

  1. 字标换成母文件版本。母文件 Layer_9 与 app 现用的 wordmark.svg 不是同一版： 母文件的猫尾是更粗壮的实心月牙、位置更高、动感短划更长；app 版是一个细卷钩。已换成母文件版。
  2. mark 放大，并修掉资产本身的偏心。mark_dog.svg 的 viewBox 是 0 0 500 500， 但图形只占 x 67–456 / y 85–407 —— 声明 108px 时实际可见只有 ~84×70，还向右偏 12、向上偏 4。 这就是「小家子气」的根因。改用紧贴 bbox 的 viewBox，并把可视宽定到 屏宽 × 42%。
  3. 标语字体待选。现状 Quicksand 确实没有辨识记忆点。给了 5 个候选（含现状对照）， 在紫底上直接比 —— 见「字体候选」卡。需要你选一个，任选非 Quicksand 都要新增字体资产。
  4. 标语换 Fraunces 16px，并重调全部相关数值。换字体和改字号不是两个独立参数 —— 原来的 1.65 行距在 16px 下过松、.15px 字距在 16px 下无意义且衬线本不需要、 62% 宽度在 16px 下会挤成三行、白 62% 对衬线偏细的笔画不够。逐项调整列在 F1 规格表。 顺带把慢网提示也换成同族，splash 因此只用一款字体，不再依赖 Quicksand。
  5. 修掉循环预览里标语不居中的 bug。动效包了一层 .b-tag，作为居中 flex 子项它的宽度是 fit-content， 导致 .tag 的 62% 相对一个收缩后的宽度解析 → 文字整体左偏。 静态帧没有这层包裹所以正常，只有会动的那屏有问题（就是你截图里那个）。已改为 align-self:stretch。

定稿前最后一件事

  1. Android 12+ 原生图标的真机尺寸复核。mark 可视宽已定 42%，但 Android 12+ 的系统 splash 图标 最终渲染尺寸由系统决定、不可指定。要在真机上量一次，把 Flutter 首帧的 mark 尺寸对齐到系统实际渲染值， 否则交接那一帧会出现一次尺寸跳变 —— 这是本方案「无缝交接」唯一无法在稿件里验证的环节。

0 · 原生与 Flutter 的交接

现状每次冷启动都闪一次白：原生白底紫 logo → Flutter 紫底。解法不只是把原生改成紫底，而是让原生启动屏成为动画的第 0 帧 —— 原生显示白 mark 居中，Flutter 首帧接住同位置同尺寸的 mark，再由它开始变化。不可控的原生启动时间被吸收进叙事，用户感知不到交接点。注意 Android 12+ 的系统 splash 图标不可定位，所以对齐只能在 50% 正中完成。
