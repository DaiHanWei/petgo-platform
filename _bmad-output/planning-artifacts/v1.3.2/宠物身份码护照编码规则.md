# 宠物身份码、护照号与学生卡编号规则

仿照印尼身份证号（NIK）、护照号，以及自定的宠物学生卡编号，登记/持证对象由"人"变为"宠物"。三套编号定位不同：

- **身份码**：仿NIK，以TT前缀标识TailTopia自有编号，可解码出宠物出生日期、物种等信息，用于日常实名登记（不含任何地理/门店信息）。
- **护照号**：仿真实护照，**不携带**可解码的宠物信息，仅类型+顺序号，用于跨境携宠场景，具体档案靠后台关联表反查身份码。
---

# 一、宠物身份码

以 **TT**（TailTopia缩写）开头，标识这是平台自有编号而非官方证件号。不含任何地理/门店信息，纯粹由出生日期、物种、顺序号组成。

## 1. 整体结构（TT + 12位）

```
TT DDMMYY SP XXXX
```

| 段位 | 位数 | 含义 | 取值说明 |
|---|---|---|---|
| TT | 2位字母 | 固定前缀 | 固定为 `TT`，标识TailTopia自有编号 |
| DDMMYY | 6位 | 宠物出生日期 | 日-月-年；**母宠物日期+50，公宠物日期+10**区分公母 |
| SP | 2位 | 物种代码 | 见下表 |
| XXXX | 4位 | 顺序号 | 同一天、同物种登记的第N只，从0001起 |

## 2. 物种代码（SP）

| 编码 | 物种 |
|---|---|
| 01 | 狗 Dog |
| 02 | 猫 Cat |
| 00 | 其他 Other |

## 3. 示例

2024年3月10日出生的母猫，当天当物种第2只登记：

- 前缀：`TT`
- 日期（母+50）：`500324`
- 物种：`02`
- 顺序号：`0002`

完整宠物身份码：**TT500324020002**

# 二、宠物护照号

真实护照号**不携带可解码的个人信息**（出生日期、地区等），仅靠系统顺序分配 + 类型前缀，具体信息全部通过后台数据库关联查询。宠物护照号沿用同一原则。

## 1. 整体结构（15位，字母+数字）

```
TT SP T YY XXXXX
```

| 段位 | 位数 | 含义 | 取值说明 |
|---|---|---|---|
| TT | 2位字母 | 固定前缀 | 固定为 `TT`，标识TailTopia自有编号 |
| SP | 2位数字 | 物种代码 | 同上表 |
| T | 1位字母 | 护照类型 | 见下表 |
| YY | 2位数字 | 签发年份后两位 | 如2026年签发→`26` |
| XXXXX | 5位数字 | 签发顺序号 | 系统内顺序分配，从00001起，**不做进一步编码**（仿照真实护照原则，不可反推宠物信息） |

护照号本身不关联宠物出生日期、物种、主人地区等信息——这些通过护照号在后台反查宠物身份码（见上一章）获取，与真实人类护照号"号码与身份证号是两套独立系统，靠数据库关联"的做法一致。

## 2. 护照类型代码（T）

| 代码 | 类型 | 说明 |
|---|---|---|
| P | 普通宠物护照 | 常规出境，已完成常规检疫/疫苗流程 |


> 完整对照表沿用官方 ISO 3166-1 numeric 标准，无需自定义，系统内直接引用标准编码库。

## 3. 示例

2026年签发、宠物是猫咪、普通宠物护照，当年第37个签发号：

`TT 02 P 26 00037` → 完整护照号：**TT 02 P 26 00037**（连写：**TT02P2600037**）

## 4. 与宠物身份码的关联表

护照号与身份码是两套独立编号，护照号**不包含**出生日期、性别、物种等字段。系统需维护一张关联表：

| 护照号 | 关联宠物身份码 |
|---|---|
| TT02P2600037 | TT500324020002 |
