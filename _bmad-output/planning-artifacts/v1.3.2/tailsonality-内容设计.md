## 1. 调研依据

宠物人格不是凭空造的娱乐概念，猫和狗各有经同行评议、且做过信效度检验的量表。本设计的四个维度全部锚定到这两套量表里的既有因子，不自创无依据的维度。

| 模型 | 物种 | 维度 | 效度情况 |
|---|---|---|---|
| **Feline Five**（Litchfield et al., 2017, PLOS ONE） | 猫 | Neuroticism · Extraversion · Dominance · Impulsiveness · Agreeableness | 2,802 只家猫、52 项特质，主轴因子分析得出 |
| **MCPQ-R**（Monash Canine Personality Questionnaire-Revised） | 狗 | Extraversion · Motivation · Training Focus · Amicability · Neuroticism | 26 项，评分者间信度 0.75~0.86、重测信度 0.79~0.93，均 P<0.001 |

**竞品扫描：** Pup Personality（16 型 + 可分享结果卡）、16Petti、CAMI（Pet MBTI，主打兽医与行为专家审核）等已验证「16 型 + 分享卡」这一形态可行。多数采用 MBTI 式四轴二分——**这对印尼市场是加分项**：16personalities 在本地年轻人中普及度极高，四轴二分的结构无需教育成本。

**我们的差异化不在测评形态，而在两点：** ① 结果绑定宠物档案（有头像、有名字、有 Diary），不是匿名一次性测试；② Jaksel 命名——这是本地竞品与国际竞品都给不了的本土语感。

## 2. 用户旅程与付费结构（2026-09-18 定稿）

> 本节是 FR-117 的**总纲**，定义用户从入口到分享的完整路径、两个付费点的边界、以及与 Diary／宠物档案／分享奖励的联动。后续各节的文案与题库都服务于本节定义的流程。

### 2.1 全流程

| # | 步骤 | 用户看到 | 可做的选择 | 得到什么 |
|---|---|---|---|---|
| **0** | 入口 | 某只宠物的**成长档案页** → 头部「Know more about your pet」聚合页 → Tailsonality 卡 | 进入 / 返回 | — |
| **1** | **测试说明抽屉**<br>（自聚合页弹出） | 明确告知测试对象：**「即将开始对【{pet}】·【品种】进行性格测试」** + 题量与预计时长 | 开始 / 关闭抽屉 | — |
| **2** | 答题 | **一页 6 题、共 3 页**（每页 5 文字题 + 1 图片题），进度「第 X / 3」 | 4 选 1；可返回改上一页；**中途返回 = 放弃进度、不保存**（2026-09-23 改） | 答完 → 结果页 |
| **3** | 结果页（免费态） | ① **结果卡图**（插画 + 代号 + 角色名 + slogan，**自带水印**，可点开看大图）② 免费摘要 ③ 配型引流模块 ④ 锁态区（可见标题、读不了正文） | 生成／分享结果卡（带水印）· 进入配型页 · 解锁 Rp5,000 | 免费内容全部可见 |
| **4** | 配型页（独立页面） | 选择自己的四字母类型 → 逐字母对照图 + 档位标签 + 总评 + **16 段逐轴详解** + 配型卡 | 换自己的类型 · 生成／分享配型卡 | **全部内容免费可见** |
| **5** | 付费 | 一个付费点：结果解锁 Rp5,000，见 §2.2 | 解锁 / 不解锁 | 结果页锁态内容 + 两张卡的无水印高清 |
| **6** | 分享 | 两张卡，见 §2.5 | 分享卡一 / 卡二 | PawCoin 奖励 |
| **7** | 佩戴 | 见 §2.4 | 选择是否佩戴、佩戴哪一次结果 | 宠物档案挂上角色小标 |
| **8** | 重测 / 回看 | 见 §2.6 | 重测（免费）· 回看历史结果 | 新结果（锁态）／旧结果快照 |

**题库自动按宠物档案的物种字段选择**（猫 → 猫套、狗 → 狗套、其他 → 通用套），不询问用户；说明抽屉里展示的「{pet}·品种」即是让用户确认对象是否正确的唯一机会。**该抽屉为贴底 sheet、不是整页**（2026-09-22 UI 阶段拍板）——入口即弹出，点「Mulai Tes」直接进答题页。

**答题中途返回（2026-09-23 改，原「保存进度」设计作废）：** 点返回时弹二次确认，明确告知**已答的题不会保存**；确认后退出，下次进入从第 1 题重新开始。不做进度留存。

### 2.2 付费点（2026-09-21 定稿：全 FR 只有一个）

| | **结果解锁** |
|---|---|
| 价格 | **Rp5,000** |
| 位置 | 结果页锁态区 |
| 解锁内容 | 角色专属深度解读 + 四段维度解读 + 能量段 + **结果卡无水印高清** |
| 解锁粒度 | **本次测试结果** |
| 重测后 | 新结果需重新解锁 |
| 换主人类型后 | **不受影响**——配型与本付费点无关 |

**⚠️ 2026-09-21 变更：配型页完全免费，无任何付费要素。**

- 配型页的**全部内容免费**：逐字母对照图、档位标签、档位总评全文、**16 段逐轴详细解读**，一样不锁
- **配型卡为「免费传播卡」：无水印 + 下载引导**，与 FR-65 年龄卡同类。按项目既有分类规则——水印只属 KTP / 护照 / 本 FR 结果卡这类「付费无水印」保护场景，**免费传播卡不加水印**（FR-73 已有同款产品决定）
- 配型页**不再有锁态区**，用户在配型页不会遇到任何付费墙

> **⚠️ 同一个 FR 内两张卡的水印规则不同，这是有意的，不是疏漏：**
> **结果卡**承载付费内容（深度解读），归「付费保护卡」——免费带水印、解锁后无水印；
> **配型卡**承载的全部是免费内容，归「免费传播卡」——始终无水印。
> 规则依据是**卡面承载的内容是否付费**，不是卡属于哪个 FR。研发勿按「同一功能的卡应当一致」去统一处理。

**为什么这么改：** 配型是本 FR 最强的分享钩子（「我 INFP，它 ENFP」比单纯晒宠物更有传播动机）。把内容锁起来、或给卡面盖上水印，都是在给传播加闸，与 FR-117「首要目标是拉新」的定位冲突。改为完全免费后，付费动机集中到结果解锁这一个点上，用户路径也更简单——**全程只会遇到一道付费墙**。无水印不影响拉新回流：卡面仍带**下载引导**，那与水印是两回事。

**定价：** Rp5,000 本版本**硬编码上线、运营不可调**，后台定价配置行见 `v1-3-2后台prd.md` AB-18A。成交价必须写入购买记录。

### 2.3 挽留提示（用户放弃付费返回时）

**触发点：** 用户在**结果页锁态区**点击返回、且结果尚未解锁时，弹一次。（配型页已无锁态区，不涉及。）

**核心卖点是「佩戴」不是「阅读」**——未付费用户的角色小标不会出现在宠物档案上（见 §2.4），这比「还有内容没看」更有说服力。

| | 文案 |
|---|---|
| 中文（内部） | 标题：**再想想？**<br>正文：解锁后，{pet} 的性格标签才能挂上它的档案——别人来看主页时就能看到。完整解读也一并解锁。<br>按钮：**再看看** / **去解锁** |
| English（App） | **Wait a sec.**<br>Unlock it and {pet}'s personality badge goes on its profile — visible to everyone who visits. Full reading included.<br>**Not now** / **Unlock** |
| Bahasa Indonesia（App） | **Yakin keluar?**<br>Kalau di-unlock, badge kepribadian {pet} bisa dipasang di profilnya — kelihatan sama semua yang mampir. Analisis lengkapnya juga kebuka.<br>**Nanti aja** / **Unlock** |

**同一次测试结果只弹一次**，用户关掉后本次结果内不再弹——反复挽留会变成骚扰。

### 2.4 角色小标佩戴

宠物档案与用户公开主页（FR-118）上的 Tailsonality 角色小标，规则如下：

- **未解锁结果的用户：不显示任何小标。** 测了但没付费 = 档案上看不到
- **已解锁的用户：可选择是否佩戴，以及佩戴哪一次结果**——同一只宠物重测多次、解锁了多次结果时，从**已解锁的那些结果**中选一个佩戴
- 未解锁的那几次结果**不可佩戴**，在选择列表中置灰并标注「未解锁」
- 默认行为：**首次解锁后自动佩戴该次结果**；之后再解锁新结果**不自动替换**，由用户主动选择
- **佩戴在结果列表页行内直接切换**（2026-09-23 UI 阶段改）：每条已解锁结果行内切换佩戴态，**不另开佩戴管理页**；同一时刻只有一条佩戴中，点另一条即替换，未解锁行的控件置灰不可点

### 2.5 分享与 PawCoin 奖励

| | **卡一 · 宠物结果卡** | **卡二 · 配型卡** |
|---|---|---|
| 主体 | 插画 + 代号 + 角色名 + slogan | **双人插画**（主人 × 宠物，按 5 档各一套） |
| 版式 | 专门设计（角色插画为主视觉） | **复用 FR-73 内容分享卡模板** |
| 未解锁结果时 | 可生成，**带水印** | 可生成，**始终无水印** |
| 解锁结果后 | 无水印高清 | 同上（不受解锁状态影响） |
| 尺寸 | **9:16 单尺寸** | **9:16 单尺寸** |
| PawCoin 奖励 | ✅ | ✅ |

**卡一遵循 FR-96 的既定原则**：免费分享得到的是带水印版，无水印需付费解锁。**卡二不适用该原则**——它是「免费传播卡」，与 FR-65 年龄卡同类，始终无水印。分类依据见 §2.2。

**画布（2026-09-23 UI 阶段调整）：** 两张卡在**页内展示与大图查看时为 3:4**，**分享到 Story 时出 9:16**。原「只出 9:16 单尺寸」收窄为「页内 3:4 + 分享 9:16」，同一套卡面内容、两种版式适配。

**结果卡的两种手势（2026-09-23 UI 阶段新增）：** 点卡图 → **大图查看**（复用 V1.3.0 批次 A 重做的公共 `ImageLightbox`，未解锁时大图仍带水印）；长按卡图 → **底部菜单**：保存到相册 / 分享 / **发个帖子炫耀**。

**发帖回流（2026-09-23 UI 阶段新增）：** 结果卡长按菜单、配型页、配型卡预览**三处的「发个帖子炫耀」拉起同一个发帖抽屉**，预上传卡图 + 预填文案——结果卡走「我测了我家毛孩子的性格，看看 TA 的 Tailsonality 是什么吧！」，配型卡走「我测了我和我家毛孩子的匹配程度，看我们的匹配结果卡片」。**复用既有发布页、只做预填**，不新建发布流程。意图是把分享从「导流出站」改为**先回流站内内容池**。

**卡二版式复用 FR-73 内容分享卡（2026-09-21 拍板）：** 沿用 `share_card_template.dart` 的三段式骨架——主体区 / 信息区 / **品牌段（固定 15% + 二维码）**。**品牌段的二维码即卡二的「下载引导」载体**，不需要另加元素；该段固定高度是 FR-73 既有决定（「一批卡混着发到 Story 里成套靠的就是这条底边一样高」），卡二沿用后可与内容卡混发成套。**卡二只替换主体区内容**，UI 阶段只需定主体区、不必重画整卡。

> **主体区内容（2026-09-24 改定）：双人插画**——主人 × 宠物两个角色的互动画面，**按 5 个匹配档位各一套**（~~原定「双人逐字母对照图」~~）。
> 逐字母对照图**从卡面移出**，只保留在配型页页内（§5 的对照区）。
> **改动理由**：卡是拿去晒的，插画比字母表更适合社交场景；且五档插画能做成一条「从重合到相反」的连续光谱，五张放一起是一个系列，比五张字母表有传播力。
> **代价（已接受）**：卡面不再是「不读字就看得懂」，跨语言的直观优势让位给了视觉表现力。
> **卡面元素**：双人插画（主体）· 双方代号（如 `INFP × ENTJ-H`）· 档位标签 · 最多 2 条差异句。三段式下，代号与档位落在**信息区**，插画占**主体区**。

**⚠️ 卡二需要 FR-73 卡片基建新增一个「双人对照」版式模板**，不是纯复用，是本 FR 的新增工程量。卡一沿用既有模板即可。

**奖励去重粒度（2026-09-18 拍板，对 FR-96 的扩展）：卡一、卡二各算一次。**

- 粒度为 **宠物档案 × 卡类型**：同一只宠物，卡一首次分享发一次、卡二首次分享发一次，**每只宠物最多两次**
- **重测后再分享不再发放**——去重绑定宠物档案而非测试结果，否则「重测 → 分享 → 拿币」可无限循环
- 仍受 FR-96 既有的两层控制约束：账号每日上限 `M`、跨渠道月度总上限
- ⚠️ 这与 FR-96 原文「同一宠物档案首次分享发放一次」不同（原文是每档案一次，本 FR 是每档案每卡类型各一次），**须在 PRD 中写明是有意扩展，并同步后台 AB-3M 的渠道注册**

### 2.6 重测、回看与结果列表页

**重测：免费、不限次数。但新结果是锁态，需要重新解锁。**

**⚠️ 重测前必须弹确认**，否则是坑：

| | 文案 |
|---|---|
| 中文（内部） | 重新测试会生成一份新的结果，**新结果需要重新解锁**。你已解锁的这次会完整保留，随时可以回看。 |
| English（App） | Retaking creates a new result, and **the new one needs to be unlocked again**. What you've already unlocked stays — you can always go back to it. |
| Bahasa Indonesia（App） | Tes ulang bikin hasil baru, dan **hasil barunya perlu di-unlock lagi**. Yang udah kamu unlock tetap tersimpan, bisa dibuka kapan aja. |

**结果列表页（新页面，2026-09-18 拍板纳入本版本）：** 承载一只宠物的历史测试结果。

- 每条显示：测试日期 · 代号 + 角色名 · 解锁状态 · 是否正在佩戴
- 点击条目 → 进入该次结果页
- **佩戴管理在本页完成**（另一处入口在结果页内）
- **已解锁的结果为购买当时的快照**——文案、插画、解读内容都固定在购买时的版本，后续运营更新文案不影响已购快照

### 2.7 Diary 联动

**测试完成后在该宠物的 Diary 时间线插入一条 banner**（形态复用里程碑 / KTP / 打卡的 banner 条目）。

- **仅在解锁后插入；未付费不插**——与角色小标同一逻辑，付费才进入公开展示层
- banner 内容：角色插画缩略 + 代号 + 角色名 + 测试日期
- 点击 → 跳转该次结果页
- 重测并解锁新结果 → **插入新 banner，旧 banner 保留**（历史事实，与打卡 banner 同规则）

## 3. 维度体系（2026-09-14 定稿；2026-09-18 改为 MBTI 字母形态）

### 3.1 设计路线：借四字母外形，保留可测量内核

**参照先例：16Personalities 本身就不是 MBTI**——它借用 MBTI 的四字母外形与 16 型结构，内核换成 Big Five 实证模型，明确不采用荣格认知功能，并靠附加 -A/-T 后缀与自有模型名（NERIS Type Explorer）与 MBTI 商标切割。印尼年轻人熟悉的「我是 INFP」正是出自该站，不是出自 MBTI 官方测评。

本 FR 走同一条路：**四字母外形对齐大众认知，每个轴的实际内涵与题目仍锚定猫狗人格量表的既有因子**。

**⚠️ 合规红线：** App 内、商店文案、运营素材**一律不得出现「MBTI」字样**，也不得宣称与 MBTI 等价或兼容。MBTI 为 The Myers-Briggs Company 注册商标；四字母组合本身不受商标保护（16Personalities 即先例），但「MBTI」这个词不能用。对外一律称 **Tailsonality**。

### 3.2 为什么 N/S、T/F 能用在宠物身上

MBTI 原本的 N/S（抽象 vs 实感）与 T/F（逻辑 vs 价值）是**认知功能**维度，动物没有对应构念，直译过来出不了可观察的题。但**大众认知里的这四对字母**与我们的可测量维度几乎一一对应，因此按大众语义映射，而非按荣格原意：

| 字母 | 大众认知的含义 | 本 FR 的实际维度 | 学术锚点 |
|---|---|---|---|
| **E / I** | 外向 / 内向 | 社交取向 | Extraversion(sociability) · Amicability · Agreeableness |
| **N / S** | 好奇跳跃 / 务实眼前 | 探索倾向 | exploration-avoidance（动物人格经典轴，Réale et al.）· Openness |
| **T / F** | 理性冷静 / 感性情绪化 | 情绪反应 | Neuroticism（猫狗双模型均有） |
| **J / P** | 有计划有目标 / 随性灵活 | 驱动力 | Motivation · Training Focus · Impulsiveness |

**为什么能量做后缀而不进四字母（2026-09-18 拍板）：** 能量高低是宠物主人最直观的认知，但 MBTI 四轴里没有它的位置。做成后缀既保住这个特征，又不破坏四字母的熟悉感——与 16Personalities 用 -A/-T 承载第五轴（Identity）是同一手法。

### 6.0 出题原则与交付说明

- **主人代答，不是宠物自答**——题干一律以「你家宝贝」为主语，问主人观察到的行为，不用第一人称扮演宠物（扮演腔在印尼市场偏幼稚，且与付费内容的「解读」定位冲突）

### 6.7 计分规则

**逐轴独立计分，轴与轴之间不交叉。**

1. 每题按所选选项记权重（+2 / +1 / -1 / -2）
2. 轴得分 = 该轴全部题目权重之和

| 轴 | 题数 | 得分范围 | 得分 > 0 | 得分 < 0 |
|---|---|---|---|---|
| 社交取向 | 4 | -8 ~ +8 | **E** 外向 | **I** 内向 |
| 探索倾向 | 4 | -8 ~ +8 | **N** 好奇探索 | **S** 务实守成 |
| 情绪反应 | 4 | -8 ~ +8 | **F** 敏感情绪化 | **T** 淡定钝感 |
| 驱动力 | 3 | -6 ~ +6 | **J** 目标坚持 | **P** 随性灵活 |
| 能量水平 | 3 | -6 ~ +6 | **-H** High energy | **-L** Low energy |

> ### ⚠️ 情绪轴的方向与其他四轴相反，这是唯一的例外
>
> 其余四轴，**先写的那个字母就是正分**：E↔I 正分是 E、N↔S 正分是 N、J↔P 正分是 J、-H↔-L 正分是 -H。
>
> **唯独情绪轴写作 T↔F，但正分是后写的 F。** 因为 MBTI 的书写顺序固定为 T 在前、F 在后，而语义上「反应大 = 敏感 = F」必须对应权重 +2。
>
> 举例（猫套 Q8「突然一声巨响」）：「整只弹起来，冲进藏身处」= **+2 = F**；「基本没反应，继续睡」= **-2 = T**。
>
> **做错的后果不是个别偏差，是系统性错配**：若按「轴名里 T 在前所以 T 是正极」实现，所有敏感的宠物会被判成淡定型，16 个角色有 8 个会整片对调，而且测试本身跑得通、不报错，只有靠人工核对结果才能发现。

**实现验收用例（必须全部通过）：**

| 用例 | 输入 | 期望输出 |
|---|---|---|
| V-1 | 全部 18 题都选第 1 个选项（全 +2） | `ENFJ-H` |
| V-2 | 全部 18 题都选第 4 个选项（全 -2） | `ISTP-L` |
| V-3 | 仅情绪轴 4 题（Q8~Q10 · P2）全选第 1 项，其余轴全选第 4 项 | 第 3 位为 **F**，其余为 `I_S_P-L` → `ISFP-L` |
| V-4 | 仅情绪轴 4 题全选第 4 项，其余轴全选第 1 项 | 第 3 位为 **T**，其余为 `EN_J-H` → `ENTJ-H` |
| V-5 | 某轴得分恰为 0（如驱动力选 +2 / -1 / -1） | 取该轴锚题（Q11）方向 → **J** |

**V-3 / V-4 是专门用来抓情绪轴反向实现的**，不可省略。

3. **平局兜底（得分 = 0）**：以该轴**第 1 题**（Q1 / Q4 / Q8 / Q11 / Q14，均为该轴区分度最高的锚题）所选选项的正负方向为准；锚题本身不会为 0——选项无 0 权重
4. 四个字母按 **社交-探索-情绪-驱动** 固定顺序拼接，能量后缀以连字符接在末尾：`ENTJ-H`
5. 四字母映射到 §4.1 的 16 角色之一；后缀只改变结果文案中的能量段与分享卡上的标签，**不改变角色本身**（插画仍 16 套）

**不做分布校准（2026-09-14 拍板）**：阈值一律取 0，不为了让 16 格人数均匀而调整切分点。冷门角色即稀有款，稀有本身有分享价值。

**上线后需监测**：若某个角色 3 个月内占比低于 1%，属于题目而非人格的问题（多半是某轴选项权重设计偏斜），届时按埋点 `role_code` 分布复核该轴题目，不动阈值。
