# ops AI 查数 · 体验规格

视觉见 `DESIGN.md`。逐屏参考见 `mockups/index.html`，本文件与单页稿冲突时以本文件为准。

## Foundation

仅电脑端。服务端渲染 Thymeleaf + htmx 1.9.12，复用 `admin/layout` 和 `tpl-a-workbench`。

## Information Architecture

| 页面 | 入口 | 用途 |
|---|---|---|
| `/admin/ai-query` | 导航“概览”下方的顶层单链接 | 新建对话、查看状态 |
| `/admin/ai-query/{conversationToken}` | 左栏对话、直接链接 | 查看和追问某个对话 |

无 `ai.query` 权限时不显示导航入口，直接访问进入现有拒绝页。

## Voice and Tone

短句，说清发生了什么、接下来能做什么。不写“抱歉”和技术错误码。全部文案进入 `messages_zh_CN / en / id`，示例问题同样本地化。

## Component Patterns

| 组件 | 规则 |
|---|---|
| 对话列表 | 用现有 `q-list`，按最后更新倒序，滚动加载；标题取问题前 80 字；状态随轮询更新 |
| 输入框 | 默认继续当前对话；Enter 发送，Shift+Enter 换行，输入法选词时不发送；上限 2000 字 |
| 回答语言 | 中文、English、Bahasa Indonesia，默认跟随后台界面语言，只在新建对话时选择，按对话保存 |
| 推荐问题 | 先显示本人最近问过的问题（各对话的第一个问题，不含追问，去重，最新在前），最多 4 条，标“最近问过”；不足 4 条用固定示例补齐。点击只填入输入框，不直接发送（2026-11-10 Dai 决定） |
| 答案 | 结论、表格、统计口径、文件卡、页脚依次排列；每个答案固定带统计口径 |
| 表格 | Markdown 净化后渲染，过宽时在容器内横向滚动 |
| 重新查询 | 在当前对话新增一轮，沿用原问题 |
| 复制 | 复制整个答案 |

## State Patterns

| 状态 | 屏 | 处理 |
|---|---|---|
| 无历史对话 | A1 | 示例问题 |
| 功能未启用 | A2 | 输入框禁用 |
| 无权限 | A3 | 现有拒绝页 |
| 输入问题 | B1 | 见“输入框”组件 |
| 输入校验失败 | B2 | 错误紧贴输入框，保留内容；为空时提示“请输入问题” |
| 排队中 | B3 | 显示等待时长；agent 不可达时停在此状态，到时转超时 |
| 查询中 | B4 | 显示已用时长和“可以离开”；同一对话禁止追问；第一期不能取消 |
| 离开后看其他对话 | B5 | 左栏继续显示进度和计时 |
| 未完成任务已达 3 个 | B6 | 拒绝提交，保留内容 |
| 完成 | C1～C3 | 见“答案”组件；用户离开期间完成时，标签页显示“(1) 已完成” |
| 文件已清除 | C4 | 显示“已清除”；保留期按对话最后更新时间 30 天 |
| 查询失败 | D1 | `{colors.danger}`，可重试 |
| 超时 | D2 | `{colors.warn}`，可重试 |
| 额度用尽 | D3 | `{colors.warn}`，可重试 |
| 授权失效 | D4 | `{colors.danger}`，不提供重试，输入框禁用 |
| 对话不可访问 | E1 | 不存在、属于他人、已过期文案相同 |
| 连接中断 | E2 | 轮询失败时提示，恢复后自动继续 |
| 列表过长 | E3 | 现有 `q-more` 滚动加载 |

## Interaction Primitives

- 仅在存在未完成任务时每 3 秒轮询，同时更新右栏和左栏；全部结束后停止。
- 打开对话时定位到最新一轮。
- 重试沿用原问题，进入排队状态。

## Accessibility Floor

输入框有读屏标签；错误用 `role="alert"`，查询状态用 `aria-live="polite"`；状态同时有文字；对比度沿用 admin.css 已校验的令牌；页脚按钮点击区域约 40px。

## Key Flows

**Ayu 查月度注册数（虚构人物）**

1. Ayu 从导航进入 AI 查数，点击示例问题填入输入框，再改成自己的问法。
2. 发送后看到“排队中”，很快变成“正在查询”。
3. Ayu 切到另一个对话继续工作，左栏仍显示计时。
4. **结果完成，标签页提示“(1) 已完成”，Ayu 回来看到结论、表格和统计口径，可以放心把数字发给同事。**
5. Ayu 继续追问平台拆分，或下载导出文件。
