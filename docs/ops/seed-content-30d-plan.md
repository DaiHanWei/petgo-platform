# 种子内容 · 30 天排期与选题库

> 配套手册抓手 3「Feed 每天要有新东西看」。核心判断：**空房间是留存杀手**——
> Social 266 人打开、只有 27 人互动，新用户进社区面对的是空屏。
> 本文只讲运营怎么执行，不需要动代码。

---

## 0. 工具与四条硬约束（先读，能省掉一整轮返工）

后台已有现成工具，不用等开发。⚠️ **入口在 V1.1.6 被重做过**，
旧的「贴进去就发」还在，但新工作台多了预览校验、Excel 导入和**定时发布**，
排期用新的那个：

| 入口 | 用途 |
|---|---|
| `/admin/seed-batches` | **批次工作台（推荐）**——建批次 → 导入/粘贴 → 预览校验 → 确认发布 |
| `/admin/seed-batches/{id}/template` | 下载 Excel 模板（6 列） |
| `/admin/content-schedules` | 定时发布队列：改时间、取消 |
| `/admin/seed-post` | 单条发布（要挑具体宠物、要传图时用） |
| `/admin/seed-batch?tab=batch` | 旧的「贴多行就发」——**没有预览**，去重命中会静默跳过，只适合临时补几条 |

**Excel 六列**：`正文` / `图片文件名` / `发布账号` / `内容类型` / `关联物种` / `计划发布时间`

- `内容类型`：只收 `DAILY` 和 `KNOWLEDGE`。**「成长日历」会被直接拒绝**（模板下拉里没有，
  但运营可以手打进去 —— 拒绝比静默继承默认值好，后者会让发出去的类型不是他写的那个）
- `关联物种`：`GENERAL` / `CAT` / `DOG` / `OTHER`
- `计划发布时间`：`2026-09-01 08:30`（**WIB 墙上时间**）。留空继承批次默认；都留空 = 立即发布。
  ⚠️ 格式不对**不会报错**，会被当成没填 → 立即发布。排期前务必核对这一列。
- `图片文件名`：不是 URL，是先上传到该批次的素材文件名（`/admin/seed-batches/{id}/assets`）

**四条硬约束**：

1. 正文**上限 1000 字**（超了后端直接 422）。纯文字可以发，不强制带图；单条最多 9 张图。
2. **去重按（正文 hash + 作者）**：同一文案换个账号可以再发，同账号重发会被跳过。
   旧的「贴进去就发」路径是**静默跳过**；新工作台会在预览里提示。
3. 作者必须在**运营发布身份池**里（`identities.isInPool`）。
   以**运营真实账号**身份发内容需要单独权限码 `seed.publish_as_real`。
4. 账号被停用 = 不能再替它发内容（虚拟账号「停用」与真实账号「被封」在这里是同一件事）。

## 1. 每日配比（N = 5 条）

阈值 N=5 是拍脑袋的起点（见 `scripts/ops/thresholds.json`，confidence=`guess`），
跑两周后按「新用户进 Social 后是否发生互动」回调。

| 类型 | 条数 | 发布方式 | 目的 |
|---|---|---|---|
| 成长瞬间（日常） | 3 | 批量（DAILY） | 让 Feed 有「别人家宠物今天做了什么」——这是 D3 推送把人拉回来后要看到的东西 |
| 互动钩子（提问式日常） | 2 | 批量（DAILY） | 专治「266 人打开只有 27 人互动」——问题比陈述更容易被回复 |
| 科普 | **每周 1 条**（排周三） | 批量，类型写 `KNOWLEDGE` | 建立「TailTopia 是懂科学的那一个」 |

> ⚠️ 科普刻意是**周频不是日频**：每条都要人过眼（医疗红线），日频的审稿负担撑不住，
> 而撑不住的结果不是「少发几条」，是「没人审就发出去了」。周三发是因为周中互动最好。
> 等审稿流程跑顺了再往上加。

**发布时段**：集中在 **18:00–20:00 WIB**，与生命周期推送（19:00 WIB）同窗口。
被 D3 推送拉回来的人，落到 Feed 时要正好看到当天的新内容，而不是昨天的。

## 2. 30 天选题库（印尼市场 · 雅加达气候 · 常见品种）

按周主题排，每周 1 条科普 + 若干日常/钩子。**避开雨季/旱季错配**——
雅加达 10 月–次年 4 月雨季，选题要跟着走。

| 周 | 科普主题（KNOWLEDGE） | 配套日常/钩子方向 |
|---|---|---|
| 第 1 周 | 雅加达湿热天气下的皮肤病预警信号（什么时候该去医院） | 洗澡后吹干、耳朵检查、晒太阳的时段 |
| 第 2 周 | 猫狗饮水量：怎么判断喝够了（附「该问兽医什么」清单） | 水碗摆位、喝水小习惯、你家的喝多少？ |
| 第 3 周 | 疫苗与驱虫的时间表怎么读（**不给剂量数字**） | 疫苗本拍照留档、第一次去医院的紧张 |
| 第 4 周 | 中暑与热应激：路上做什么/不做什么 | 正午遛狗时间、地面温度手背测试法 |

> 每周的 7 天里，科普那 1 条排在**周三**（周中互动最好），
> 周末两天日常条数可以从 3 提到 4——用户周末在家、更有时间刷。

## 3. 接《宠物科普内容运营智能体》

你已有的那份 system prompt 就是干这一步的。接法：

**输入模板**（每周一次，一次出一周量）：

```
本周科普主题：<从上表取>
市场：印尼（雅加达为主），读者是养宠 0–3 年的城市养宠人
输出语言：印尼语（Bahasa Indonesia），口语、不用书面公文腔
数量：科普长文 1 篇 + 可直接发的短日常 21 条（每天 3 条 × 7 天）+ 互动钩子 7 条
每条日常：≤ 120 字，第一人称宠物主口吻，不带品牌名、不带链接
每条钩子：以一个具体问题结尾（不要「你觉得呢」这种空问）
```

**输出 → Excel 的列映射**：日常/钩子直接落 `正文` 列，图片 URL 落 `图片URL` 列。
科普那 1 篇**不要**进 Excel（会被打成 DAILY），单独走单条发布页。

**智能体的三条红线照抄不误**（它的 prompt 里已经写了，运营复核时按这三条验收）：
- 把握低于 80% 的事实**不写**，进【需人工核实】区；
- 处方药**不写剂量数字**，一律「按体重由兽医计算」；
- B/C 级结论不得用 A 级的确定语气——这是最常见也最致命的科普事故。

⚠️ **AI 出的科普稿必须有人看过再发。** 这不是流程洁癖：宠物健康内容说错一次，
前面积累的信任全部清零，而 TailTopia 的护城河恰恰是「本地信任」。

## 4. 每日执行清单（3 分钟）

- [ ] 打开 Feed，数今天有几条新内容（含真实用户的）
- [ ] < 5 条 → 从本周内容池取差额，批量发（日常/钩子）
- [ ] 本周三 → 确认科普那条的 `内容类型` 是 `KNOWLEDGE`，且**已有人逐字审过**
- [ ] 检查上周发的内容有没有被举报/下架（后台内容管理）
- [ ] 内容池见底 → 跑一次智能体补下周量

## 5. 什么时候可以把这块交给 agent

手册第五章把「种子内容生产」列为**第一批可以直接交给 agent** 的动作——理由是它可逆、低风险
（发错了可以下架）。但注意手册说的是**生产**，不是**发布**：

- ✅ 现在就能交：选题、写稿、出 Excel（智能体已就绪）
- ⏸️ 暂不交：**按下发布**。科普稿必须过人眼，日常稿至少扫一遍有没有踩医疗红线
- ❌ 不交：内容被举报后的处置——那涉及社区规则判断
